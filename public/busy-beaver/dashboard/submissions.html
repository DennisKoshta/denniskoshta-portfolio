**A nested bell counter never halts**

`1RB0RC_1LC1RB_0RE1LD_0LC1LA_1RF1RA_---0RB`

PR: https://github.com/ccz181078/busycoq/pull/28

The head shuttles between a wall and a binary counter whose bits are three cells apart. Each round consumes two pairs of the bell and decrements the counter. When the bell runs low, the wall bites the counter; a bite on low set bits can open several nested copies of the same process.

The proof keeps two facts: the bell is large enough, and a nonzero residue modulo 3 changes sign at each completed cycle. The tape's left side acts as a stack of pending levels.

The useful part is the induction: we prove safety for every finite number of steps, so we do not need to prove that each nested level eventually returns. After a checked 327-step prefix, the invariant rules out halting forever.

The Rocq file proves `nonhalt: ~halts tm c0.` against busycoq BB6. `Print Assumptions nonhalt` is closed. The low-level rule layout builds on BECv5's TM1.

Three more BB(6) nonhalting proofs: a bouncer whose apparent chaotic edge follows an exact recurrence.

```text
1RB1LD_0RC1RC_1LA1RE_---1LE_1RF0RC_0RB0LF
1RB1LE_1LC1RD_0LA1LA_---1RE_1LF0LA_0LC0RF
1RB0RD_0RC0LB_0RD1RD_1LE1RA_1RC1LF_---1LA
```

These are three starts of one transition table, after renaming states and reflecting one machine. The head crosses five blocks of ones separated by short words. Every twelve trips, two separators move closer; their collision rebuilds the blocks. Two collision types then alternate forever.

At the boundaries of each double cycle, the relevant block lengths obey:

```text
(n,x) → (n + 12x + 808, x + 32)
```

Each start has a separately proved opening into this family. They reach it at steps 153,126,993; 153,013,640; and 163,638,058 respectively. The closed recurrence then proves all three never halt.

A spread-digit bouncer counter: nonhalting proof submitted in https://github.com/ccz181078/busycoq/pull/26

`1RB0LF_0RC---_1RD0RA_1LE0RC_0LA0LE_1LE1LB`

This machine is a binary counter with variable gaps between its digits. Ordinary bounces increment the counter. At overflow, a finite tail either lets it wrap or triggers a long pause: the left side freezes into a wall, which is consumed two increments at a time while the gaps are rebuilt and new digits can be inserted.

The key is a four-rule token transducer for the return from the tail. Together with the tail's small front-unit cycle, it reduces the behavior between normal overflows to four paths. An interval invariant is preserved by every path, so the proof does not have to predict the tail's choices.

The blank run enters the invariant after 92,299 steps. The Rocq file proves blank-tape nonhalting directly, using Individual62 and standard libraries. Its structure follows CounterClass3v2 TM1's sweep/carry/macro-step approach.

`1RB0RF_1RC1RF_1LD0RE_---0LE_1LA0LE_0RA0LC`

PR: https://github.com/ccz181078/busycoq/pull/25

A marker moves along the tape while incrementing a counter. When its budget runs out, it consumes one counter digit and leaves a residue. Cleaning up that residue can launch a whole nested epoch inside a single outer bounce.

Informal write-up: attached

Watched each time the head reaches new ground on the right, the tape is a binary counter, and every carry burns fuel in each digit it touches. A digit that runs dry sheds a spare wall toward the head (walls drift right and refill the digits there), but a digit with a single marker has none to shed. New digits are born at the right end, and the time between births grows by a ratio that oscillates with growing swings; when the third swing crosses 2, a single-marker digit is left with bit 0 and no fuel, and the next carry into it halts the machine.

The .v replays the whole run in 107,781 checked moves (closed-form batches between structural events). It compiles against unmodified busycoq, Print Assumptions lists only functional_extensionality_dep (from flip_halts_iff), and coqchk passes.

PR: https://github.com/ccz181078/busycoq/pull/15
Attached: informal write-up + space-time diagrams

**Mechanism**
- The tape is a binary down-counter: a list of pairs `(10)^p (01)^q`, each carrying one digit, behind a left marker `(10)^h 11001`.
- Each decrement touches the pairs up to the borrow. A pair whose q runs out fuses with the next one.
- At 0 an End sweep adds a tail; at the next 0 the list is re-paired with one more pair, and the count starts again.

**Proof**
- Nine macro rules, each proved as `K -->+ K'` from 14 `es` sweeps.
- A per-step invariant (bounds on p + Rt and q − Rt, where Rt counts the touches a pair still gets before the next re-pairing, plus parities) is preserved by every rule. It holds at the base, reached after 78,710 steps; `progress_nonhalt_cond` concludes.
- Loose template: SBCv6 TM21.

The same table started in B, C and D is also on the holdout list; those are in the same PR, each in its own thread.

Checks: Coq 8.20.1, unmodified busycoq, Print Assumptions closed, coqchk passes (~65 s).
