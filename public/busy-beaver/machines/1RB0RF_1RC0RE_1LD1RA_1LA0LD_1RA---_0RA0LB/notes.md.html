Cleanup time, exact

  • Set-up:
  • V is the clean word the bell shifts (B0: 0T'', B1: inc T).
  • The depth of a token is the number of digit tokens (0/1) before it.
  • The j's of V have depths d_1 ≤ … ≤ d_k, and f = d_k.
  • Y = value(V) + Σ_i 2^(d_i).
  • Cleanup lemma (paper, from the recursion):
  • The t walks through V's j's in order.
  • The digits below the t always hold exactly the number of increments since the bell.
  • Each cascade adds 1 at the next j's depth and freezes the 1-digits it passes into j.
  • So the t vanishes at increment exactly 2^P, with P = the number of 0 bits of Y among bits 0..f−1 (P ≤ f).
  • After cleanup, Y's 1 bits are j's, its 0 bits are digit slots, the top j has depth zb(Y) (the zeros of Y below its top bit), and the counter value equals the number of increments since the bell.
  • Validated (cleanup_formula.py):
  • 100,000/100,000 macro epochs: the exact cleanup time; the top-j depth on all 19,774 dirty epochs of the first 20,000.
  • 4,800/4,800 random V in the model.
  • 240/240 random V by direct TM, counted hub by hub from K(0, 2^P+3, σ(V)) (84 + 77 + 79).
  • The A-frame macro simulator (amacro.py) reproduces the N sequence of data/macro_epochs_2e4.json (20,000/20,000).

Proved on paper

  1. Closure. {clean words} ∪ {words with exactly one t} is closed under inc and under σ of clean words, and inc never meets 011 or 11 there. So no halt occurs inside R1. The t-case recursion terminates because the number of j's after the t drops.
  2. Depths never increase. σ and inc map tokens one to one (only 1→j and j↔t change, plus new top digits).
  3. value(T) ≤ a at every b = 0 hub, with equality at the first b = 0 of an epoch (cleanup leaves value = increments = a; R1 adds 1 to both; E gives value(T') ≤ value(T)/2^(r+1) < a+2+r). Hence N ≥ value(V) at every bell (B1: value(V) = value(T)+1 ≤ a+1 = N; B0: value(V) ≤ value(T)/2^(r+1) < N). Checked on 199,045 b = 0 hubs and 100,000 bells (invariants.py 1e5): 0 failures.
  4. If V has a digit after its last j (S1′), then 2^P ≤ 2^f ≤ value(V) ≤ N, so the t is gone before the first b = 0.
  5. L* ⇒ S1′ next epoch. L*(e): 2^zb(Y_e) ≤ N_e. Then by the first b = 0 of epoch e the count has carried past the top j. E, B0 and B1 keep that order, so V_{e+1} has a digit after its last j, and (4) covers epoch e+1.

Integer epoch model (nmodel.py)

  • Post-cleanup multiset M* = {Z_d(Y) : d ∈ M} ∪ {Z_p(Y) : p a 1 bit of Y}; its maximum is zb(Y).

Potential identities (paper; checked)

  • Let U = n + Σ_{d∈M} 2^d be the potential of the word at b=0.
  • The three b=0 steps act on it as follows:
  • E(μ, k): U → (U + 2)/2^μ − 2.

Lemma S (paper; checked)

Setting. Let epoch e be safe. Let m = bitlen(N_e), and let s be the total shift of e's b=0 loop: the sum of μ over its E eats, plus r+1 for a B0 bell (s = 0 for a B1 bell with no E). Write zb(Y) for the number of zero bits of Y below its top bit.

Statement. - C(e) means: zb(Y_e) ≤ m − 1 + s, or (s = 0 and Y_e = 2^m). - Lemma S: C(e) implies that epoch e+1 is safe.

Proof. - The top j of V_{e+1} has depth at most zb(Y_e) − s, and P_{e+1} is at most that depth. - Case zb(Y_e) ≤ m − 1 + s: then 2^P ≤ 2^(m−1) ≤ N_e < N_{e+1}. - Case s = 0 and Y_e = 2^m: - All old depths stay, because Z_d(2^m) = d. So M* = M ∪ {m}. - The B1 bell gives Y_{e+1} = 2^(m+1) + (N_e − v_e + 1). - Hence P_{e+1} = m − popcount(N_e − v_e + 1) ≤ m − 1, using 1 ≤ N_e − v_e + 1 ≤ 2^m and v_e ≤ N_e. - In the edge case N_e − v_e + 1 = 2^m, P = m and N_{e+1} = 2^m, so the epoch is still safe.

Corollary. If Y_e < 2^(m+1), then C(e) holds, because zb(Y_e) ≤ m with equality only for Y_e = 2^m. So C can fail only when Y_e ≥ 2^(bitlen(N_e)+1), which needs J_e > 2^m > N_e.

Checks. - Trajectory to 1e5: C holds at every epoch, and C ⟹ safe(e+1) holds 100,000/100,000. - Random states (half tuned to Y ≈ 2^q, 3 seeds): 59,887/59,887. - C is close to sharp: in the 113 random states where C fails, the next epoch is unsafe 10 times.

What is left: the Big-Y lemma

Needed: for every epoch, if Y_e ≥ 2^(bitlen(N_e)+1), then zb(Y_e) ≤ bitlen(N_e) − 1 + s_e. - With Lemma S and the prep results, this gives non-halting from blank. C also holds at epochs 7, 8, 14 and 15, so no finite prefix is needed beyond init and epoch 1.

Conjecture C0: 2^zb(Y_e) ≤ N_e, or Y_e = 2^bitlen(N_e). - It implies C and holds at all 1e7 epochs. - It is not inductive on its own (c0test.py). Over 2 seeds, 5 epochs per start: - from 6,000 perturbed reachable states, C0 broke 3 times; - from 6,000 tuned near-crossing states, C0 broke 7 times, and one start became unsafe.

Half of a proof: - Right after an exact-power epoch with s = 0, Y_{e+1} = 2^(m+1) + (N_e − v_e + 1). - C(e+1) then needs only popcount(N_e − v_e + 1) ≥ 2 − s_{e+1}. - Missing: that big Y arises only there.
