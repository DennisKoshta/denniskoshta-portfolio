What is now proved locally

At each reduced A/C boundary, suppose the tape strictly left of the head contains no adjacent zeros. Eight exhaustive local rules preserve this condition. The hazardous windows A001 and C000 violate it. This gives nonhalting for an arbitrary right word with an infinite 011 reservoir on the left.

The complete argument is formalized in ../LocalSafety.v. The premise fails on blank left tape, so this theorem is explicitly not a blank-start nonhalting theorem. Root also formalized the uniform bulk roundtrip in ../LocalBulk.v, the sweep schemas in ../LocalSweep.v, and the local prefix interfaces in ../LocalRules.v. Their assumptions are closed; independent kernel receipts are maintained by root.

The run-sweep derivation is order-sensitive. A one-run is split into groups of three, emits 011 blocks, and either continues left or turns C right. A right turn can increase the preceding one-run before that run is scanned. Counts of run residues therefore discard information used by the next return. The precise schemas and finite checks are in run-sweep-schemas.json and run-sweep-samples.json; an independent checker replayed 17,120 instances with arbitrary two-bit exteriors.

The exact finite-reserve reduction

normal-form.md defines N(k,w)=A>0(011)^k w and gives every branch. It includes blank start as (k,w)=(0,empty).

The virtual core processes the full word w independently of k. A D call with right bit zero consumes one prefix block; a D call with right bit one returns without consuming one. If it terminates at the interface, record its consumption d, exit state s, and output word v.

  • If the core asks for more than k blocks, the real machine enters F on a blank left tail and moves left forever.
  • If s is A and k=d, the real machine reaches E0 two transitions later and halts.
  • All other terminating cases return to the normalized section. A with one block remaining and F with no block remaining need one-return boundary rules. E with no block remaining still has a regular two-return rule and regenerates at least one block.

The zero-reserve entry convention is exact: A00 reaches the same state as the first five virtual C steps in only two steps. This supplies an accounting offset of -3, not a negative transition sequence.

A clean remaining proof target

Away from the explicit boundary restarts, canonicalization gives a word-only two-return map. If c counts leading 011 blocks absorbed into the next reserve, its debit is

delta = d + [exit=A] - c.

For cumulative debit D_i, a sufficient invariant is a bound on D_i + threshold(w_i), where the threshold is d+2 for A, d+1 for F, and d for E, together with the entry-domain condition. Below the threshold, the exact boundary rules can change the word trajectory. The model therefore does not claim that one word trajectory works for every reserve forever.

The final one-return boundary in the saved prefix ends at record 32, step 5104, head -32. Its normalized seed has reserve 1 and the following 81-bit word:

111001111011001110111011101110110111111111011001111011011111111001111011011111111

The next 380 observed normalized steps all lie in the common two-return domain. Their required initial reserve is exactly 1. This yields a concrete future target: prove the infinite supremum of cumulative debit plus threshold is at most 1 for this seed. The present evidence only establishes the finite prefix through record 792.

Precise obstructions

Simple run constraints are insufficient. The constructed configuration A>0(011)^4 1111 P²T has no internal 000 and no isolated one-runs, but reaches E0 after 108,338 defined transitions. Its halt was independently replayed. It is not a state asserted to occur from blank tape.

A stronger obstruction is universal. lookahead-obstruction.md derives two families of right words sharing arbitrarily long prefixes. With a single remaining prefix one and blank tape farther left, one family halts and the other takes the infinite F escape. Both can satisfy the same simple run constraints. Independent literal checks passed 6,336 cases with sixteen exterior contexts, exact tape/head/time agreement and read confinement. ../LocalObstruction.v formalizes these opposite outcomes uniformly in the parameters and arbitrary unread suffixes. No fixed left window can classify the relevant arbitrary core inputs.
