Mechanism

  • Rename the twin's states A..F to B,C,D,E,F,A. The result is #12 with one transition changed (A0 = 1RA instead of 1RB; in twin names F0 = 1RF), started in #12's state B. It is not #12 up to renaming or mirroring (all 1,440 relabelings checked). F0 is read only at the first step of the left-edge push R3, where it takes a 6-step detour (F0 F0 F1 B1 A1 A0) to the configuration #12 reaches in 2 steps. The tape effect is the same; it costs 4 more steps.
  • So the run model is #12's. The tape is a stack of runs of 1s, run like a call stack (push R1, edge push R3', pop R2). An epoch on a word W replays the machine's own history one level down, on W's marker tail. Each inner epoch costs 2, or 3 when it absorbs a marker (#12's absorption law).
  • The difference is the edge. The twin returns to 0^inf <F 0 1^2 0^2 W, where #12 returns to 0^inf <A 0 1^3 0^2 W, so its edge frame has budget 2 instead of 3. The top level has no markers, so every top epoch costs exactly 2: zero slack, but it never runs out.

How the proof works

  • Rules. tR1, tR3/tR3c (R3', including the detour) and tR2, each one plain es. #12's whole model layer is unchanged: Life/Life_tm, the epoch rules, and main, the absorption law by induction on n + #markers.
  • Budget 2. The new Ep_tm2 : Ep W 2 W' -> conf [] (2::2::W) -->+ conf [] (2::2::W') carries a cost-2 epoch, proved for #12's value-4 edge frame, over to the twin's value-3 edge frame. It is Life_shape at z = 3, then push0_ok at h = 2, then Life_tm.
  • nonhalt. init reaches conf [] [2;2;1] in 48 steps (solve_init). Then progress_nonhalt_cond runs with C i := conf [] (2::2::snd i). The exact cost cost [] n = 2, by reflexivity, is what closes the zero-slack step.
