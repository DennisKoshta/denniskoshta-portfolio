What the counter is. Look at the tape just left of the LSB at each round start. After the A-sweep it is in swept form: dense 1^k 0 becomes swept 1 0^k. Write a swept token 1^a 0^k as k when a = 1, else as a.k. - 2 = 100 is filler. - A token with k ≥ 4 zeros is a binary digit. Its bit cell is index k−3 (the cell E reads when the B-sweep stops there). Bit 1 splits the token: - 5-digit: 5 / 1 3 - 4-digit: 4 / 2.3 - 6-digit: 6 / 2 3 - 7-digit: 7 / 3 3 - A plain 3 token always reads as bit 1, so a carry continues through it. - Left end: 3 (P-mode) or 3 4 (Q-mode). - The LSB sits next to the unary. Each round is one increment plus one marker step. So tm10's binary counter is still there; only the digit encoding changed.

Round start. RS(S,P,b,g,m) = 0^inf S P b <E (110)^(g+1) 00 (110)^m 0^inf. - P is the LSB prefix: 1 (=10) for a 5-digit LSB, 0 (a single 1) for a 4-digit LSB. - b is the LSB bit, g is the marker distance, m is the run right of the marker. - No-marker state: NM(S,P,b,n) = 0^inf S P b <E (110)^n 0^inf. - A round start is an E-left event whose right side is exactly (110)^+ [00 (110)^+].

Generic carry transducer. Derived from the micro-steps (B/C/E/A) and checked only against the blank-tape run, not validated separately. It scans the counter from the right: - 2: skip. - (a,k≥4): set the bit, giving (a,k−4)(1,3). Stop. - 2.3: the previous token gains 2 zeros and 2.3 becomes 2. Stop. This is the 4-digit walking left. The reason is now clear: the transient cluster is a slow carry.
