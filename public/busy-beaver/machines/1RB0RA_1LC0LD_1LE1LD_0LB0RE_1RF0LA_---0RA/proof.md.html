The map. Let σ send #7's states to #30's:

#7 state A B C D E F
σ (#30 state) E A B F C D

Its inverse sends #30's A, B, C, D, E, F to #7's B, C, E, F, A, D. For every state q and symbol s:

#7[q][s] = (w, d, q') ⟺ #30[σq][s] = (w, −d, σq'),

and #7[q][s] is undefined exactly when #30[σq][s] is. The only such pair is #7's F0 and #30's D0. For example, #7's A row 1RB 0RA becomes 1LA 0LE, which is #30's E row.

  • Uniqueness. Among all 720 permutations and both orientations, σ with the mirror is the only map that sends #7's table onto #30's (X1).
  • Consequence. Map a configuration of #7 to its mirror image (cell x goes to cell −x) and rename its state by σ. One step of #7 then becomes one step of #30's table. #7's start 0^inf A> 0^inf maps to 0^inf E> 0^inf. So #7 halts from the blank tape if and only if #30's table halts from the blank tape in state E. In busycoq this is flip_halts plus perm_halts, as in #24 (Δ6). X2 checks the step-for-step correspondence over 2·10^6 steps, with full-tape comparisons at checkpoints.
