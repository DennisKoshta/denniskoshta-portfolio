Summary

  • The parent is a counter fed by a marker bounce. Its hub is K(a, b, X) = 0^inf (110)^a 0 (011)^b C> X 0^inf. Each bounce adds 1 to the counter word X, and at b = 1 the machine eats the lowest digit of X and leaves a residue. The next epoch restarts with budget N = k + 1 and digests the residue recursively. The parent's Lemma D shows that the digestion always fits in the budget (parent Summary, §5).
  • This machine's table is the parent's, mirrored and renamed (§1). So from the blank tape it runs the parent's table from 0^inf E> 0^inf, on the mirror-image tape. That is a different orbit of the same epoch map.
  • Its first four left records are outside the parent's invariant family. The fifth, L(16, 0001) at step 1,059, is inside it, and the restart gives the hub K(1, 17, t1) at step 1,114 (§2). There the parent's orbit invariant (I1)–(I4) holds: it is the parent's own base case "κ = 0, special", with t1 in place of t2 (§3).
  • Everything else in the parent's argument is a statement about the table, about one epoch, or about the induction step, so it holds unchanged (§4).
  • Only the finite part is new. This machine's orbit shares no epoch with the parent's below N = 20,000, so it is computed again: 587 epochs below the write-up's threshold N* = 14,796, and 687 epochs up to N = 17,724 for the .v's invariant (§5).

The map. Let σ send this machine's states to the parent's:

this machine's state A B C D E F
σ (parent state) E A B F C D

Its inverse sends the parent's A, B, C, D, E, F to this machine's B, C, E, F, A, D. For every state q and symbol s:

M[q][s] = (w, d, q') ⟺ P[σq][s] = (w, −d, σq'),

where M is this machine's table and P the parent's, and M[q][s] is undefined exactly when P[σq][s] is. The only such pair is this machine's F0 and the parent's D0. For example, this machine's A row 1RB 0RA becomes 1LA 0LE, which is the parent's E row.

  • Uniqueness. Among all 720 permutations and both orientations, σ with the mirror is the only map that sends this machine's table onto the parent's (X1).
  • Consequence. Map a configuration of this machine to its mirror image (cell x goes to cell −x) and rename its state by σ. One step of this machine then becomes one step of the parent's table. The start 0^inf A> 0^inf maps to 0^inf E> 0^inf. So this machine halts from the blank tape if and only if the parent's table halts from the blank tape in state E. In busycoq this is flip_halts plus perm_halts (§6). X2 checks the step-for-step correspondence over 2·10^6 steps, with full-tape comparisons at 27 intermediate steps.
  • Reading configurations across the mirror. l q> r in the parent's frame is rev(r) <(σ⁻¹q) rev(l) in this machine's frame. The two configurations that §2 needs:
  • L(16, 0001) = 0^inf <A 101 (001)^16 0001 0^inf is 0^inf 1000 (100)^16 101 B> 0^inf in this machine's frame;
  • K(1, 17, 1) = 0^inf 110 0 (011)^17 C> 1 0^inf is 0^inf 1 <E (110)^17 0 011 0^inf in this machine's frame.
  • A third start. The same table is on the holdout list a third time: 1RB1RF_1LC0RD_---0LD_1LE0LD_1RA0RF_0RE0LB is the parent's table renamed, with no mirror, and it starts in the parent's state B (X1). It is not covered here.

From here on everything is in the parent's frame and uses the parent's notation (parent §2): hubs K(a, b, X), left records L(k, T), pre-records L'(k, T), the grammars G ⊂ O ⊂ H, the end words E*, budgets N = k + 1, ordinary and special residues.

3. The base of the parent's orbit induction, clause by clause

The parent's induction (parent §5, D.6) starts at its epoch 3: L(7, 000 t2), N = 8, a special residue, κ = 0. This machine's base is e5: L(16, 000 t1), N = 17, also a special residue.

The running maximum. In D.6, k_t is k(W_t), the number of blocks of the W in the residue Y_t = 11 a^x z W, and k(W) = 0 for a special residue. It is not the record index of L(k, T) in §2's table. The running maximum is taken from e5 on: κ_t := max_{5 ≤ s ≤ t} k(W_s). At the base, κ_5 = k(W_5) = 0: Y_5 = t1 is special and has no W. The record index of e5 is 16, but it does not enter the invariant. Read with it, (I4) would fail at the base, since N_lo(16) = 2^19 − 2^14 is far above 17. X4 checks both readings.

This is the parent's base case, "κ = 0, special", word for word, with t1 in place of t2. Both are tails in G, so the digestion is empty and the reset D.4(r) applies.

No earlier record can serve as the base. At e1 (N = 1) the budget is below β + 2. The induction step from e2 or e3 fails, because their digestion does not fit in N, and the parent's rules indeed do not cover those epochs. e4's residue is not in H, so (I1) fails there, although its epoch is computed by the rules and ends at e5. X4n checks all of this.

4. Why the rest of the parent's argument applies unchanged

The parent's argument has three kinds of parts. Statements about the table hold for every configuration. Statements about one epoch hold for any epoch K(1, N, Y) with Y ∈ H and enough budget. The rest is the orbit induction with its base and its finite part. Only the base and the finite part refer to the starting configuration.

For N_t ≥ N* it is D.7, with the same case split on κ_t ∈ F. - Every epoch has N_{t+1} ≥ N_t + 1 (parent §4, corollary), so N reaches N* after finitely many epochs and stays above it. - Every epoch reaches the next left record. So the sequence of left records is infinite, and this machine never halts.

The parent's finite part cannot be reused. This machine's orbit from e5 shares no epoch (N, Y) with the parent's orbit from its epoch 3, nor with the third start's orbit, up to N = 20,000 (X6). The starts do not merge before the threshold, so this machine needs its own finite part.
