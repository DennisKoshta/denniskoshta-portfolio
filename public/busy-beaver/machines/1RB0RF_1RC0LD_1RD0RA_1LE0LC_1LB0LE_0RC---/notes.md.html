Halting condition

F1 is the only undefined cell. F is entered only from A1 (0RF), so the machine halts iff A reads 1 with a 1 on its right (A> 1 1).

What the tape looks like

Almost all of the tape is one of two fields: - a 3-cell field (011)^n (any phase), and - a 6-cell sea (010001)^m, which carries one phase defect (an extra 0 or an extra 1).

At the left wall sits either a counter (011)^a (a binary counter, 3 cells per digit) or a junk word J of a few dozen cells.

Rules found (validated by direct simulation from constructed configurations)

  • P1 / P0, counter pass (40/40 each; a = 0..9, b = 1..2^a+60, c = 2^a..2^a+300): 0^inf <D (011)^a (010001)^b x (010001)^c 0^inf x = 1 (P1) or 0 (P0) -> 0^inf <D (011)^(a+1) (010001)^(b+2^a) x (010001)^(c-2^a) 0^inf if c >= 2^a One pass = 2^a sweeps; each sweep moves the defect one word right. Pass time grows ~4x per digit. The real orbit has b = 2^a + k with k = 5 or 8 (history: k = 5 in the 5.66e7 cycle, k = 8 in the 8.33e7 one). Rulefit's "closed" table E1(2n, 632-n) -> E0(2n+1, 632-n) is this pass in one cycle, with that cycle's reservoir built in.
  • O, overflow (24/24; a = 0..7, c < 2^a, both defect types): the next right record shows 0^inf J (011)^(2b+2c) C> 0^inf with |J| = 3a+4 cells The 6-cell sea is re-laid as a 3-cell field of the same length; J holds the counter's partial state. J's content is not yet characterised. So the counter runs from a0 to A, where c0 + 2^a0 lies in [2^A, 2^(A+1)), and the residue r = (c0 + 2^a0) mod 2^A is left behind in J.

Verdict for this stage

The micro level is clean (P0, P1, O). The macro level is not: what the next cycle does depends on J, i.e. on a ~12-bit binary residue of a slowly growing n, and the spurt is one residue outcome. Plateau lengths 1, 1, 9, 3, 31 show no pattern. Per the stage brief ("park if the spurts look residue-driven") this is parked as STUCK.

Not flagged CRYPTID_CANDIDATE: the residue map is not formalized, so whether it is pseudo-random is open. It could still be a clean binary rule (e.g. J = binary digits of r, the spurt iff r = 0 or r = 2^A - 1). That is the one test worth funding.
