τ: A↦E, B↦A, C↦B, D↦C, E↦D, F↦F (a 5-cycle on A–E). Row τ(s) of this table is #11's row s with every target state t replaced by τ(t). Symbols and directions are unchanged. Lemma R (relabelling). For a configuration c, let τc be c with its head state renamed by τ; the tape and head position stay the same. Then c → c′ under #11 if and only if τc → τc′ under this machine, and c is halted exactly when τc is (F1 is the only undefined cell, and τ fixes F). So every #11 run c →ⁿ c′ gives a run τc →ⁿ τc′ here, of the same length, and conversely.

Start. This machine's c0 is 0^inf A> 0^inf = τ(0^inf B> 0^inf). So its run is τ of #11's machine run from 0^inf B> 0^inf. It is not #11's own run, which starts in A. §R checks this in lockstep for 2·10⁶ steps (2·10⁷ in the long run): state = τ(#11's state), same symbol written, same move, identical tapes at the end.

Halting cell. Only D1 = 1LF enters F (it is τ of #11's E1), and F1 is ---. So the machine halts exactly when D reads 1 with a 1 to its left.

3. The argument (complete)

Theorem. 1RB0RB_1LC0RA_1LE0LD_1LC1LF_1RA0LD_1LC--- does not halt from the blank tape.

  1. Initial segment. The machine runs from c0 to K((1,1,10); 8, 1) in exactly 732 steps without halting. This is a finite exact computation (§C); in Rocq it is solve_init.
  2. Base. INV([(1,1,10)], 8, 1) holds, in class A (§2).
  3. Transfer. P§3.2 (coverage) and P§3.3 (closure): every INV state has a macro step M or O, of at least 32 machine steps, to an INV state. These statements are about the triples and a, b, and the macro steps are #11's rule instances K → K′. By Lemma R, each instance is a run τK →⁺ τK′ of this machine, of the same length. So coverage and closure hold verbatim for the configurations K_A = τK.
  4. Conclusion. By induction from the base, the run is an infinite chain of macro steps, each of at least one machine step, so it never halts (progress_nonhalt_cond with P := INV, as in P§5). No macro step presents the halting cell: each is an exact computation from one K to the next, composed of window lemmas in which F reads only 0. ∎

Nothing in #11's argument after its init depends on #11's own orbit. Its orbit statistics (P§7) are evidence, not premises.
