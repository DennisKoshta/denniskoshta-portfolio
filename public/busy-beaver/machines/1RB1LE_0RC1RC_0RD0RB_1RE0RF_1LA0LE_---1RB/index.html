Mechanism

How it works: 3 notes
  • Inner loop Y(a,b,c) = 1^a 001 (10)^b 11 (01)^c E>: each round a+2, b-1, c+3, eating 6 blank cells.
  • When b hits 0, E wipes the 1^a block and walks left (Return); the level to its left resumes the same loop.
  • When that gap runs out it calls the right level again: a call stack, so each epoch replays shrunken copies.

Proof strategy & riskshow the formal proof will go · 3 risks to watch

Copy TM20's skeleton, not its rules: prove XY/YX/XY1/YX1/Return with es + ind (Incs-style), define P u r r' (call returns 0^u), prove one Column lemma per gap residue mod 3, then a Good-style inductive invariant with inequality bounds on the column chain; init via chunks + native_compute; nonhalt via progress_nonhalt.

  • ▲Gap leftovers mod 3 vary in the run (start residues 1:41, 2:23, 0:17 of 81 runs); TM20 kept all counts = 0 mod 3. Invariant must track residues.
  • ▲Epoch ratio alternates x2.5 / x3 (not affine), so only an inequality invariant can work; exact epoch map unknown.
  • ▲Resisted mxdys's FractalType7 LLM batch; template is 7 transitions away, so new Column lemmas, not copy-and-modify.
