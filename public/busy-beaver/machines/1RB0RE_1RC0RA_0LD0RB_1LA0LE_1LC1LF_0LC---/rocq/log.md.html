Design as built (differences from the plan)

  • krec = (w : sd, b : N, c : N); the counter word is kept as a run-length side (no flat word, no re-encoding). kden (w,b,c) = K (sdn w) b c; kcfg pushes the boundary 0 onto w and builds the bell as 4 runs.
  • Batch: split 16 w takes up to 16 clean digits from the low end (pop3 pops a whole 3-cell block from a run; past the end of w the 0inf tail gives D0 digits, so padding is automatic), propose = min b (maxv - val D), addn adds n digit by digit (Z, small numbers), pushd pushes the new digits back with block merging; push_block drops all-zero blocks pushed onto an empty side (u^^n *> 0inf = 0inf).
  • rounds needs no bound hypothesis: val ds' <= maxv |ds'| (val_le_maxv) gives it; n = 0 by val_inj.
  • Eat: urun 1 (first K-form with b >= 1); oracle round: urun 0. FUEL = 65535 (max needed 12,954).
  • pop skips empty blocks / zero counts (sound for any sd), push folds 3 singletons into a following equal run and 6 singletons into a run of 2 (as the Python mirror).

Call-only variant (fallback, not in the kill file): dev/W55b.v

  • For a simulated round with b >= 1: enter (E1, F0) + simulate only the counter call from (C, w, ([0],1) :: bellsd b c, DL) until state B, DR with the right side syntactically back to the start (sd_eqb), then round_sim (= enter ; call ; bellpart). Gives up (CFail) when the right side equals the bell alone (the head crossed the boundary, e.g. a counter overflow), then falls back to the full urun 0. Compiles (2.0 s, -native-compiler no).
