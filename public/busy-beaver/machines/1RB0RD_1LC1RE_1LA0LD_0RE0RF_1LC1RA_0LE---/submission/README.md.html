Mechanism

  • Counter and register. Left of the head is a binary counter in the words W0 = 001 and W1 = 111 (W1 W0 = digit 0, W1 W1 = digit 1, a lone W0 a separator). Right of the head is the register 1 (011)^n 01. Each increment is one bounce and adds one 011.
  • Shift-overflow. When the counter is full after c increments, the overflow re-reads it shifted by one word, and the register becomes (c−1)/2 new zero digits. So c grows like 2 to the power of the previous c: cycle 2 already makes a block of 654,311,423 pairs.
  • The halt. From the blank tape the machine runs 194 cycles. In the 195th overflow, an increment inside the re-read carries off the far end of the counter, and 1,368 steps later F reads a 1.

How the proof works

  • Rules. TM3's rules (LInc_spec, LOv_spec, Incs, Ov, the lpow block lemmas) are proved again on this table with TM3's own scripts, after renaming the two head notations.
  • Abstract lists. Blocks W10 l / W11 l stand for (W1 W0)^(1+l+n) / (W1 W1)^(1+l+n) with a lower bound l. step_rec is one cycle on abstract lists, and step_rec_spec proves it sound.
  • The run. init reaches the first abstract configuration in 38,573 steps (solve_init). final_check_ok : final_check 192 = true (vm_compute) runs 192 cycles, the last Incs, and a checker on the final counter.
  • The halt. Doomed x says the overflow run from Lmp x halts for every right part. Two walk lemmas (19 and 12 steps, es) carry it through separators, pairs and blocks, from the 13-token far tail (far_halt, 1,368 steps, solve_halt).
