Notation (TM3's, in our state names)

  • Left part = counter Lmp x: a list of words, W0 = 001, W1 = 111 (paper order), x[0] next to the head.
  • Parsing from the head: W0 = separator; W1 b = a digit pair with bit b (W1 W0 = 0, W1 W1 = 1). Least significant digit next to the head.
  • Right part RC n = 1 (011)^n 01 0^inf. TM3's l <| r = l <D 010 r; l |> r = l A> r.
  • P-config: Lmp x <D 010 RC 1.

So one cycle is P x → P y with y = (W1 W0)^((c−1)/2) · W1 W1 · LOv(ones(x))[1:]: the counter fills, the right part's length becomes (c−1)/2 new zero digits, and the counter is re-read with a shift. c grows like 2^(previous c): shift-overflow.

Cryptid check (ground rule 6)

Not a cryptid: the fate is decided by a finite deterministic computation on lists (194 cycles, list ≤ 38,502 items) that ends in a halt. The far tail looks irregular, so there is no closed-form invariant, but none is needed for a HALT proof.
