Lemma R (relabelling). For a configuration c, let σc be c with its head state renamed by σ; the tape and head position stay the same. Then c → c′ under #33 if and only if σc → σc′ under this machine, and c is halted exactly when σc is (F1 is the only undefined cell, and σ fixes F). So every #33 run c →ⁿ c′ gives a run σc →ⁿ σc′ here, of the same length, and conversely.

3. The argument (complete)

Theorem. 1RB0LD_1RC0RE_1LD0RE_1LA0LA_1RB1RF_1RB--- does not halt from the blank tape.

  1. Initial segment. The machine runs from c0 to K((1,1,9); 8, 1) in exactly 687 steps without halting. This is a finite exact computation (§C); in Rocq it is solve_init.
  2. Base. INV([(1,1,9)], 8, 1) holds, in class A (§2).
  3. Transfer. P§3.2 (coverage) and P§3.3 (closure): every INV state has a macro step M or O, of at least 32 machine steps, to an INV state. These statements are about the triples and a, b, and the macro steps are #33's rule instances K → K′. By Lemma R, each such instance is a run σK →⁺ σK′ of this machine of the same length. So coverage and closure hold verbatim for the configurations K_D = σK.
  4. Conclusion. By induction from the base, the run is an infinite chain of macro steps, each of at least one machine step, so it never halts (progress_nonhalt_cond with P := INV, as in P§5). No macro step presents the halting cell: each is an exact computation from one K to the next, composed of window lemmas in which F reads only 0. ∎

Nothing in #33's argument after its init depends on #33's own orbit. The orbit statistics in P§7 (class counts, drop counts, overflows) are evidence, not premises.
