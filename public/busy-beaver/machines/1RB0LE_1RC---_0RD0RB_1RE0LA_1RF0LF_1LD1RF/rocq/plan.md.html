Print Assumptions nonhalt lists exactly the four open statements (plus functional_extensionality_dep). So the remaining work is exactly those four.

The round lemma, as stated:

tail_round current previous zs last k lv :
  tail_round_pre current previous zs last k lv ->
  ~ tail_triggers k last lv ->
  exists zs' last' lv',
    post_ca_tail (round_post_unary current previous)
                 (round_primary_width current previous) zs last k lv
    -[tm]->+
    post_ca_tail (round_post_unary next current) (round_primary_width next current)
                 (z_column previous :: zs') last' (S k) lv'
    /\ tail_round_pre next current (z_column previous :: zs') last' (S k) lv'
    /\ length last' = pred (length last)
    /\ eff_level last' lv' = k + 1 - eff_level last lv
  where next = tail_next_index current previous zs last lv

The parameters round_post_unary, round_primary_width and z_column are SOBCv10's own. The layout is SOBCv10's post-C/A word with the last column split off as a signed-digit word, followed by U^(2k+1) y.

The precondition tail_round_pre is a draft: SOBCv10's column safety, head parity and width dominance, a value window for the last column, k ≤ 4 and lv ≤ 5. It holds at the entry by hand, and it is consistent with the four rows of proof.md section 4. Fixing it exactly is the first task of stage R1.

Induction and proof shape

  • Rounds. No infinite induction: exactly three tail_round uses plus one tail_round_trigger, chained in sobc_D_nonhalt (already proved). Inside a round, the structural inductions are SOBCv10's: on the column list (frontier counts, mixed_columns_spec) and on digits (bfinish_spec, standard_mixed_to_binary_out_spec).
  • Signed last column. New induction on the signed digit list for the frontier count and the decode, generalizing bfinish_count.
  • Opening. Inductions on the family parameters m and p, as in SOBCv10's sobc1_* opening lemmas. The run itself is never simulated (exception 4 alone is 3.2·10^9 hashes).

Risks

risk where mitigation
