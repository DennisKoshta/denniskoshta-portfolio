Lemma R (relabelling). For a configuration c, let ρc be c with its head state renamed by ρ; the tape and head position stay the same. Then c → c′ in the parent if and only if ρc → ρc′ in the twin, and c is halted exactly when ρc is. So every parent run c →ⁿ c′ gives a twin run ρc →ⁿ ρc′ of the same length, and the converse also holds.

Start. The twin's c0 is 0^inf A> 0^inf = ρ(0^inf B> 0^inf). - The parent's own run starts in A. After one step (A0 = 1RB) it is at 0^inf 1 B> 0^inf. - So the twin's run is the parent's machine run from 0^inf B> 0^inf: the parent's run without the 1 its first step writes. It is not the parent's run. - §S checks the twin from blank against the relabelled parent from 0^inf B> 0^inf in lockstep: identical at every step for 2·10⁶ steps.

Halting cell. Only B1 (1RF) enters F in the twin, and only A0 (1RB) enters B. So the twin halts exactly when it reaches A> 0 1 1, which is ρ of the parent's B> 0 1 1.

3. The argument (complete)

Theorem. 1RB0RD_1RC1RF_1LD0LE_1RA0LC_1RE1LC_0RA--- does not halt from the blank tape.

  1. Initial segment. The twin runs from c0 to B′ in exactly 38,732 steps without halting. This is a finite exact computation (§C, §D); in Rocq it is one esx.
  2. Base. INV+(e)(B′) holds (§2).
  3. Transfer. - The parent's period theorem (P§3.8.1, proof P§3.8.4) says: from an E-start satisfying INV+(e), every K up to the next E-start is in D, INV+(e) holds again there, and there are at least two macro steps, each of at least one machine step. - Its statement and proof use only the rules of P§2 and arithmetic on (h, P, T). By Lemma R, each rule instance K →⁺ K′ of the parent is a twin run ρK →⁺ ρK′ of the same length. - So the theorem holds verbatim for the twin's configurations ρK.
  4. Conclusion. By induction from B′, the twin's run is an infinite chain of rule applications, each taking at least one step, so it never halts. - This is the parent's P§3.1 reduction with K0 and B replaced by K0′ and B′. - A rule application never presents the halting cell A> 0 1 1, because each rule is an exact computation from one K to the next. ∎

L* = 3 is inside the theorem's scope. The theorem assumes INV+(e), whose clause (d) is L* ≥ 3, so B′ meets it with equality. The proof uses the size of L* in three places, and each holds at L* = 3: - P§3.8.4 Step 2 and (d): M = L* + 1 ≥ 4 pairs at the L-start, so pairs 1 and 2, the x-pair and the last pair are distinct; - P§3.8.3: the pair-1 and pair-2 budgets need L* ≥ 2; - P§3.8.4 (e2): needs L* ≥ 2.

Nothing in P§3.4–3.8 assumes L* ≥ 4. The parent's own evidence tested this case directly: - its §G3 exhaustive boxes include "reg L*=3" and "T2 L*=3" at the thresholds; - its G4 random chains start at L* = 3..40.

This file adds §N, 5,000 random L* = 3 starts around B′. In Rocq, Jstep is proved for every J state, and B′ satisfies J (§2).

Nothing in the parent's argument depended on the parent's own orbit beyond P§3.7. The orbit-specific statistics in P§3.3 and P§5 (r values, merge counts, X1 count) are evidence, not premises.
