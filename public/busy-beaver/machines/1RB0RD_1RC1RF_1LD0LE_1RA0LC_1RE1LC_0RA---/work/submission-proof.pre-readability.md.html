Lemma R (relabelling). For a configuration c, let ρc be c with its head state renamed by ρ; the tape and head position stay the same. Then c → c′ in the parent if and only if ρc → ρc′ in this machine, and c is halted exactly when ρc is. So every parent run c →ⁿ c′ gives a run ρc →ⁿ ρc′ of this machine of the same length, and the converse also holds.

Start. This machine's c0 is 0^inf A> 0^inf = ρ(0^inf B> 0^inf). - The parent's own run starts in A. After one step (A0 = 1RB) it is at 0^inf 1 B> 0^inf. - So this machine's run is the parent machine run from 0^inf B> 0^inf: the parent's run without the 1 its first step writes. It is not the parent's run.

Halting cell. Only B1 (1RF) enters F, and only A0 (1RB) enters B. So the machine halts exactly when it reaches A> 0 1 1, which is ρ of the parent's B> 0 1 1.

3. The argument (complete)

Theorem. 1RB0RD_1RC1RF_1LD0LE_1RA0LC_1RE1LC_0RA--- does not halt from the blank tape.

  1. Initial segment. The machine runs from c0 to B′ in exactly 38,732 steps without halting. This is a finite exact computation; in Rocq it is one esx (init).
  2. Base. INV+(e)(B′) holds (§2).
  3. Transfer. - The parent's period theorem (P§3.8.1, proof P§3.8.4) says: from an E-start satisfying INV+(e), every K up to the next E-start is in D, INV+(e) holds again there, and there are at least two macro steps, each of at least one machine step. - Its statement and proof use only the rules of P§2 and arithmetic on (h, P, T). By Lemma R, each rule instance K →⁺ K′ of the parent is a run ρK →⁺ ρK′ of this machine of the same length. - So the theorem holds verbatim for this machine's configurations ρK.
  4. Conclusion. By induction from B′, the run is an infinite chain of rule applications, each taking at least one step, so it never halts. - This is the parent's P§3.1 reduction with K0 and B replaced by K0′ and B′. - A rule application never presents the halting cell A> 0 1 1, because each rule is an exact computation from one K to the next. ∎

L* = 3 is inside the theorem's scope. The theorem assumes INV+(e), whose clause (d) is L* ≥ 3, so B′ meets it with equality. The proof uses the size of L* in three places, and each holds at L* = 3: - P§3.8.4 Step 2 and (d): M = L* + 1 ≥ 4 pairs at the L-start, so pairs 1 and 2, the x-pair and the last pair are distinct; - P§3.8.3: the pair-1 and pair-2 budgets need L* ≥ 2; - P§3.8.4 (e2): needs L* ≥ 2.

Nothing in P§3.4–3.5 or P§3.8 assumes L* ≥ 4. The case L* = 3 was also checked numerically, for the parent's abstract map and for starts near B′ (§6). In Rocq, Jstep is proved for every J state, and B′ satisfies J (§2).

Beyond the initial segment and the base (P§3.7, and the base checks in P§3.3 and P§3.8.1), nothing in the parent's argument depends on the parent's orbit. The orbit-specific numbers quoted in the parent's write-up (r values, merge counts, X1 counts) are not premises.

4. How this orbit relates to the parent's (explanation, not a premise)

No coupling. Two other holdout machines have the same table up to renaming and mirroring: 1RB1RF_1LC0LE_1RD0LB_1RA0RC_1RE1LB_0RD--- (the table started in the parent's C) and 1RB0RE_1LC0RA_1LD0LB_1LA1LF_1LE1RA_0LC--- (mirrored, started in the parent's D). At every macro step their K is the parent's K with one far exponent larger, by +2 and +1 respectively. This machine has no such coupling: - B′ differs from B everywhere but h. At 10⁹ steps this machine's tape spans 79,454 cells (−79,241..212), with 39,718 nonzeros. The parent's spans 67,343 cells, with 33,665 nonzeros, so this tape is 18% wider.

Same macro map, same behaviour.
