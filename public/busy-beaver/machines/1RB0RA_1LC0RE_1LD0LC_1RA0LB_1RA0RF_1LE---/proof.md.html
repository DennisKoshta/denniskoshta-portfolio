This machine is W4-3, 1RB0RF_1RC0RB_1LD0RA_1LE0LD_1RB0LC_1LA--- (the parent), with its states renamed. It starts in the parent's state B instead of A. So it runs the parent's transition table, only from a different start.

1. The renaming

Write σ for the map from the parent's states to this machine's states, and φ for its inverse:

sigma:             A -> E,  B -> A,  C -> B,  D -> C,  E -> D,  F -> F
phi = sigma^-1:    A -> B,  B -> C,  C -> D,  D -> E,  E -> A,  F -> F

Row σ(q) of this table is the parent's row q, with every target state t replaced by σ(t). Symbols and directions are unchanged, so there is no mirror.

this state 0 1 = σ(parent state) parent 0 parent 1
A 1RB 0RA σ(B) 1RC 0RB
B 1LC 0RE σ(C) 1LD 0RA
C 1LD 0LC σ(D) 1LE 0LD
D 1RA 0LB σ(E) 1RB 0LC
E 1RA 0RF σ(A) 1RB 0RF
F 1LE --- σ(F) 1LA ---

For example, the parent's C1 = 0RA becomes 0Rσ(A) = 0RE, which is this machine's B1. Among all 720 renamings, with and without the mirror, σ is the only map from the parent's table to this one.

Lemma R (relabelling). For a configuration c of the parent's table, let σc be c with its head state renamed by σ; the tape and the head cell stay the same. Then c → c′ in the parent's table exactly when σc → σc′ here. And c is halted exactly when σc is, since F1 is the only undefined cell of both tables and σ fixes F.

Start. This machine starts from 0^inf A> 0^inf, which is σ of 0^inf B> 0^inf. So its run is σ of the parent's table run from state B, step for step.

Halting cell. Here only E1 = 0RF enters F, and the machine halts only when F then reads 1. E1 is σ of the parent's A1 = 0RF, which occurs only in the wiggle of P§2.2. So a halt here is σ of the parent's halt: a rightward d = 1 event at a defect e with e + 1 also a defect.

From here on, configurations are written in the parent's state names. In particular the head state at a record exit is the parent's B, which is this machine's A.

3. The invariant holds at record exit 28

Record 28 has class r5 and epoch e = 2, so u = 9^(e-2) = 1 and K = K0(r5) + 2e = 3 + 4 = 7. Take the four parts of C_r5(2) in P§3.3 in turn.

(L) Left word. lo = A - 34, and the defects left of A are exactly the ten of 2.3. Also λ = lo + 1 = -93 is the leftmost cell that has ever held 1, so this lo is the parent's lo.

(C) Chain. The defects in [A, B] are 4K - 2 = 26 defects forming K = 7 blocks in U0, with block 1 = (A+2; A+3) and the last separator at B - 2. Every gap has the residue and at least the smallest value of its role:

inter gaps      5, 5, 5, 9, 37, 2737                           all 1 mod 4, all >= 5

Consecutive bases then differ by 2 mod 4, as (C) requires.

(W) Window. J(r5) = 3. The last three chain gaps and the right region are V_r5(1) of P§3.4:

(H) Head. The head is on cell B - 1 in state B, the cell holds 1, and state B moves right.

4. The argument

Theorem. 1RB0RA_1LC0RE_1LD0LC_1RA0LB_1RA0RF_1LE--- does not halt from the blank tape.

  1. Opening run. By Lemma R, the run of this machine is σ of the parent's table run from 0^inf B> 0^inf. That run reaches record exit 28 after 2,629,088,387,088 steps without halting (section 2).
  2. Base. Record exit 28 is in C_r5(2) (section 3).
  3. Induction. Lemma S (P§6) is the step:

C_r(e) -->+ C_(r+1)(e) for e >= 2, without halting C_r4(e) -->+ C_r5(e + 1)

Its only hypothesis is the invariant (P§7 for the halting part). The deep chain enters only through the residues and minimums of (C). 4. The deep chain is free. The parent's formal proof states Lemma S this way. Its invariant Inv lists the chain as gap variables, and the deep part of that list is arbitrary (P§10.3). 5. Conclusion. So the parent's table, run from B, passes through infinitely many record exits and never halts. By Lemma R this machine does the same, with its states renamed. ∎

Nothing in the parent's argument after its base case depends on the parent's own orbit. Its base case (P§8) and its twelve concrete steps 16 → 28 are not used here: the configuration at record exit 28 is reached directly.

5. Why the runs agree so closely (explanation, not a premise)

The record exits 16 to 27 of this start are in C_r(e) too, with exactly the parent's start-up windows (the values of the parent's Appendix C). In fact, at every record exit from 12 on (the earliest checked) the two runs differ in only one gap, 4 cells longer here.

At every record the new left digit joins the chain, so the parse moves one defect along. The extra 4 cells stay in one physical gap, whose index in the chain grows by one per record:

  • at record exit 12 it is the 10th gap from lo, among the first defects of the tape (records 12 to 15 are not yet in the invariant's form, which starts at record 16);
  • at record exit 16 it is the digit gap of block 2 (K = 3);
  • at record exit 28 it is the digit gap of block 5 (K = 7).

Its role cycles digit → separator → separator → inter → digit. The regrouping offsets of P§6.2 change it in the same way in both runs, so the difference stays exactly 4.

Over an epoch K grows by 2, so the chain gains 8 gaps, while the gap moves 6 places. It falls further behind the right end of the chain and stays in the deep part, where only residues and minimums matter. This is an observation (checked at record exits 16 to 28, and to 33 with --full); the induction in section 4 does not need it.

The start-ups differ before that: λ moves at different steps (2.1), and the extra 4 cells first appear somewhere before record exit 12.
