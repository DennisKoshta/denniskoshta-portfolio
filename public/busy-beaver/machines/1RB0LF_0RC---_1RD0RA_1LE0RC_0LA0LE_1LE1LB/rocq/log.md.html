Key reductions / lessons

  • T(f) table (16,384 entries) is unnecessary: the return is retf, a 4-rule token transducer (E/PZ->TZ, E/P->T0 flip to F, F/P->T1 flip to E, F/PZ/P with a 0 ahead -> FPZP two-token eat). tail_ret in rocq/py/tok.py matches the real per-first-zero-position behavior for all 14 slot positions + the 5 ENDCARRY growth cases.
  • retf_spec needs induction on a nat length bound, not structural induction on the token list, because FPZP consumes two processed tokens at once.
  • follow Bnc then finish: the first token-peeling rewrite block already normalises the RHS too, so the A-form target closes by reflexivity.
  • Tokenisation convention: right of the lead the tape is a word over T0=00, T1=01, TZ=100; processed tokens are P=(10), PZ=(010). (001)^a 00 = 00 (100)^a so the normal lead reads as T0::TZ^a.
