Mechanism

How it works: 3 notes
  • Tape: (01)^n runs split by single defects (11, 00, 1111); the head zig-zags between them; the wall grows 2 cells/bounce.
  • Defect groups drift left from the right edge at exact speeds 1, 3/4, 1/2, 3/8...; left block repeats every 16 bounces.
  • The right edge is chaotic (hi ~ 20·sqrt(L)). Halting needs E to sweep an odd (10) run ending in 00: unseen to 1e11.

Proof strategy & riskshow the formal proof will go · 3 risks to watch

BLv3-style. 1) es/ind for sweep/wall/edge rules; 2) the 16-bounce left-block rule with a odd, b,c even (multistep_nonhalt + progress_nonhalt_cond on n); 3) the hard part: a closed (regular) set for the edge region that excludes 'E> 10^odd 001' (LongN/InfiniteRect quadRect, or a CTL-style language search first).

  • ▲Edge is chaotic and growing (hi ~ 20*sqrt(L), 56 groups at 1e9): a finite closed set may not exist -> STUCK at step 3.
  • ▲Halting is a parity event (odd (10) run before a 00 defect); a late halt like BLv2's 3 kills is possible. None to 1e11.
  • ▲On mxdys's UBRRBA_TODO list (Dennis: fair game); twin #27 is this exact table started in state E, so one proof should cover both.
