0. Summary

  • Hub. The tape is 0^inf (110)^a 0 (011)^b B> X 0^inf. A bounce moves the marker 0 one block to the right, applies the local pass LP to the counter word X (a binary +1 when X is a clean counter), and spends one 011 of the budget b.
  • Eat. At b = 1 the machine eats the lowest digit of X. An a-block eat gives new budget. A b-block eat, or a bare tail, sweeps the (110)^a run into a new left record 0^inf <E 101 (001)^k 000 Y.
  • Epoch. The next epoch starts at K(1, k+1, Y), where the residue Y is not a clean counter. Its first bounces digest it. The digestion is recursive: at a b-block, one bounce runs a whole sub-epoch on the rest of the word (D6).
  • Where halting is. The machine halts only if an eat happens before the digestion is done. #30's invariant Inv bounds the digestion cost by a constant times about 2^(k/2), against a budget N ≳ 2^(k+3). It is closed for N ≥ 17,705.
  • This machine. From the blank tape, W4-1 reaches K(1,3,t1) at step 55. The rules-only model then runs 691 epochs to K(1, 17712, Y691), where Inv 11 holds. From there #30's inv_step carries the invariant forever.
  • The two orbits merge (not used in the proof). The model orbit of W4-1 and the one of #30 are different until epoch index 795 of both, at N = 20,922, and identical from then on [C]. Before that, W4-1's orbit is another orbit of the same macro map.

Lemma S (renaming). Let σ map #30's states to W4-1's: A→E, B→A, C→B, D→C, E→D, F→F. Then for every state q and symbol r, W4-1's cell (σ q, r) is #30's cell (q, r) with the target state renamed by σ. This holds for all 12 cells, the halting cell included [S1]. - Equivalently, with φ = σ⁻¹ (A→B, B→C, C→D, D→E, E→A, F→F), busycoq's Perm tm tm30 φ holds (Permute.v). That is, W4-1's (q, s) is undefined iff tm30's (φ q, s) is, and tm (q,s) = Some (s', d, q') iff tm30 (φ q, s) = Some (s', d, φ q') [S2]. - Consequence: the W4-1 run from (q, t) is, step for step, tm30's run from (φ q, t) with the states renamed. The tape and head positions are the same. Since φ A = B, W4-1 from the blank tape is tm30 from 0^inf B> 0^inf. This is checked for 2·10^6 steps [S5].

The only halting transition is C reading 0 (#30's D0) [S3]. In busycoq a configuration is halted when no transition is defined for it, so the machine halts exactly when it is in C reading 0. C is entered only by B0 = 1LC [S4], which moves left. So one step before, the machine is in B reading 0 with a 0 in the cell to its left (the pattern 0 B> 0). B is entered only by A0 = 1RB, which leaves a 1 to B's left, and by F1 = 0LB [S6]. So the halted configuration comes exactly two steps after a configuration 0 0 F> 1: F1 gives 0 B> 0 0, then B0 gives C reading 0, the only undefined transition [S7]. An exhaustive check over 5-cell windows confirms that this is the only way to be in C reading 0 after two steps [S8]. (Under the convention that also counts the halting transition as a step, it is three steps.)

2. Notation, words, families

  • Configurations use the busycoq/wiki notation. In l q> r the head is in state q and reads the first symbol of r. In l <q r it reads the last symbol of l. Sides are written in reading order (left to right).
  • Chunks: a = 001, b = 101, z = 000. A block is d01 a^e, an a-block if d = 0 and a b-block if d = 1, with exponent e ≥ 0.
  • Words are #30's .v type word: t0..t3, blk d e w = d01 (001)^e 000 w, p11 x w, p01 x w, p00 w, p10 w. enc w is the cell string followed by 0^inf. Two words with the same enc are the same tape. Examples: p10 t0 ≡ t1, p00 t0 ≡ t0, p10 t1 ≡ blk true 0 t0, p00 t1 ≡ blk false 0 t0.
  • Counter words G: gw bs s for a block list bs and a tail t_s (s ≤ 3). There are k = |bs| blocks, LSB first.
  • The value is gval bs s = (4+s)·2^k + Σ d_i 2^i, which lies in [4·2^k, 8·2^k).
  • ginc is binary +1 on the value. Tails step t0 → t1 → t2 → t3, and t3 → blk false 0 t0 is the overflow (d = 1).
  • Residues: an ordinary residue is p11 x (gw bs s). A special residue is one of t1, p01 1 t1 or p10 (p00 t2).
  • Families (W4-1 names):
  • hub K(a, b, w) := 0^inf (110)^a 0 (011)^b B> enc w. The 0 after (110)^a is the marker. The .v's K N y is K(1, N, y).
  • pre-record P(k, y) := 0^inf <D 01 (001)^k 000 enc y. Here D reads a blank.
  • left record L(k, T) := 0^inf <E 101 (001)^k T. It is one step after P(k, y), with T = 000 y (D0 = 1LE).

5. Invariant, inductive step and progress (independent of the start)

5.1 Domain: Inv k N y (#30's .v, Section 11)

Weights and bounds: - w(q) = 2^⌊(q+1)/2⌋, v2(q) = 2^⌊q/2⌋, p2(q) = 2^(q+1); - Ws(P) = Σ_{q<P} w(q), V2s(P) = Σ_{q<P} v2(q), Pf(k) = max(12, k+3); - Af(k) = 5 Ws(Pf k) + 6 w(Pf k) + 2 Ws(k); - Bf(k) = Af(k) + 5 V2s(Pf k) + 6 v2(Pf k) + 2^(k+1); - Xf(k) = Af(k) + 5 Pf(k) + 7; - Costf(k) = 2 Xf(k) + 2 + 2 Af(k) + 11 Ws(Pf k) + 13 w(Pf k); - Nlo(k) = 2^(k+3) − 8·2^⌊(Pf(k)+3)/2⌋, and Nstar = 17,705.

For a block list bs with exponents e_q at positions q, let Mw(bs) = Σ_q w(q) e_q and M2(bs) = Σ_q p2(q) e_q.

Inv k N y holds iff all of these hold: - N ≥ 17,705; - N ≥ Nlo(k); - y is special (t1, p01 1 t1 or p10 (p00 t2)), or y = p11 x (gw bs s) with s ≤ 3, |bs| ≤ k, Mw(bs) ≤ Af(k), M2(bs) ≤ Bf(k) and x ≤ Xf(k).

5.2 Inductive step: inv_step : Inv k N y → ∃ kk y', Phi 1 N y kk y' ∧ ∃ k', Inv k' (S kk) y'

The proof (#30 .v Sections 7–11; written out in #30 submission/proof.md §8.3) has these steps: 1. Positions (N1). 7·2^k + Bf(k) < 2^(Pf(k)+1) for every k. The Q potential 2^f·(m + 2Σ 2^i(e_i+1) + p) never exceeds its start value plus 3·2^(f+n), and it starts below 7·2^k + M2(bs). So no digestion creates a counter position ≥ Pf(k) (QI_Ps). 2. Digestion exists. DigT_exists gives DigP x bs s n c bsp sp: the residue reaches the counter word gw bsp sp in n own-level bounces with c absorptions. The constructors are the prefix (2x+2 bounces), LP_5 at an a-block, LP_6 at a b-block (sub-epoch GPhi, then the next level nested in the new block, LPs_nest), and the end chains DigE. 3. Cost (N2, Lemma D). Dig_cost gives n ≤ 2 Mw + 2x + 2 + 11 Ws(P) + 13 w(P) ≤ Costf(k). Also Costf(k) + 2 ≤ 17,705 for k ≤ 11, and Costf(k) + 2 ≤ Nlo(k) for k ≥ 12. So n + 2 ≤ N: the digestion ends inside the budget, and every eat of the epoch is at a G word. 4. Counting ends. gcount: the potential Ψ = value + budget + Σe − #blocks never grows at a bounce and drops at every E1. So the counting phase GPhi (1+n) (N+c−n) bsp sp r reaches E2, E0, Et1, Et2 or Et3. epoch_ord composes everything into Phi 1 N y (rk r) (ry r). 5. Invariant again (next_inv). Dig_mass is used three times: weights (2w(ℓ−1), w), (2^ℓ, v2) and (1, 1). With Dig_len, GPhi_rel and GPhi_val, they give Mw(W') ≤ Af(k'), M2(W') ≤ Bf(k') and x' ≤ Xf(k'), with k' = max(k, k(W')). - If k(W') > k, the value bound gives 2^(k(W')+3) ≤ N' + 8·2^⌊(Pf+3)/2⌋, i.e. N' ≥ Nlo(k'). Otherwise N' > N ≥ Nlo(k). - A special residue digests by an end chain: at most 13 bounces, 5 absorptions and one block with e = 0.

inv_step is a statement about words and Phi. It is proved once for all k, N, y, so it applies to W4-1's orbit unchanged. As a sanity check, [J] runs the model on from epoch 691 to epoch 1,200 (N = 33,240). On every epoch, Inv κ_t N_t Y_t holds with κ_t the running maximum of k(W), which is the choice next_inv makes.

5.3 Progress

  • Each epoch is K(1, N, y) -->+ K(1, kk+1, y') (epoch_tm). This is at least one step; in fact at least 3·kk + 8, from Rst alone.
  • Also kk + 1 ≥ N + 1, since a + b ≤ S (rk r) (GPhi_rk). So N strictly grows. Progress itself only needs -->+.
  • progress_nonhalt_cond with P(N, y) := ∃ k, Inv k N y on the configurations K(1, N, y) gives non-halting from any configuration where P holds.
