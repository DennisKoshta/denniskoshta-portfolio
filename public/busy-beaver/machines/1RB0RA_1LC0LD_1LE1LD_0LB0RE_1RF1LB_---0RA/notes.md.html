A round is INC + marker one block left, about 8n+16 steps. - Counter = binary in 3-cell digits. The carry walk goes left one cell per state: E reads a digit, then B and C read the two filler cells. - E1 = 1LB, B0 = 1LC, C0 = 1LE: so 001<E -> <E111, a digit 1 carries. - E0 stops the carry, and A sweeps back right clearing the 1s. - A block 010 is walked as B0 C1 D0, so carries skip it (filler). - This is where tm10's 1-cell digit (HL2: E1 = 1LE) changes. - Eats. When the marker reaches the counter (n = 0), the case depends on b and the low end of W (EAT0f / EAT0z / EAT1). - EAT0z and EAT1 absorb the marker. They also move every counter block one cell right: phi: 1->f (100->010), 0->0, f->s (010->001). The marker is then reborn at the right end (BIRTH), and the next epoch lasts about n = m+1 rounds. - Read from b in phase 0, a phi-shifted word reads f as filler, 0 as digit 0 and s as a phase shift. So a new counter starts at 0 in the low part, and the old value sits left of the first s as debris (phase C: f=1, 0=0, s=filler). - A carry that reaches an s runs a second pass (the A clean-up hits a 0 and restarts a walk, then an E-walk crosses the unary and back). The net effect is CARRY_S: X s Y -> inc(incC X) f Y0, recursive if inc meets another s. - Epochs late in the run (1e10): about 3,800 rounds each, unary growing by 1-4 blocks per epoch. W has about 20 blocks, e.g. 1 1 1 0 1 1 0 1 1 f f f 0 f…. The eats seen are EAT0f 498, EAT1 495, EAT0z 73.

What was done. I worked out the flush exactly on the abstract round system (the 9 validated rules), proved it for every case but one, and narrowed the open part to one arithmetic case. Notation. - At a phi-eat (EAT1 or EAT0z), U is the s-free word before the shift: inc W for EAT1, W' for EAT0z. Then V = phi(U), and N is the new n (the epoch length in rounds). - d = number of digit blocks (0/1) of U; val(U) = its phase-0 value (f skipped); v(W,b) = 2 val(W) + b. - The f-runs of U are (e_i, p_i), where p_i = digits right of run i. r is the leftmost run, Q = p_r. - X = val(U) + sum_{i<r} e_i 2^p_i, and PC = X + e_r 2^Q.

Lemmas (short proofs, all checked below): - L0. (I2) holds at every round start: phi outputs no 1, and inc puts its 1 right of every remaining s. So incC only ever sees {f,0,s}. - L1, flush counter. While s blocks remain, the part right of the rightmost s (with b) has phase-0 value t = the number of increments since the phi-eat. - Proof: it starts at 0, since phi outputs no 1. CARRY_S, unrolled over a run of e s blocks, is X' s^e Y -> inc(incC^e X') f^e Y0. inc puts its 1 at the lowest 0 of the segment just left of the run, or recurses into the next run, which is bit position t either way. - L2, flush time. F = 2^(1+D_F), with D_F = Q - popcount(X mod 2^Q). So F <= 2^(1+Q). - Proof: in phase C the non-s blocks of V read as U's digits. Clearing run i adds e_i at bit p_i, and inc and Y0 leave the phase-C reading unchanged. So the digits right of the leftmost run when it clears are the zero bits of X mod 2^Q, and by L1 it clears at t = 2^(1+D_F). - L3, after the flush. v(W,b) = t = m. The filler/digit pattern on U's digit positions (plus any new top) is binary PC (1 = f), and the old f-runs stay f. - L4. v(W,b) <= m at every later round start of the epoch. INC/CARRY add 1 to both. EAT0f gives v' = 2 val(W') + d < v and m' = m + 2 + j. - L5, generic flush bound. If U starts with 1: F <= 2^(1+Q) <= 2^d <= 2 val(U) <= N. - For EAT1: 2 val(U) = v + 1 <= m + 1 = N. - For EAT0z: N >= 4 val(U). - L6. At an EAT0z phi-eat, N > m >= v >= 4 val(U) >= 2^(d+1) >= F, whatever U starts with. - L7, leading digit. If U_k starts with 1, then U_{k+1} has leading digit 1. After the flush, the capacity right of the leading f is C = 2^(1+zeros(PC)) <= 2 val(U_k) <= N_k, unless PC = 2^d exactly ("top exact carry"). In that case t still reaches C/2 = 2^d <= N_k, so the digit under the leading f is 1, and EAT0f right-shifts keep it. - L8. U_{k+1} starts with f only after an epoch with no overflow. When U_k started with 1, that requires a top exact carry.

Case analysis when U_k starts with f at an EAT1 (d = d_k): - (iii) X mod 2^d != 0: F <= 2^d <= N. - (iv-1) X = 0 mod 2^d ("bottom exact"), epoch k-1 had an EAT0f, and U_{k-1} started with 1: N_k > N_{k-1} >= 2^(d_{k-1}) >= 2^(d_k+1) >= F. - (iv-2) Bottom exact, epoch k-1 had no EAT0f, and U_{k-1} started with 1: impossible. The runs of U_k are those of U_{k-1} at the same positions and val(U_k) = (N_{k-1}+1)/2, so bottom exact forces N_{k-1} = 2 val(U_{k-1}) - 1, which contradicts L4. - (iv-3) U_{k-1} also started with f (a chain): OPEN. L7 inside a chain is open too. - Sketch for closing it: the chain's top run has e = 1, and the carry floor(X/2^d) is at most 1 at the chain's first step (because sum_lower = 2^d - val(U_{k-1}) < 2^(d-1)). Notation (new). - S1: U starts with a digit 1. S2: U starts with f. - sigma(U) = sum over the f blocks of 2^(digits right of the block). Lemmas (proved by hand on the abstract system, by induction on k, assuming F <= N for earlier phi-eats): - C0. N_{k+1} >= N_k + 1. If epoch k has no overflow, then 2^(Z_k) <= N_k. - U_k in S1: Z_k <= D_k by L9, because a number below 2^(D+1) with a 1 bit has at most D zeros. Also 2^(D_k) <= 2 val(U_k) <= N_k. - U_k in S2 with c = 1: the word after the flush is f 1 f ... and Z_k = 1 + zeros(P_k). So 2^(Z_k) = F_k <= N_k. - c in {0, 2}: the word after the flush starts with a digit 1 (1 f ... or 1 f f ...). So U_{k+1} is in S1 and C3 is not needed. - C4, shape. Every S2 word is f 1 ...: one leading f, then the leading digit 1, with c <= 2. - From S1, no overflow plus L9 force PC = 2^D (a top exact carry). F_{k+1} <= N_{k+1} whenever U_{k+1} is in S2. - tau_k >= 1: F_{k+1} <= 2^(1+D_{k+1}) <= 2^(Z_k) <= N_k < N_{k+1}, by C3 and C0. - tau_k = 0 and U_k in S1: this is the old iv-2 argument. Y_{k+1} = val(U_{k+1}) - val(U_k) mod 2^D, and val(U_{k+1}) = (N_k+1)/2 > val(U_k).
