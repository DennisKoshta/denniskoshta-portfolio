Halting pattern (from the table)

  • D is entered only from C0, so a halt needs C0 at x and a 1 at x+1.
  • C is entered from F1 (then C sits on the cell F came from; if it reads 0, D reads the 0 that F1 just wrote) or from B0.
  • B is entered from A0, D0 (B then reads the 1 that C0 wrote) or E0 (then C reads the 1 that E0 wrote).
  • So the only halting pattern is A> 0 0 0 1 (3 steps to the undefined D1). A is entered only from F0, so in practice F> 0 0 0 0 1.
  • Validated: 200/200 random contexts halt in exactly 3 steps.

Local rules (exact; scripts/validate.py, 200 random instances each with random left/right context words)

LS     L 1^(a+1) 0 1^b <E R   ->  L 1^a <E 0 1^(b+1) R    b+2 steps
WALL   L 0 0 <E R             ->  L 0 0 F> R              3 steps (also L = 0^inf)
RS3    L F> 0111^n R          ->  L 1011^n F> R           6n steps
RSodd  L F> 0 1^(2k+1) R      ->  L 1 01^k 1 F> R         4k+2 steps
RSeven L F> 0 1^(2k) 0 1 R    ->  L 1 01^k 1 <E 0 R       4k+3 steps
HALT   L A> 0 0 0 1 R         ->  halt                    3 steps

(01^k = (01)^k.) Reading in runs of 1s between single 0s: - the left sweep moves every 0 one cell left (it needs every run >= 1; a 00 or the left end turns it); - the right sweep moves every 0 one cell right through odd runs: run 1 merges with the next run, run 3 just shifts, run 5 splits into 1 + 3. So a bounce leaves a pure 0111 field unchanged and toggles a defect 11111 <-> 10111; - an even run (0, 2, 4) makes A read a 0, and the head turns left there: even runs are internal walls.

Wave 6, stage 1 (2026-10-14)

Goal: look for a CTL certificate first. If none turns up, build the run-length model and settle the cryptid question.

Result: cryptid candidate, confidence med. No CTL certificate was found. The wall dynamics are now an exact particle picture, and the halting route is known. The machine halts if two exact-timing coincidences occur, each between a wall birth at the left end and a wall arriving far to the right. Nothing in the data rules these coincidences out. Non-halting would need a hidden timing lock, and no regular (CTL-style) language can express one.

Particle picture (head is stateless between runs)

  • A bounce runs from one left-end E turn to the next. F always reaches a separator 0 in state F, and E always moves over 1s, so the head carries no state from run to run. One bounce therefore applies a fixed local transducer to the run sequence, from the left end up to the first even run, where F turns (RSeven). Everything to the right of the leftmost even run is frozen.
  • Defects are odd runs (1, 5, rarely 7 or 9). Each is a 2-cell phase slip of the 0111 field, and they drift 2 cells left per bounce (observe).
  • Walls are even runs (2, 4) and 00. Each is a 1-cell parity flip of the zero positions.
  • Only the leftmost wall moves. A lone 2 in a pure field moves exactly one run (4 cells) right per bounce: 324/324 (scripts/stage1/chain_checks.py).
  • Everything beyond it stays put. In the real run to 1e8, the tape more than 8 cells right of the leftmost even run was unchanged over the bounce in 86,698 of 86,704 bounces (frozen.c). The 6 exceptions are a wall of run length 8, which RSeven rewrites in place over more than 8 cells.
  • Annihilation. A moving wall that reaches a frozen wall annihilates with it into odd runs. Typical case: 3.2.2.3 -> 3.3.1.3, 414 of about 1,000 annihilations to 1e8.
  • Birth. Walls are born from defects that reach the left edge. In 1,306 of the 2,019 births to 1e8, the leading run goes from 1 to 2 (1.3.3.3.3.3 -> 2.3.3.3.3.3). Births happen on 2.2 % of bounces to 1e8, and that share falls later (see the estimate).
  • Right end. The emitter cycles through 3 states: .3.1.5.5.1.3:1, .5.1.3.1.4.1.1 and .5.5.1.3.1.5.5. A wall that reaches it in any state, form or offset is absorbed safely: 216/216.
  • The walls form a stack. Old frozen walls persist for 1e5 bounces or more (e.g. at -3171 and -1299 near 2e9). Growth and wall phases alternate irregularly: 398 of each to 2e9, and a wall phase that started at 1.87e9 was still open at 2e9 after 60,857 bounces (work/stage1/phases_2e9.txt).

The halting route

Halting needs F> 0 0 0 0 1, which in practice means an interior 000 that a wall then reaches.

The tape never has an interior 000 at left-end bounces. None in 773,707 bounces to 2e9 (pairs.c). To 3e10 (5,248,319 bounces, ones.c → work/stage1/ones_3e10.txt) there is still no interior 000, and a run 1 directly before a 00 (1:) occurred 11 times: 3 in the start-up transient and 8 between 1.24e9 and 2.24e10 (bounces 531,221 to 3,891,278). Every one of the 11 was the leftmost wall structure (no wall to its left).

The chain, with each link checked on synthetic tapes (chain_checks.py):

  1. A frozen 1: must exist: a run 1 directly before a 00 wall.
  2. A moving wall that reaches a frozen 1: turns it into an interior 000: 36/36 (forms 2, 4 and :; shifts 0-3; contexts 1:1, 1:3, 5.1:1). Control: the same with a run 3 before the 00 never does, 12/12.
  3. A moving wall that reaches a frozen 000 halts the machine within a few bounces: 105/105. If F reaches the 000 with no wall in front, it just dissolves it: 4/4, no halt in 200 bounces.

What happens in the real run. Each 1: so far was the leftmost structure, so F dissolved it on the next bounce. Example: 2.2:1 -> 3.1:1 -> 7:3 at steps 1,238,230,449 / 1,238,230,967 / 1,238,231,495. That matches chance: with births on about 1.1 % of bounces at those times, 8 episodes give 0.09 expected coincidences. For a 1: to stay frozen, a wall must be born at exactly that bounce. That wall must then reach the 1: before another birth intercepts it. When it makes the 000, another birth must happen at exactly that bounce, followed by another uninterrupted trip.

A real-tape check of half the chain. Start from the tape at step 1,238,230,449, with one change: the first run 3 becomes 1, i.e. a defect arrives one bounce earlier. Then 1:1 stays frozen, the new wall reaches it, and an interior 000 appears at bounce 52. Without the change there is no 000 in 3,000 bounces (chain_checks.py, real_tape_*).

The full chain on the real tape. Same start, but now with three edits, each of which only changes when a defect reaches the left edge:

  • before bounce 0: first run 3 -> 1, so wall W1 is born one bounce earlier;
  • after bounce 51: first run 3 -> 1, so wall W2 is born exactly when W1 makes the 000;
  • after bounce 86: first run 1 -> 3, which suppresses a natural birth that would otherwise intercept W2.

With these edits the machine halts at bounce 105. With only the first two edits, the natural birth at bounce 86 intercepts W2, and the 000 dissolves later without a halt.

No timing lock is visible. To 1e8, births and annihilations fall in the same bounce 14 times, against 22.7 expected if they were independent. Births 1-5 bounces after an annihilation: 14/20/13/14/24, against about 22 each.

Verdict and estimate

This is a cryptid candidate. Non-halting comes down to whether exact-bounce coincidences between left-end births and distant wall arrivals ever line up. That is pseudo-random timing rather than arithmetic, but the consequence is the same.

A crude estimate, assuming births are independent of everything else:

  • Birth rate. Births become rarer over time. As the share of bounces whose leading run turns even (births.c, windows of 500k bounces), the rate falls from 1.55 % (to 1.1e9 steps) to 1.2 % (around 1e10) and 0.54 % (around 2.8e10). That is roughly t^-0.33.
  • Per episode. A 1: at run index k completes the chain with probability about p^2 · e^(-2pk), where p is the birth rate and a wall moves one run per bounce. At the 8 real episodes (p ≈ 0.011, k = 11 to 238) this averages about 4e-5. Expected halts so far: 8 × 4e-5 ≈ 3e-4.
  • Episode rate. About 1.7e-6 per bounce (8 in 4.7M bounces). Bounces grow like t^0.71: 773,707 at 2e9, 5,248,319 at 3e10.

If the birth rate levels off near 0.5 %, the expected halt is around 1e16 steps. If it keeps falling like t^-0.33, the expected number of halts grows only like a tiny power of t: heuristically it still halts eventually, but astronomically late. Either way, a simulation hunt is unlikely to find the halt. A halt that far out also could not be certified with the runners we have (1e10 or more bounce-level macro steps).
