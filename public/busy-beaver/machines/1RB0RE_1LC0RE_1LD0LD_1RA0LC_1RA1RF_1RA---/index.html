How we proved it never halts

#11's proof in a mirror, from a different start

#11 is a binary counter whose digits burn a unit of fuel each time a carry touches them, and its proof is an invariant showing that a digit only ever runs dry where that is harmless. This machine is #11's table seen in a mirror, with left and right swapped and the state letters renamed, started in the state that is #11's D. So the same kind of counter runs with the head at the left end of the tape and a fixed marker, 1001, at the right.

The invariant talks only about the digits' lengths and values, never about direction, so it and its proof carry over word for word. Only the small tape lemmas that the two moves (add 1, and overflow) are built from had to be mirrored.

What is new is a 215-step opening. At step 82 the counter has no digits; an overflow of that empty counter creates the first one, and at step 215 the tape is a one-digit counter with fuel to spare, a state the invariant covers. From then on #11's argument applies, so this machine never halts.

The Rocq file re-proves #11's tape lemmas in mirror image and keeps #11's moves, invariant and closure proof word for word. It replays the 215 steps, checks the invariant there, and proves the result for this table directly.

2.1 Building blocks

A window lemma w → w' says: started on the cells of w, the machine runs the stated number of steps without reading a cell outside w, and leaves w'. The last step may move the head onto a neighbouring cell. Such a lemma holds in every tape context.

  • T1–T14 are exact finite runs on this table.
  • For S1–S6, one block is a finite run, and induction on n gives every n.

(10)^(n+1) 11 <D  =  (10)^n 1011 <D  →  (10)^n 11 <D 01  →  11 <D (01)^n 01

2.4 What the rules do, in words

The digits form a binary counter, and each M is one increment.

  • M flips the trailing 1s to 0 and the last 0 to 1. Every digit it touches pays one 10 from its v, and a digit flipping 0→1 also gains a 01.
  • When all bits are 1, O swaps the two halves of every digit. Each (01)^u becomes the (10)^u fuel of a new bit-0 digit, and each (10)^v becomes the next digit's (01)^(v−1). The counter restarts at value 1 with one more digit.
  • When a digit flipping 0→1 has spent its last 10 (v = 1), it drops: its 01s merge into the next digit, and the counter loses that digit.

The only way the rules can fail is the failure mode: a carry reaches a bit-0 digit with v = 0, where Lf's first lemma T4 has no 10 to read. That happens if a carry flips a bit-1 digit with v = 1 to 0.
