Mechanism (three levels)

Words: every long region of the tape is a power of one of four periodic words: - H6 = rotations of 110000 (100001, 000011, 011000, ...), - K6 = rotations of 110010 (001011, 100101, 010110, ...), - P4 = rotations of 1100 (1001, 0011, ...), the unary round counter at the right end, - P3 = rotations of 110.

  1. Trip level. The head shuttles between the right end and an active boundary. Three short trips only cross the counter 1001^c (D sweeps it unchanged: 1001^n <D -> <D 1001^n) and re-phase the block next to it. The fourth trip crawls left through the budget region with a local zig-zag and converts one block at the boundary. Fig cycle_closeup_P shows one such 4-trip cycle.
  2. Phase level. Each phase converts a budget region one block per cycle and adds 2 blocks to the counter. Three cycle rules, all validated from random instances (rulefit check): - R1 (K6 eats H6, e.g. 7.2e9..1.33e10): 0^inf 1011 110010^a 1^2 0^4 1101 100001^(b+2) 1001^c A> 0^inf -> ... 110010^(a+1) ... 100001^(b+1) 1001^(c+2) A>, 60/60 (b+2 >= 2, any c >= 0; also 36/40 with b+1 >= 1, all 4 failures at b = 0, the last block, which is the phase end). - R2 (the 1e8 hub): 0^inf 1011^3 001011^a 0^4 110^2 000110^(b+2) 01^2 1 0^4 110010^(p+1) 110000^(q+3) 1^3 01 1001^c A> -> a+1, b+1, c+2, 40/40. - R3 (the 5e8 hub, two 12-blocks Y = 010110000110 become one 24-block X = 010110010110000110000110): 0^inf 110^3 X^a 010110^2 000110^3 110 Y^(b+3) 000110^(p+1) 01^2 100001^(q+1) 1001^c A> -> a+1, b+1, c+2, 40/40. - In each phase the sum (grown + remaining) is conserved and the counter value is 2 x (blocks converted) + const (phase 6: c = 2g + 2 or 3 at the A record).
  3. Epoch level (the stop). When a budget runs out, the counter (about 2n P4 blocks = 8n cells) is re-read as a new 6-cell layer of about 4n/3 blocks, and the next phase depends on n mod 3. Experiment (scripts/vary.py, work/budget_residue_experiment.txt): the real phase-6 configuration at 1.29e10 with the remaining budget changed so the phase budget is n = 9996..10001, each run 1.3e9 steps, record-aligned:
