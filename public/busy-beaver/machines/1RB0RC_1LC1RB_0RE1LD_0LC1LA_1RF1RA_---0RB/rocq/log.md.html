Round 1 (2026-10-13)

Design (differs from W4-2 in the left side, same one-lemma-per-rule layout)

  • Tape family: RT l q Z := l {{C}}> [0;0] *> [1;0]^^q *> Z *> const 0 with Z : list sym (NOT list Sym: Sym and sym are convertible but rewrite treats them as different terms, so a zone typed list Sym breaks every rewrite against lemma statements whose numerals elaborate to sym).
  • Left side = a stack of frames. FR p l := [1] *> [0;1]^^p *> [0;0] *> l is the frame 00 (10)^p 1; the cycle start has no frame (l = const 0). Rounds give [1;0;1;0] *> FR p l = FR (p+2) l (FR_round, FR_rounds), PUSH k gives [1;0;0]^^k *> [1;0;1;0] *> FR p l = Nat.iter k (FR 0) (FR (p+2) l) (FR_push): the pending inner levels are frames with p = 0, and an ending bite pops the top frame. So the shift law is free: no rule lemma reads below the top frame.
  • Zone: zone r L v := [1]^^r ++ dg L v ++ [1;1;1], dg (S L) v = [1;1;bitc v] ++ dg L (div2 v), bitc v = 0 iff v odd. Width 3L+3+r; bit b of v on the b-th block 11c (= the lattice of proof.md, lowest cell 2/3/4 for r = 0/1/2). Lowbit decomposition v = 2^b (2o+1): dg_low ((111)^b 110 dg o) and dg_lowones ((110)^k 111 dg o for v = 2^k-1+2^(k+1) o).

Plan for round 2+ (route 3 of proof.md 9, CPS form)

  • safe c N := forall M, M <= N -> ~ halts_in tm c M.
  • Phase lemma PH (pure -->*, no IH needed): from a config (P, q, r, L, v) with r in {0,2} to its bite, three outcomes: (A) no overflow (run_bite); (B) r = 2, O2, then q in {1,2} with the all-set zone (q = 2 here is exactly H: excluded by H* arithmetic); (C) O0/O2(+R1), then chain, then run_bite on the bite level (zone 0 L' (2^L'-2-j)). In (C) the bite zone is never all set, so H never happens there.

Props = (U1)-(U4) of proof.md 6 (+ the (6,4,0) exclusion for K' starts). Cases: r = 1 first round by hand (R2 / O1, EQ1 / EQ2 arithmetic), then PH; the bite: EB_tape (pop, continuation), B2 = PUSH_lev k = 0 then EB1o, N = PUSH_lev k >= 1 then inner1, then IH at a smaller budget (nh_prog gives M < N) for each inner level lev 1 and for the resumed phase lev (P_c+2) l (a J start), chaining the continuations.

  • Final: nonhalt by strong induction on N over cycle starts in Ist, from init and U with P = 0, l = const 0, the continuation being the induction hypothesis.

Design change: phase invariants instead of chain arithmetic

The round-1 plan (phase lemma PH with three explicit outcomes, then Lemma K / Z' / A1 / Kp as separate arithmetic on the overflow chain, EQ1/EQ2 for w = 1 mod 3) was replaced by one generic lemma plus invariants: - phase Inv: for any Inv j q r L v (j = frame offset from the level start) that every Rnd preserves, the run from a config with Inv reaches a bite config (q <= 2) with Inv, by lt_wf_ind on q. No case analysis on overflows at all. - PI t (the phase invariant of a level from t = (n,r,L,v)) is a conjunction of - j even; Qv j .. = Mv t (sign law, from Rnd_sign); - r' = 1 -> j = 0, r' = 2 -> L' = 0 -> j <= 2 (the (6,4,0) exclusion, U5); - Saf q r L v (Lemma P: no H, every bite has a rule; parity of q when w = 2, the O1 lookahead); - t in K' -> KI j q r L v: r = 0: 2^L <= j+q /\ (2^(L+1) <= j+2v+2 \/ 2^(L+1)+1 <= j+q) /\ (q = 0 -> v <> 0) /\ (L = 0 -> 4 <= q); r = 1: 2^(L+2)+2 <= q /\ (v = 0 -> 2^(L+1)+5 <= q); r = 2: 2^(L+1)+2 <= j+q /\ 2v+5 <= q. At the bite this gives d(F t) >= 2 for every plain end and A1 (2^Lc <= j+2) for a nested bite. - t in J, d(t) <= 1 -> ZI (cap t + 1): r = 0: L <= C+1 /\ q + 2^(L+2) + C <= 2v + L + 2^(C+3) + 1 /\ (q = 0 -> v = 0 -> L <= C) (q + 2^(L+2) - 2v - L is constant along R1/O0, so at most one more overflow); r = 1, 2: the start bounds. Gives cap(G t) <= cap(t) + 1 (Lemma Z'). The w = 1 mod 3 starts need no EQ1/EQ2: K1/ZI1/Saf1 hold at the start and map to K0/K2 etc. - Post t t' = U1..U5 of proof.md 6 (+ validity); U N = CPS form: pops safe for N-1 steps -> start safe for N steps (safe c N := forall M <= N, ~halts_in tm c M). - U_all by strong_induction: N = 0 by one round (safe_prog0); else phase, then bite_shape: ending bite (EB_lev + ending), B2+B1 (ending_B2), or nested bite: PUSH_lev, inner1, STK (induction on the number of pending frames, U at fewer steps per level, carrying Budget t C := Kst t \/ cap t <= C and the alternating sign SR), then U for the rest of the level at frame P+j+2, and compose for the arithmetic (QvN: the N row of the sign law via 2^k = 3x + 1 + k mod 2). - cycles: strong induction on N over Ist (= K' with M <> 0); nonhalt from init.
