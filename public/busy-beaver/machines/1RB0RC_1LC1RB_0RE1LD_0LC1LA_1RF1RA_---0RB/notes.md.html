Two levels

  • Fast level (one cycle). From R(-1,n,Z): about n/2 rounds; each moves the wall 2 pairs right and decrements Z. Overflows refill Z (and widen it by 1 or 3 cells). When q <= 2 the wall reaches Z and bites its low end (B0/B1/B2/B2'), then a new cycle starts with n' = n+1..3.
  • Slow level (calm phase). Cycles alternate between w = 3L+3 and w = 3L+2 (for example 27/29 at L = 8). Per two cycles n grows by 2 and the start value v drops by 1. The counter overflows early in each cycle, and the bite drops one bit (v -> v>>1).
  • Level-up. When v reaches 0 near n = 2^(L+1), a second overflow per cycle widens Z for good: L -> L+1, v jumps to about 2^L. Fig levels_fill shows the sawtooth, one tooth per level.
  • Transitions. Some level-ups pass through an irregular phase: nested bites eat Z deep, w drops to 5..17 and rebuilds.
  • n = 258..810 (about 550 cycles), n = 2050..2110 (60 cycles).
  • Deep eats (w = 8) recur at n near 2^13, 2^17, 2^19, 2^21, 2^23, with the same margin-1 zone 110110110111111 at cycles 8,477 and 2,096,322.

1. The nested bite B2'' has a closed form: a stack of the same rules

  • Input: R(p, 2, (110)^k Y) with k >= 2 and Y starting 111.

2. Global structure: calm 2-cycles, clean and messy level-ups

3. Invariant search

  • Parity part (holds on all data):
  • At the outer level, configurations with q even and w = 2 mod 3 occur only in cycles that start with w = 2 mod 3 and n even, and right after O1 (checked on every configuration of the transients L = 10..32).
  • Reason: a B1 bite gives n' = p+3+r with p odd, and r = 0 whenever the new w is 1 or 2 mod 3, so those starts have n' even (a B0 bite with f = 2 gives w' = 2 mod 3 with n' odd, which is harmless). Nested-bite outputs with w' = 2 mod 3 have odd q'.
  • So H (an O2 overflow at q = 4) needs E = n - 2v = 4 at a w = 2 cycle start, or n - 2^(L+1) = 4 at a w = 1, v = 0 start.
  • No congruence obstruction. At w = 2 starts inside transients, E mod 16 is spread evenly over the even residues (2,570 starts, L = 10..32).
  • Bell-capacity window. Let cap(w) = number of counted bits, +1 when w = 1 mod 3 (an R2 round adds a bit) d = n - 2^(cap+1)
  • Since v <= 2^LL - 1, E >= d + 2. So d >= 3 at a w = 2 start rules out E = 4.
  • J := d >= 2, minus (d = 2 with an all-set zone, w = 0 or 2) and (d = 2, w = 1, v = 0).
  • Exhaustive test (w <= 21, every v, n from 2^(cap+1)+2 to 2^(cap+2)+100): no cycle from J halts. The only J states that leave J are (w = 0 mod 3, v = 0, n = 2^(cap+2)+3), one per width.

Q(p, q, Z) = q - (p+1) - v - (-1)^cap   (mod 3)      (+v instead of -v when w = 1 mod 3)

At a cycle start (p = -1), Q = M because 2^(cap+2) = (-1)^cap mod 3. - Rounds, overflows and q = 2 bites keep Q: R1, R2, O0, O1, O2, B2, B2'. - Bites that end a cycle negate Q: B1 (all three cases), B0 (f = 2 and f >= 5), B0c. - Each case is a two-line computation from the rule table, using 1/2 = -1 (mod 3). - The nested bite B2'' keeps Q.   • Composite form of a continuation cycle. Let the first continuation of the cycle from s be at R(p_c, 2, Z_c), with k low set bits and L_c bits.   • Later continuations of the outer level sit inside the last G-step.
  • Check: 533,148 continuation cycles from K (w <= 27) and 151,880 (w <= 15, n < 2^(cap+10)), 0 mismatches (below).

2. Gap (b) closed: no halt and no gap inside nested levels

  • Phase lemma. Call a phase start a level start or the output of a continuation. Inside a phase:
  • a w = 2 zone with q >= 3 exists only from the phase start (w = 2) or right after an O1 at the phase start (w = 1, v = 0); R1 and O1 keep the parity of q;
  • after the first overflow the zone has w = 0 mod 3 for the rest of the phase, so only O0 follows;
  • H = R(p, 2, (110)^j 111) is produced only by O2 at q = 4 (dec never gives an all-set zone; R2 and O0 leave the LSB clear; B2 with a reparse would need an all-set w = 1 zone at q = 2, i.e. a phase start with q = 2, and every phase start has q >= 3).
  • So H needs a phase start with w = 2 mod 3, q = 2v + 4, or w = 1 mod 3, v = 0, q = 2^(L+1) + 4. That set is H. Check: the cycle from t (w >= 3, n >= 3) halts iff t is in H, on 610,121 states (w <= 24) and 606,121 (w <= 12, n < 2^(cap+12)).
  • Parity of pops. A pop with w' = 1 or 2 mod 3 has n' = p + 3 (B1, no reparse) or p + 5 (B2 then B1), so n' = p + 1 mod 2. B0 with f = 2 never occurs inside a cycle: q = 0 only follows R2 or O0 at q = 3, and both leave the LSB clear. Inner levels have p even, so their pops have n' odd when w' = 1, 2.
  • Lemma J. J = { w >= 3, n >= 3, n odd when w = 1 or 2 mod 3 }. For t in J the level from t never halts, never meets a configuration without a rule, and pops into J.
  • Proof: q stays odd in its w = 1, 2 part, so q = 2 occurs only with w = 0 mod 3, w >= 6, zone not all set (B2, or a continuation with Y != 111 and |Y| >= 6, so t_2 is in J). Pops have w' >= 3, n' >= 3 and the parity above. Continuations recurse (induction on the length of the computation).
  • The innermost level is R(0, 1, Y[2:]) -> (3, Y[3:]), in J.
  • Consequence: every phase start except the outer cycle start is in J, so a cycle from s halts iff s is in H. In K, H = {T_c} u {(6,4,0)} (w = 2: n = 2v + 4 >= 2^(c+1) + 2 forces v = 2^c - 1; w = 1: d >= 2 forces L = 0, n = 6).
  • Check: J1 holds on all 1,920,333 J states with w <= 27, n < 2^(cap+4), and 479,621 with w <= 15, n < 2^(cap+10).

3. Gap (a) closed: Lemma K for continuation cycles

  • A1 (bell at the continuation). From K, level 0 always overflows (E >= 4), so the first continuation is at a level m >= 1 with L_c = c + m bits, and p_c >= 2^(L_c) - 3
  • m = 1: p_c = n - 3 (w = 2 start), n - 4 (w = 0), n - 5 (w = 1, v >= 1, via the R2 equivalence (n, w, v) ~ (n-1, w+2, 2v-1)); d >= 2 gives the bound. w = 1, v = 0: the O1 level has c - 1 bits, the next one c bits and p_c = n - 3.
  • m >= 2: p_c = n - 3 - j with j = m - e (the O0 overflows before; e = 1 if the first overflow is O2), and reaching level m needs q_m = E - e - 4 + m - 2^(c+m+1) + 2^(c+2) >= 2. With n >= E this gives p_c - 2^(c+m) + 3 >= 2^(c+m) - 2^(c+2) + 6 - 2m + 2e >= 0.
  • Check: min slack 0 (it is tight at w = 1 mod 3, d = 2).
  • Lemma Z' (zone-dominated step). If t is in J and d(t) <= 1, then d(G t) >= 2 or cap(G t) <= cap(t) + 1.
  • With n <= 2^(c+1) + 1 the top level of the step makes at most one overflow after its first (the next one would need E >= 2^(c+2) + 2 > n).
  • Cases: w = 0, no overflow: bite, cap - 1; w = 0, one O0: bite at c + 1 bits, cap c (L = 0: B0c gives cap 1); w = 2 (n odd): B1 to w = 1 gives cap + 1, or O2 then a bite at odd q gives cap c; w = 1 (n odd): v >= 1 reduces to the w = 0 case by the R2 equivalence (d - 1 <= 1), v = 0 is O1 then the w = 2 case.
  • A continuation inside the step: its inner run is again G-steps from (3, Z_c[3k+3:]) with L_c <= c + 1. If the last inner state is K-like (d >= 2), then d(G t) >= p_c + 3 + 2 >= 2. Otherwise every inner state is zone-dominated and, by induction, the inner cap grows by at most 1 per step: cap <= (L_c - k - 1) + k <= c.
  • K-likeness persists. If t is in J and d(t) >= 2, then t is not T_c or (6,4,0) (both have even n and w = 2 / w = 1), so Lemma K gives d(G t) = d(F t) + 1 >= 3.
  • Lemma K, continuation case. With F(s) = (p_c + 2) + t_(k+2):
  • if some inner state is K-like, so is t_(k+2), and d(F s) >= p_c + 4 >= 4;
  • otherwise t_2, ..., t_(k+2) are all zone-dominated, cap(t_2) = L_c - k - 1, and Z' gives cap(t_(k+2)) <= L_c - 1. Then, with n(t_(k+2)) >= 3 (Lemma J) and A1, d(F s) >= (2^(L_c) - 3) + 2 + 3 - 2^(L_c) = 2.
  • Lemma K, Lemma Z' and K-persistence are proved together by induction on the length of the cycle computation (inner G-steps are strictly shorter).
  • Data: min d(F s) on continuation cycles is 5 (slack 3 over the bound).
  • (6,4,0) has no predecessor in K (needed for the closure of I): plain cycles give n' >= n - 1 - f + 2 with f <= log2(n) - c overflows, continuation cycles give n' >= p_c + 5 >= 2^(L_c) + 2; so n' = 6 forces n <= 9 and c <= 1 (w <= 8), inside the exhaustive window (0 predecessors, work/invariant_w3-31_X3.txt).
