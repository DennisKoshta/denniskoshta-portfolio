Deepen pass (overnight 2026-10-10)

Goal: close the open gaps (phase list, tail rule T -> T', invariants). Result: the micro-mechanism and the halting condition are now exact and validated; the tail rule is NOT closed. Confidence stays med. Tools: scripts/deepen_* (C tracers; build with gcc -O2; sources say how to run).

1. Crossing lemma (exact, validated). A sweep complements every cell it crosses (10<->01, 00<->11) and never moves a wall. All tape changes happen at turns, within 8 cells of the turn point. - Left sweep (F/A): complements until it reads two 0s in a row (A reads 0); it always turns at the first 00. - Right sweep (B,C,D,E,A cycle, 4 cells per 6 steps): crosses 00/11 at one parity and turns at the other (C0 starts a C-run left, or A1 -> F). - Checked on all 931,918 sweeps from blank to the E5 anchor (3.54e10 steps; deepen_ccheck.c). Non-complement changes lie <= 8 cells from the sweep ends, except 5 right-edge sweeps (<= 12 cells; these are the right-edge growth events). - Consequence: write the tape as a list of maximal alternating segments. Sweeps leave the segment lengths alone; only turns rewrite them (local, <= 8 cells).

2. Halting lemma (exact; hand derivation + validation). Halt = E reads 0. E is entered only by D0. D can reach a 0 followed by a 0 only after a D1, and D1 happens only after a C-run that follows a left-sweep turn. - D1 happens exactly when the configuration 1 0 0 <F 0 0 occurs: F reads 0 at u+1, the cells u-1,u = 1,0, and u+2,u+3 = 0,0 (already complemented by the sweep). - The machine halts exactly when the configuration is 1 0 0 <F 0 0 0 0 or 1 0 0 <F 0 0 1 0 0. - Validated on random tapes (deepen_haltlemma.py, 40k runs): 7,886/7,888 halts after step 40 match. The 2 misses are at steps 40-41 and come from the random start state. 32,118/32,119 D1 events match. - On the blank-tape orbit to 3.54e10 steps, D1 happens only 6 times: steps 130, 309, 2,306,898, 2,380,763, 2,488,620,044 and 2,497,241,765 (deepen_d1log.c). All 6 are at the right edge and are the right edge's growth steps (hi 8->14, 44->50, 72->78). Each time the D-run is 6 long and E then reads 1. The pattern never occurs in the bulk. - So non-halting = "the pattern 1 0 0 <F 0 0 (0 0 | 1 0 0) never occurs", and in practice the question is only open at the right edge.

3. Phase lists (exact periodic turn programs; deepen_wturns.c + deepen_seg.py). Phases with at least 5 cycles, as period k x cycle count: - E1: 16x254 | 20x63, x26, x48, x139 (the same 7-counter slow cycle; the turn-wall index drops 8->5 as interior walls are absorbed) | 44x46 | 44x197. - E2: 16x767 | 20x87, x88 | 44x29 | 48 (7 sub-phases, x8 to x233) | 100x78 | 104x12 | 100x173 | 44x104. - E3: 16x2306 | 20x532, x533 | 44x178 | 48x133 | 100x469 | 104x22 | 212x8, x58 | 436x9 | 44x1106. - E4: 16x6923 | 44x1961 | 104 (4 sub-phases) | 212/216/220 (7 sub-phases) | 436x25 | 100x1935 | 436x155. - The programs nest: k' = 2k+4 (or +12) each time one more wall joins the bounce (16, 20, 44, 48, 100, 104, 212, 436). - The phase list is different in every epoch and its depth grows. There is no fixed per-epoch phase list; only the left part (a, c) repeats exactly.

4. Tail = growing register system (open). A processing front moves right through T during the epoch (snapshots: deepen_dumpat.c | deepen_cmp.py). - Dense blocks (1110)^n (1101)^n (1011)^n (0111)^n act as registers and are converted block to block. E2 values: 87/93, 52, 128 -> 174, 177, 175, 173 -> 45, 126 -> 14, 48, 18 -> 467, 15 -> 7. - The wall-cluster count at the anchors grows: 15, 14, 15, 20 (E1-E4). - Tail gap values show no affine pattern (first gap 192, 349, 2129, 3920, 16848). - T -> T' therefore needs a register machine whose number of registers grows. It was not decoded. There is no sign yet of residue (Collatz-type) branching; branching is on which register empties first.

5. Local-language saturation (deepen_factors.c). Distinct 16-cell windows (mod complement) around turn points: 1768 / 1939 / 1967 / 2022 / 2363 at the E0..E4 anchors. - The bulk (pos <= -150) has produced no new window since step 258,986,194 (epoch 2). - All 341 new windows in epoch 3 are at the right edge (pos > -150): the growing 1^k run and the small dense block there (1^6 -> 1^8 -> 1^10). - So the bulk lives in a fixed finite local language, which looks like a regular closed language. The right end is the only region that keeps producing new local patterns.

6. Tail robustness (deepen_gentails.py + deepen_runcfg.c). Real tails were perturbed: gaps rescaled by up to +-1/3, and 15% of the walls dropped. - 80 perturbed tails on the E1 left part (5e8 steps each) and 20 on the E2 left part (1.2e9 steps each): 0 halts. - 33 runs had D1 events (E always read 1). - 18 runs entered another right-edge regime: the right edge ran away to about 50k cells. - So non-halting looks robust to the tail, but the bounded right edge of the real orbit is specific to it.

Assessment. Mechanism: a nested wall bouncer with exact micro rules (crossing = complement, local turn rewrites). Halting reduces to one local pattern, which has never occurred in the bulk. - The epoch-induction route is blocked on the tail: there is no finite phase list and T -> T' is a growing register system. - More promising route: a closed regular language.
