1. Families

Groups are 3 cells and are read left to right:

group name role
000 digit 0 counter digit
001 digit 1 counter digit
010 inert i skipped by the counter's carry
100 pending S only in residue-derived words; a carry turns it into i (rule inc, §2.3)

A counter word is X = x0 g1 g2 …gk, where x0 is one cell and each gj is a group. Its value is value(X) = x0 + Σ 2^j, where j runs over the digit-1 groups and counts digit groups only (inert and pending groups are skipped; the first digit group has weight 2). The word is normalized when it has no 100 group. The language is L_X = x0 {000,001,010}* {100,010,000}*.

K(a, b, X) := 0^inf (110)^a 0 (011)^b C> X 0^inf          a >= 1, b >= 1, X in L_X        (hub)
L(n, Q)    := 0^inf <E (010)^n 001 Q 0^inf                 n >= 1, Q in {100,010,000}*     (left record)

Family predicate used by the epoch argument (§4): every hub reached in the bounce phase satisfies value(X) = a. It holds at K(1, n, 1Q), because Q has no digit-1 group. Rule B preserves it, because B adds 1 to a and inc adds 1 to the value (Lemma V, §2.3).

2.3 inc (rule B) and eat (rule E), every case

inc(x0 g1 g2 …): - x0 = 0: set x0 := 1. - x0 = 1: set x0 := 0, and a carry enters g1. carry(w) is defined by cases on the first group of w: - 010: pass, go to the next group. - 001: becomes 000, pass. - 000: becomes 001, stop. - past the end: append 001, stop. - 100: becomes 010. Then tog toggles the groups after it, up to and including the next 000: 010 -> 000, 100 is skipped, and past the end a 000 becomes 010. The carry then resumes at the group immediately after the former 100. That group lies inside the segment that was just toggled, so it may itself have just changed. In symbols: carry(100 w) = 010 carry(tog(w)).

The other reading, "resume after the toggled segment", disagrees with the TM on 1,524 of the 14,580 words of L_X with ≤ 7 groups (check 2.3x).

The toggle is binary +1 on the i/0 string to the right (i = 1, 0 = 0), skipping S groups. It never meets a 001, because S groups occur only in the tail {100,010,000}*.

Lemma V (value). For X in L_X, inc X is in L_X and value(inc X) = value(X) + 1.

Proof. In the prefix {000,001,010}*, the carry is binary +1 over the digit groups, and it passes inert groups. If the carry enters the tail, every tail digit group is 000, so the tail contributes 0 to the value. A 100 becomes inert (010), and tog only swaps 010 <-> 000 inside the tail, so neither changes the value. The carry then stops at the first 000 after the former S. That group has the same digit index as the position the carry had reached, so the value grows by exactly 1. Every rewrite stays inside {000,001,010}*{100,010,000}*. ∎

Check 2.3x verifies this on every word with ≤ 7 groups.

eat(a, x0 G), with G normalized: - x0 = 1 (odd case): H := carry(G), and a' := a+1. - x0 = 0 (even case): the J-walk drops groups from the front of G, starting with k := a+1: - 001: drop it, k += 1. - 010: drop it, replace the rest by carry(rest), k += 1. - 000 (or the end of G): drop it and stop. Then a' := k+1.

H := what is left. - Residue in both cases: Q' := regroup(cells(H)[1:]), i.e. group by group 010 -> 100 (S), 001 -> 010 (i), 000 -> 000.

3. The epoch map in closed form

Agreement checks: - check 3a: agrees with the deepen map on 20,000/20,000 epochs; - check 3b: 17,141/17,141 random normalized states (revision-2 run); - check 3c: the TM's own records, 276/276 epochs to 1e9 steps; - the deepen pass: 1,142/1,142 epochs to 1e11; - the skeptic: 26,744 arbitrary eat states.

State at an eat. A normalized counter of value n is x0 = n mod 2, followed by a layout λ = i^c0 d i^c1 d i^c2 d …. The d-slots hold bits 1, 2, 3, … of n, and c_j ≥ 0 is the number of inert groups just before d-slot j. Write the state as (n, c) and define: - C(c) := Σ c_j 2^j (the inert weight); - J(c) := max{ j : c_j > 0 } (the slot of the top inert group, -1 if there is none); - B(x) := the bit length of x; - Z(M) := B(M) - popcount(M), the number of 0-bits of M below its top bit (Z(0) := -1); - the potential P(n,c) := ⌈n/2⌉ + C(c).

Lemma 3.1 (eat). Let M be the number the d-slots of the uneaten part H spell, plus C(H). - n odd: H = c, M = (n+1)/2 + C(c) = P, n' = n+1. - n even: let V = n/2 + C(c) = P and let t be the number of trailing 1-bits of V. Then H = (c_{t+1}, c_{t+2}, …), M = V >> (t+1), and n' = n + 2 + t + Σ_{r≤t} c_r.

Proof (n even). Induction over the J-walk with the invariant m + C(rest) = ⌊V/2^k⌋ after k digit slots have been dropped, where m is the value on the rest. - Dropping an inert slot before d-slot 0 adds 1 to m and removes weight 1 from C(rest). - Once those inert slots are gone, C(rest) is even, so the next digit is the parity of ⌊V/2^k⌋. - A digit 1 is dropped with m := (m-1)/2, which keeps the invariant at k+1. - The first digit 0 ends the walk. That is d-slot t. - n' counts the dropped groups: t+1 digit slots plus Σ_{r≤t} c_r inert slots, plus 1.

The odd case is one carry into slot 0, and that carry passes inert slots. ∎

Lemma 3.2 (next layout). In the next epoch the residue Q' has: - an S at each inert slot of H; - an i at each d-slot of H holding 1; - a 0 at each d-slot holding 0.

Once the bounce phase has carried through every S, the layout is λ' = merge(H, M). For each j it has c^H_j inert groups, then i if bit j of M is 1 and d otherwise; past the end of H the bits of M continue in the same way. Equivalently, with r(j) := #{0-bits of M below j}, every inert group of H at slot j and every 1-bit of M at position j lands at slot r(j) of the new layout. So:

C' = Σ_j (M_j + c^H_j) · 2^{r(j)}

Proof. The d-slots of H, read as i = 1 and 0 = 0, spell m_H. Toggles run left to right. An S sitting before d-slot j adds 2^j to the number spelled by the slots after it (inc, §2.3), and it never changes a slot to its left. So the final i/0 pattern spells m_H + Σ_S 2^{j(S)} = m_H + C(H) = M, and each S itself becomes i. The main counter's carries only ever stop on 000 groups, which are the d-slots. They never touch a slot to the right of the exploration frontier, which is where the remaining S groups are. ∎

Lemma 3.3 (normalization depth). In the next epoch, the last S is consumed by the main counter's D-th exploration, which happens at increment 2^D - 1. Here

D = 1 + #{ j < J(H) : bit j of M is 0 } = 1 + r(J(H))          (D = 0 if H has no inert slot)

So the next eat is normalized iff 2^D ≤ n', i.e. iff slack := B(n') - 1 - D ≥ 0. Also D ≤ 1 + J(H).

Proof. Each exploration ends on a d of λ'. The last S sits just before H's d-slot J(H). The d's of λ' before that point are the 0-bits of M below J(H). The counter runs from 1 to n', so the k-th exploration happens iff 2^k - 1 ≤ n' - 1. ∎

4. Coverage

Every member of the families that the run reaches is covered: - L(n,Q) with n ≥ 1 and Q ∈ {100,010,000}: R applies. - K(a,b,X) with b ≥ 2 and X ∈ L_X: B applies. inc keeps X in L_X and value(X) = a (Lemma V). - K(n,1,X) with value(X) = n: E applies if X is normalized*. It then produces L(n',Q') with n' ≥ n+1 ≥ 2 and Q' ∈ {100,010,000}*. The regroup of a normalized H only produces those three groups, because every group of H starts with a 0.

That leaves exactly one obligation: every eat sees a normalized counter, i.e. slack_t ≥ 0 for all t (Lemma 3.3).

5.1 What is needed (the only form of Lemma N)

5.2 Sufficient conditions for one step (proved, but not invariant)

Lemma S-odd. If n is odd and C(c) < 2^{B(n+1)-1}, then the next eat is normalized.

Proof. H = c and 2^{J(c)} ≤ C(c) < 2^{B(n')-1}, so J(H) ≤ B(n') - 2 and D ≤ 1 + J(H) ≤ B(n') - 1. ∎

Lemma S-even. If n is even and J(c) ≤ B(n) - 1, then the next eat is normalized.

Proof. J(H) = J(c) - t - 1 ≤ B(n) - 2 ≤ B(n') - 2. ∎

Check 5.2 confirms both on random states.

Let Inv_S(n,c) := (n odd ⟹ C < 2^{B(n+1)-1}) and (n even ⟹ J ≤ B(n)-1). Inv_S at epoch t implies slack_t ≥ 0. It is only a one-step sufficient condition.

5.3 Inv_S is not an invariant of the orbit

  • The orbit itself. A cascade (§5.4) starts at t = 350,272:
  • t = 350,272: odd n = 4,193,605, c = [3,15,3,0,11,0,0,1], M = 2^21.
  • t = 350,273: slack is exactly 0 (D = 21, B(n') = 22, and J = B-1 at even n).
  • t = 350,274: n = 4,193,611 is odd and C = 3,145,901 = 1.5001·2^{B-1} ≥ 2^{B(n+1)-1}, so Inv_S fails. The slack at this eat is still 15.

Checks 6a and 6b reproduce this, and so did the skeptic's two independent implementations, in Python and in C. Through 10^10 orbit epochs (n ≈ 1.95·10^11) the skeptic found: - slack 0 only at t ≤ 15 and at t = 350,273; - slack never below 0; - for t ≥ 20, Inv_S fails only at t = 350,274.

Revision 1's "slack ≥ 2 for t ≥ 20" and "J ≤ B-2 at every even n" were true only up to its 200,000-epoch horizon. - Structural reason. By cascade lemma (ii), every cascade with c_0 odd and n''+1 < 2^B puts the orbit, two epochs later, at an odd n with C'' = 3·2^{B-2} + (C - c_0)/2 ≥ 2^{B-1}. - Witness of non-closure (check 5.3). n = 2049, c = [1023] gives (2050, C = 3071, J = 11) and then (3075, C = 3072), where Inv_S fails. Both eats are still normalized.

5.4 Cascade lemma (proved; check 5.4)

Let n be odd, B := B(n+1), and M = (n+1)/2 + C = 2^{B-1}. Write the next two epochs as (n', c') and (n'', c''), with n' = n+1. Then:

  • (i) V' = n'/2 + C' = 2^B, M' = 2^{B-1}, J(c') = B-1, and D' = B - 1. So slack' = 0 if n'' < 2^B, and 1 otherwise. Here n'' = n + 3 + c'_0 = n + 3 + c_0.
  • (ii) If c_0 is odd and n'' + 1 < 2^B:
  • n'' is odd;
  • C'' = 3·2^{B-2} + (C - c_0)/2 ≥ 2^{B(n''+1)-1}, so Inv_S fails at (n'', c'');
  • M'' = 5·2^{B-2} + (3 - C)/2.
  • (iii) For every c_0, D'' ≤ B - 1, so the eat after (n'', c'') is normalized (slack'' ≥ 0).

Proof. - (i) M has no 1-bit below B-1, so r(j) = j there. Also C < 2^{B-1} gives J(c) ≤ B-2. Hence C' = C + 2^{B-1} and V' = (n+1)/2 + C + 2^{B-1} = 2M = 2^B. So t' = 0 and M' = 2^{B-1}. By Lemma Z (§5.5), J(c') = max(D-1, Z(M)) = B-1, because D - 1 ≤ J(c) ≤ B-2. Then H' = c'[1:] has J(H') = B-2, and D' = 1 + r(B-2) = B-1 since M' has no 1-bit below B-1. Finally n'' = n' + 2 + c'_0 with c'_0 = c_0. - (ii) M' = 2^{B-1} again acts as the identity, so C'' = C(H') + 2^{B-1} = (C + 2^{B-1} - c_0)/2 + 2^{B-1}. n'' has the parity of c_0. Substituting n = 2^B - 2C - 1 gives M'' = (n''+1)/2 + C'' = 5·2^{B-2} + (3-C)/2. - (iii) By Lemma Z, J(c'') = max(D'-1, Z(M')) = B-1. - If n'' is even, J(H'') ≤ B-2, so D'' ≤ B-1. - If n'' is odd, D'' = 1 + #{0-bits of M'' below B-1}. Here M'' mod 2^{B-1} = 2^{B-2} - (C-3)/2, and 1 ≤ C ≤ 2^{B-2} because (n+1)/2 ≥ 2^{B-2} and c_0 is odd. This value lies in (2^{B-3}, 2^{B-2}+1], so it is nonzero, M'' has a 1-bit below B-1, and D'' ≤ B-1. ∎

So the eats right after a cascade are safe. The danger lies later in the excursion it starts (§5.5–5.7).

5.5 Lemma Z and Lemma R (proved; check 5.5)

Lemma Z (top inert slot). J(c') = max(D - 1, Z(M)). The first term counts only if H has an inert group; the second only if M ≥ 1.

Proof. Every inert group of H at slot j, and every 1-bit of M at j, lands at slot r(j) (Lemma 3.2), and r is non-decreasing. The top inert group of H lands at r(J(H)) = D - 1 (Lemma 3.3). The top 1-bit of M lands at r(B(M)-1) = Z(M). ∎

Lemma R (no violation without an excursion). If slack_{t-1} ≥ 0 and P_{t-1} < 2^{B(n_t)}, then slack_t ≥ 0.

Proof. D_t ≤ 1 + J(H_t) ≤ 1 + J(c_t) = 1 + max(D_{t-1} - 1, Z(M_{t-1})) by Lemma Z. - First term. D_{t-1} ≤ B(n_t) - 1 ≤ B(n_{t+1}) - 1. - Second term. M_{t-1} ≤ P_{t-1} < 2^{B(n_t)}: M = P at odd n, and M ≤ P/2 at even n. So Z(M_{t-1}) ≤ B(n_t) - 1, with equality only if M_{t-1} = 2^{B(n_t)-1}. - Without equality, D_t ≤ B(n_t) - 1, which is enough. - Equality is impossible at even n_{t-1}, because there M ≤ P/2 < 2^{B(n_t)-1}. At odd n_{t-1} it is exactly a cascade start, and cascade lemma (i) gives slack_t ≥ 0. ∎

Corollary (reduction). Call epoch s an excursion if P_s ≥ 2^{B(n_{s+1})}. Then Lemma N follows from the slack at t = 0 together with

Lemma X (excursion lemma, OPEN): for every t ≥ 1 such that epoch t-1 is an excursion, slack_t ≥ 0.

Proof. Induction on t, using Lemma R when epoch t-1 is not an excursion and Lemma X when it is. ∎

Lemma X cannot come from magnitude bounds alone. Take the super-cascade (check 8b): an odd n with M = (n+1)/2 + C = 2^{B(n+1)} exactly and n'' < 2^B. It has V' = 2^{B+1}, M' = 2^B, J(c') = B and D' = B, so slack' = -1. Example: n = 1019, c = [0,1,0,0,0,0,0,0,2]. It has C/2^{B-1} = 1.004, its first eat has slack 0, and the next has slack -1. The orbit reaches C/2^{B-1} ≈ 1.5 at odd n (§5.3). So whatever proves Lemma X must use exact values, as cascade lemma (ii) does. There, the dangerous value M'' = 2^B is excluded by arithmetic: 5·2^{B-2} + (3-C)/2 ≠ 2^B for C ≤ 2^{B-2}.

5.7 Plan for Lemma X, and the cryptid question

Plan. 1. Classify excursion entries. An excursion entry has P_t ≥ 2^{B(n_{t+1})} while P_{t-1} < 2^{B(n_t)}. Since P_t = ⌈n_t/2⌉ + Σ_j (M_j + c^H_j)·2^{r(j)} and ⌈n_t/2⌉ ≈ M_{t-1} - C_{t-1}, an entry needs r(j) close to j for the heavy terms. So M_{t-1} must have at most about two 1-bits at or near its top, with the inert weight below its lowest 1-bit. Examples are the cascade 2^{B-1} and the near-cascades 2^{B-1} + 2^{B-2} and 2^{B-1} + 2^{B-3}. 2. Follow each entry type exactly, as in cascade lemma (ii)–(iii), until the potential returns below 2^B. Each continuation of the excursion forces one more exact bit pattern, which pins C further. For example, the cascade continues past t+2 only if 2^{B-2} - (C-3)/2 is a power of two, i.e. only if C = 3. 3. In parallel, look for a 2–3 epoch invariant that names the post-cascade states explicitly (the skeptic's suggestion).

The risk is that the list of entry types turns out not to be small. The ψ-term depends on where the inert groups of H sit relative to the 1-bits of M.

Cryptid assessment (ground rule 6): not flagged as of this revision; this is a priority call for Dennis. - An excursion starts with a coincidence: ⌈n/2⌉ + C equals a power of two or nearly so. On the main orbit this happens about 0.1 times per binary level, and it happened once in 10^10 epochs. - Halting would need the excursion that follows to reach a violating pattern. In every case examined, that is excluded by exact arithmetic rather than by luck: - cascade lemma (ii)–(iii); - 0 violations in 302,484 constructed cascade and near-cascade starts; - 0 violations in more than 2·10^9 natural-orbit eats. - If Lemma X turns out to need an unbounded family of entry types, the condition does depend on exact coincidences of ⌈n/2⌉ + C with sparse binary patterns along one deterministic orbit. Then the right outcome is ground rule 6 (CRYPTID_CANDIDATE), with §5.5–5.6 as the heuristic.

5.8 Funded stage on Lemma X (2026-10-10): the exit fires

New proved results. All are checked by scripts/fs_lemmax.py, which passes for seeds 1 and 2 at N = 20,000. The counts are in notes.md, "Funded stage".

The notation is that of §3, plus two quantities: - m(M) = Σ_{1-bits p of M} 2^{r(p)}; - L(H,M) = Σ_j H_j (2^j - 2^{r(j)}) ≥ 0.

With them, C' = m(M) + C(H) - L(H,M).

  • F4/F5 (potential identities).
  • Odd n: P' = P + m(P) - L(c,P).
  • Even n: P' = V + 1 + ⌈(s+σ_s)/2⌉ - C_lo - (2^{s+1}-1)C(H) + m(M) - L(H,M).
  • Lemma A. No excursion starts at an even eat: even n and P < 2^{B1} imply P' < 2^{B1}, where B1 = B(n').
  • Lemma B. P + m(P) ≤ 2^b + 2^{b-2} for P < 2^b. So an odd entry has P' ≤ 1.25·2^{B1}.
  • Lemma R2. Suppose slack(σ) ≥ 0 and slack(σ') < 0. Then one of three things holds:
  • σ is a super-cascade: n odd and P = 2^{B1};
  • P ≥ 2^{B1+1};
  • σ is an even cascade (V = 2^{B1}) with B(n) < B1.
  • Lemma EC. Suppose n is even, V = 2^{B1}, B(n) = B1 and slack ≥ 0. Then slack' ≥ 0, and 1.125·2^{B1} < P' ≤ 1.25·2^{B1} + 1. This is cascade lemma (iii) for any residue.

So every failure has to pass through a super-cascade or through a potential ≥ 2^{B1+1}. Both of these can only be reached from inside an excursion, and every excursion starts at an odd eat. The entry shapes are P = 2^B - 2^k + x: a top run of w ones followed by a tail. That is an infinite family. Natural orbits use only the cascade and w = 1.

Counter-family (proved for every B ≥ 8; exact for B = 8..300; TM-confirmed at B = 8). Let σ0(B) = (3·2^{B-2} - 7, [3, 0^{B-6}, 10, 0, 2]). - It satisfies everything Lemma X may assume: slack is 2, it is not an excursion, and P0 = 15·2^{B-4} (w = 4). - Epoch 1: V = 17·2^{B-4}. - Epoch 2: P = 2^B at odd n, a super-cascade. - Epoch 3: V = 2^{B+1} and slack = -1. - On the TM, from K(185, 1, X(σ0(8))), the eats are n = 186, 191 and 192, and then a non-normalized eat at n = 194. - The TM then recovers: normalized eats resume at n = 207. The same happens at B = 9 and B = 10.

So a finite case analysis over entry types cannot prove Lemma X. What decides safety are equations like P_{t+2} = 2^B in the residue counts. Whether the main orbit ever solves them is a question about exact coincidences along one deterministic orbit. Following ground rule 6 and the agreed exit, the machine is flagged CRYPTID_CANDIDATE.

The heuristic still supports non-halting: - 0 non-normalized eats in more than 2·10^9 natural eats, and none to 10^10 main-orbit epochs; - natural entries are 1,769 cascades and 11 w = 1 near-cascades in 5.9M eats, and never w ≥ 2; - the TM recovers even from the family's non-normalized eats.

The rule layer (§1–§4, §2.5) remains formalizable as an AntiHydra-style reduction.
