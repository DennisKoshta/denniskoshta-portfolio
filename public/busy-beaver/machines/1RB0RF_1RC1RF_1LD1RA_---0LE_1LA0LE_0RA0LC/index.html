Mechanism

How it works: 3 notes
  • Mirror of FractalBEC tm10: blocks (110)^a 0 (011)^b on the left, a binary counter on the right; each bounce adds 1.
  • C1 differs: when b runs out the bell eats the counter only partly, so N grows by 1, 3 or 4+r per epoch, never doubles.
  • Uneaten digits stay as inert 1s inside the next counter (residue); carries pass straight through them.

So safety depends on the orbit's exact residue counts solving equations like P=2^B: pseudo-random arithmetic along one orbit (ground rule 6). Heuristic for non-halting stays strong: 0 non-normalized eats in >2e9 natural eats and to 1e10 main-orbit epochs; natural entries are cascades (1,769) and w=1 near-cascades (11), never w>=2; the TM even recovers from the family's non-normalized eats (B=8,9,10).
