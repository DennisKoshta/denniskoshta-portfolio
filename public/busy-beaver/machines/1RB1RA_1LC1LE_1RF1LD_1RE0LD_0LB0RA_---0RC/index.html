How we proved it never halts

The counter never exceeds twice the word's length

The tape holds a binary counter on the right, written 11 for a 1 and 00 for a 0, lowest digit first, and on its left a word of 10 pairs with one flaw, an extra cell called the defect. Each trip of the head into the word and back adds 1 to the counter, and every second trip moves the defect two pairs further from the counter. Once the defect has walked off the far end, the next trip reaches the blank left edge, where a sweep shifts the whole word by one cell, eats the counter's lowest digits and plants a fresh defect. So the word grows with every eat.

The key fact is a size bound at each eat: the counter's value is at most twice the number of pairs in the word. The eats fall into five cases by the counter's last binary digits. In the hardest, the eat misaligns the low digits and briefly creates a second defect, which later cancels the first; that works out only if the word is long enough, and the bound supplies exactly that.

Why that settles it: each case is a chain of exact moves from one eat to a later one, where the bound holds again. The missing table entry (state F reading 0) could only come up if the left-edge sweep met two 0 cells in a row, but that sweep only crosses the word 10 10 … 10 1, which has none. The blank tape reaches an eat inside the bound at step 165, so the machine never halts.

The Rocq proof uses busycoq's binary-counter library, proves every move as an exact run and every case as a chain of them, checks the bound's closure by arithmetic, and runs the opening directly.

How it works: 3 notes
  • Tape between counts: M(a,X,b,N) = 0^inf 10^a X 10^b 011 B> 0 D(N) 11 0^inf. D(N) 11 is N in binary, low digit first, 1 = 11, 0 = 00 (the final 11 is the leading 1). X is a one-cell phase defect (an extra 1 or 0) in the 1010 word.
  • Each count adds 1 to N and moves the defect left (X=1 -> X=0 in place, X=0 -> X=1 two pairs left). When it falls off the far end (word 10^p, no defect: E(p,N)) a C/F sweep runs the whole word into the counter and eats its low end: N odd -> (N+1)/2, N = 0 mod 4 -> N/4, N = 2 mod 8 -> (N+6)/8, N = 6 mod 8 -> a two-defect transient ending in a quick second eat. The word gains 2 to 7+t pairs.
  • Eat to eat: p' = p+1+e+[p odd], N' = f(N)+p'+[p even] (e = 1,2,3 digits eaten); 6 mod 8: N = (2m+1)2^(t+3)-2 -> E(p+7+t, m+2^t+t+1), N = 16m+6 -> E(p+7, m+5). This equals the direct run at all 2,091 eats to 1e11 steps. Invariant p >= 20, 1 <= N <= 2p is kept by every branch (algebra; exhaustive for p <= 2000) and holds from E(21, 6) at step 3,097. No branch halts (the only halt, F0, needs a C/F sweep, and all 514 sweeps to 1e9 are eats), so the pseudo-random order of eat types needs no prediction: not a cryptid. Siblings: none.
