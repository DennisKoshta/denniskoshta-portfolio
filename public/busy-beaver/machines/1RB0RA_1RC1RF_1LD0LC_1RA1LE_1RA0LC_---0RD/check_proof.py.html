"""Check every rule and claim in proof.md for 1RB0RA_1RC1RF_1LD0LC_1RA1LE_1RA0LC_---0RD (stdlib only).

usage: python3 -B check_proof.py [--long] [--seed S] [--quick]
  default: about 6 minutes of pure Python (--quick: about 2.5 minutes).
  --long : also recompile and rerun the C trackers (scripts/proof/rle2.c to 1.3e10 steps, about 60 s;
           scripts/funded/cfgdump.c to 3e8 steps) and compare with the stored files.
  --quick: fewer random instances (smoke test).

Checks (names as in proof.md):
  HALT     the only undefined transition is F0, and F is entered only by B1.
  FULLPY   independent Python run from blank to 1.6e7 steps: visit runs at b18 and b618 equal the stored C file.
  IFACE    stored run to 1.3e10 (data/proof/rle_b18_b618_1.3e10.txt): b18 visits are only AC/DC, b618 only AE/BE;
           b18 runs alternate A/D (one D-run per epoch); the epoch table N_m, c_m, j_m.
  INIT     the rest point S0 (step 300,032,133): M clean, T canonical T(P,PP;e=5521).
  ZM       zone M (cells 18..617): per-visit rules MD/MA (and the top carry -> B visits), exact on random words.
  GMAP     the value map g: every v ends at 0 or 5; visit bound.
  TA       zone T: A visit = throttle increment (exact), including K = -1.
  TB       zone T: the first B visits after an A-run follow the throttle frontier rule (exact, throttle part).
  TBURST5  [flagged F2] all 40 canonical throttles with K <= 2: B^5 then A^2600 -> canonical, K' in {K, K-1}
           (INFO line: K = 3, where 3 of 81 throttles end with a dead slot).
  TBURSTJ  [flagged F3] random canonical throttles, B^j (j up to 3000) then A^2600: no halt, all answers E
           (INFO line: how many end canonical; the rest end with a dead slot or big-region leftovers).
  TNEG     zone T is NOT safe for arbitrary visit words: T(R,R) on B A^7 B A^8 B answers C. (Expected PASS = the
           counterexample reproduces; it is why the burst shape in IFACE matters.)
