Round 1 (2026-10-12)

Architecture chosen

proof.md section 10 recommends a verified interpreter. Built a symbolic run-length simulator (ssim) instead of a defect-model interpreter: it runs the machine itself, so the soundness proof is generic (it calls tm for single steps) and only the two sweep cycles are machine-specific.

  • A run is (first symbol, length); a length is a linear form LF c [v0; v1; ...] = c + sum v_i x_i over N. A side is (list run, tail), tail T0 = 0^inf or TV k = abstract side k. ev_cfg nu sg c evaluates a data config to a TM config for a valuation nu : list N of the x_i and sg : nat -> side of the abstract sides.
  • sstep: if the head state and the first symbol of the next run are in a sweep cycle (right B0 C1 A0 B1, left D1 D0 E1 C0) and every coefficient of the run length is 0 mod 4, cross the whole run in one step (state index + c mod 4; the run is pushed, complemented and reversed, onto the other side, merged with its first run when the alternation continues). Otherwise one machine step (pop the head cell; needs c >= 1, or a definitely empty run, which is dropped). Returns a flag: true iff at least one machine step was made.
  • sstep_spec : sstep c = Some (c', b) -> Rel b (ev_cfg nu sg c) (ev_cfg nu sg c') for ALL nu, sg (Rel true = -->+, Rel false = -->*), and runp_spec for runp p (exactly p steps, p positive).
  • Reading an abstract tail makes sstep return None. So a run "until stuck" with abstract sides is a locality proof for free: the lemma holds for every content of the abstract sides.

Conventions for the next rounds (decided in round 1)

  • Cuts. Every region boundary is a cut inside an alternating stretch, never at a defect:
  • chain / right region: after cell B+1 (3 cells after the U0 place of s3 = B-2);
  • block j / block j+1: 3 cells after block j's s3 (U0 place); block j+1 gets I-3 >= 2 cells of the inter gap I (residue 2 mod 4);
  • left word / chain: between cells A-1 and A (block 1 gets 3 cells before its digit at A+2). All footprints of proof.md (Lemma B, L81, R) stay inside their region, so every regional run is an ssim run with the other sides abstract.
  • States at cuts. Entering a block from the right at its phase c: Lc D reading 0. At c+2: Lc C reading 0. Leaving to the right at phase c+2: Rc A (reads 0); at phase c: Rc B (reads 0). (Block bases differ by 2 mod 4, so "c+2 of block j" = "c of block j-1".)
  • Block runs, left side, nearest first (m = 3): with gap lengths a (digit gap), s, t (separator gaps), lp (left part) and state offsets (dd, d1, d2, d3) from proof.md 3.2: [(S0, 3-d3); (_, t+d3-d2); (_, s+d2-d1); (_, a+d1-dd); (_, lp+dd)], symbols by the defect rule (next run starts with the far symbol of the previous one). At rest every block starts with S0 at its right cut, in every state (the region length and the defect count are fixed).
  • Global config at a visit boundary: Lc D (chain runs ++ left word runs, T0) (right runs, T0), the head on cell B+1. Invariant point for Lemma S: Rc A ... at the same cut (after the record visit).
