0. Summary

349 runs W4-2's counter in a mirror, started in W4-2's state F. One transition differs, and it only changes how long one kind of step takes.

  • Conjugacy (Lemma M). 349 is TP mirrored and renamed by f = (A↦F, B↦A, C↦B, D↦C, E↦D, F↦E). So 349 never halts if TP never halts from 0^inf F> 0^inf.
  • Detour (Lemma E). In TP, F1 = 1RC is followed by C1 = 1LA and A1 = 1LF whenever F has a 1 on its right. These three steps leave the tape, head and state exactly as W4-2's single F1 = 1LF does. TP enters F only by A1, which writes that 1, so the condition always holds.
  • Rules. TP's left step therefore computes W4-2's map phi, with 2 extra steps per F1. The right step and the overflow never read F1, so they are W4-2's runs. Hence W4-2's level-1 rules R1–R5 hold on TP with new step counts, and everything above them carries over: the macro rules S0–S3 and P0–P4, the invariant I, Lemma S and Lemma C are statements about phi and integers.
  • Start. From F the run reaches the clean state (std, 2, 2) at step 73, which satisfies I.

2. Notation and families

These are W4-2's (its proof.md §2), repeated so this file can be read alone.

  • Words. A word w is the finite nonzero part of the tape left of the head, plus the cell under it. It is written highest cell first and read as a number: bit d is the cell at offset d, and offset 0 is the cell A reads. Even offsets are E-cells, odd offsets O-cells.
  • W(e, o) is the word with bit d of e on E-cell 2d and bit d of o on O-cell 2d+1. In Rocq this is WS e o.
  • Counters.
  • Standard: std(N) = W(N, 0).
  • Packed: pk(N) = W(N - 2^(P+1), 2^P) for N ≥ 2 with 2^(P+1) ≤ N < 2^(P+2). For example pk(6) = 1100, pk(7) = 1101.
  • std(N) and pk(N) are clean words; every other word is dirty.
  • Configurations (TP). K(w, n, m) = 0^inf w <A 1 (10)^(1+n) 0 (10)^m 0^inf for n, m ≥ 0. The right part is R n m of the .v. A clean overflow state S(typ, N, m) = K(typ(N), 0, m) is written (typ, N, m).
  • The same configuration in 349. Mirror the tape and rename the state (TP's A is 349's B):

K'(w, n, m) = 0^inf (01)^m 0 (01)^(1+n) 1 B> w~ 0^inf

Here w~ is w written from offset 0 to the right. Every rule below holds for K' on 349 with the same step counts (check D). - Parameters of (typ, N, m): i = the number of trailing 1 bits of N, k = N >> (i+1) (so N+1 = (2k+1)·2^i), b = m+1+i, L = bitlen(k), and for pk with k ≥ 1, r = k - 2^(L-1).

3. Rules

3.1 Lemma M: 349 is TP in a mirror

Lemma M. Swap L and R in every transition of TP, and rename TP's states by f⁻¹ (F→A, A→B, B→C, C→D, D→E, E→F). The result is 349, character for character.

  • So flip tm349 (349 with its directions swapped back) at state q is TP at state f(q), for every state and symbol, halting cells included. This is busycoq's Perm (flip tm349) TP f (Permute.v): tm (q,s) = None → tm' (f q, s) = None, and tm (q,s) = Some (s',d,q') → tm' (f q, s) = Some (s',d,f q').
  • Consequence. flip_halts (Flip.v) gives halts tm349 c0 → halts (flip tm349) (A;; tape0), because the blank tape is its own mirror. Then perm_halts gives halts TP (f A;; tape0) = halts TP (F;; tape0).
  • So it suffices to show that TP never halts from 0^inf F> 0^inf.

349's undefined cell F1 is TP's E1. Check T verifies the string identity and both Perm clauses cell by cell. Check Z runs 349 from blank and TP from F in lockstep (state renamed, head at minus the position, every cell mirrored) for 10^6 steps (--full: 5·10^6).

For comparison, Eqv_v3's TM518 tm is W4-2 mirrored and renamed by the same f, and 349 differs from it only in A1 (349: 1LD; TM518 tm: 1RA). That one cell is exactly TP's F1.

3.2 The left step on TP

Lemma E (detour). For every left side l and right side r, on TP:

l 1 <F 1 r   -->(3)   l <F 1 1 r          transitions F1 (1RC), C1 (1LA), A1 (1LF)
  • Proof. F reads the 1 and F1 writes 1 and moves right, so C reads the cell right of F, which is 1. C1 writes 1 and moves left, so A reads F's cell, now 1. A1 writes 1 and moves left, so F reads the last cell of l.
  • W4-2's F1 = 1LF does the same in one step: l 1 <F r --> l <F 1 r, and with r = 1 r' that is the right-hand side above.
  • Why the 1 is always there. The only transition into F is A1 = 1LF (check T). It writes 1 and moves left, so right after F is entered the cell on its right is 1. F leaves F at once (F0 = 1LA, F1 = 1RC). So in every run, every time F reads a cell, the cell on its right holds 1, except for the very first read of a run started in F.
  • 349's form, mirrored: x 1 A> 1 y --(A1 D1 B1)--> x 1 1 A> y.

The eight one-digit lemmas. These are the .v's TA0–TB. Here l and r are arbitrary, cells are written left to right, and a is 0 or 1.

.v lemma TP run transitions TP steps W4-2 steps
TA0 l a 0 <A r --> l a 1 B> r A0 1 1
TA1 l 0 1 <A r --> l <A 1 1 r A1 F0 2 2

TF0 l 0 0 <F r --> l 1 0 B> r F0 A0 B1 3 3

  • TF2' and TF3' need 1 as the first cell of the right side. Without it they are false on TP. For example, W4-2's TF2 with l = 1, r = 0 0^inf never reaches its right-hand side within 40 steps on TP (check TL).
  • In W4-2's .v these are TF2 l r: [1;0] *> l <{{F}} r -->+ l <{{A}} [1;1] *> r and TF3. The restated versions put [1] *> r on the right of both sides.

The left step (phi_spec). The .v reads phi digit pair by digit pair through two relations, PA e o e' o' (A at an E-cell) and PF e o e' o' (F at an E-cell). Their constructors PA0–PA2 and PF0–PF3 are chosen by the parities of e and o. Read as functions they are PA(w) = phi(w) and PF(w) = phi(2w+1) >> 1 (check PS).

Lemma L. On TP, for all e, o and every right side r: - (PA) if PA e o e' o', then WS e o <A r -->+ WS e' o' B> r; - (PF) if PF e o e' o', then WS e o <F 1 r -->+ WS e' o' B> 1 r.

Proof. Mutual induction on the derivation, exactly as W4-2's phi_spec. Each case first rewrites the lowest digit pair, then:

case steps of the proof right side when the hypothesis is used
PA0 TA0 no hypothesis
PA1 TA1, IH (PA), TB 1 1 r
PA2 TA2, IH (PF), TB 1 1 r: starts with 1
PF0 TF0 no hypothesis
PF1 TF1, IH (PF), TB 1 1 1 r: starts with 1
PF2 TF2', IH (PA), TB 1 1 1 r
PF3 TF3', IH (PF), TB 1 1 1 r: starts with 1
  • The PF hypothesis is only ever applied to a right side that starts with 1, which is what the restated (PF) clause demands.
  • TF2' and TF3' are only used in PF cases, whose goal has 1 r on the right by the restated clause.
  • The PA clause is unchanged. It is the only part the rest of the proof uses (PA_spec := proj1 phi_spec). ∎

Left step L. For every word w and every right side r, 0^inf w <A r --> 0^inf phi(w) B> r on TP. - If the last cell of w is 0, this is L0 = A0 (1 step). - Otherwise let (e, e+1) be the lowest pair of adjacent 0 cells. The scan reads offsets 0..e+1 as in W4-2 (its §3.1 L1), and every F1 on the way is a detour. F reads cell c with value 1 exactly when cells c-1 and c are both 1 (1 ≤ c ≤ e-1). - So the step count is L_TP(w) = 2e + 3 + 2·p11(w), where p11(w) counts the adjacent 11 pairs among offsets 0..e-1. - The scan never reads right of offset 0: a detour from F at offset c ≥ 1 reads offset c-1 ≥ 0. The transitions used are A0, A1, F0, F1, C1 and B1.

Check LS runs every word up to 14 cells and 3,000 random words up to 90 cells. It confirms the result, the step count, the untouched right side, and that every F1 is followed by C1 reading 1 and then A1.

3.3 Right step and overflow on TP

These runs are W4-2's, cell for cell, because they never read F1 and TP differs from W4-2 only in F1.

  • Right step RS (n ≥ 1). l B> R n m --> l <A R (n-1) (m+1) in 10n+7 steps, for every l. W4-2 proof.md §3.1 gives the 8-row chain. The run reads F only as F0 (in the shift 01 <A --> <A 11, transitions A1 F0) and never reads E1. Check RS verifies every row of the chain on TP.
  • Overflow OV (n = 0). Let f = phi(w) = x 1 0^q, X = (10)^m 0^inf and Y = (10)^(m+2) 0^inf.
  • OV0: f B> 1 1 0 0 X --> f <C 1 0 1 0 X, 7 steps (B1 B1 B0 C0 D0 C0 D0).
  • CD: 0 0 <C --> <C 1 0 (C0 D0), applied to the 0s of f.
  • OVe (q = 2u): then C1 gives x <A 1 (10)^(u+m+2) 0^inf = K(x, m+1+u, 0), q+8 steps after the left step.
  • OVo (q = 2u+1): C0 and D1 give x <E 0 0 (10)^u Y, q+8 steps. Then E reads the last cell of x:
    • x ends in 1: E1, halt (TP E1 = 349 F1);
    • x = x' 0 0 or 0^inf: E0 A0 B0 C0 D0 C1 give K(x', 0, m+u+2), q+14 steps in all;
    • x ends in 10: E0, then A1 enters an F-scan inside x (no rule; never reached).
  • None of these enters F except the last, nested case. Check OV runs W4-2's OV checks on TP: every f up to 13 cells with m ≤ 3, plus 2,000 random cases.
  • In .v form these are RS, OVe and OVo of W4-2's file, unchanged (check V).

Where a macro rule ends (W4-2 proof.md §3.4). - The overflow states met before the end are dirty (in S2, S3, P3, P4) or empty. - The empty state K(0^inf, 0, M) = S(std, 0, M) occurs once, only in S2 (M = b+L+2) and P0 (M = b). It violates I (N = 0 < M), and S0, which has no hypothesis on m, takes it to the result. - Inside a macro rule every overflow is of kind R2 or R3. R4 and R5 never occur inside a macro rule.

Check B compares each closed form with an abstract execution of R1–R4 (every clean state with m ≤ 90, N ≤ 3m+8, plus 2,000 constructed large states per rule) and with direct runs of both TP and 349 (30 per rule). The two direct runs agree with each other in step count and in every overflow state met.

4. Invariant, coverage, closure

The induction runs over clean overflow states (typ, N, m) with N ≥ 1. All of §4 is W4-2 proof.md §4, unchanged: it uses only the closed forms of §3.6. In W4-2's .v it is I, Cov_S3, Cov_P4, C_S1, C_P1, C_P2, step_std, step_pk and step_I, none of which executes the machine (check V).

4.1 The invariant

  • I0: 1 ≤ m ≤ N (pk: N ≥ 2).
  • Class P (N ≡ m mod 2), with D = N - m:
typ N even N odd
std 2N ≤ 3m+6 N ≤ 2m+3
pk N ≤ 2m+3 2N ≤ 5m+6
  • Class X (N ≢ m mod 2): N ≤ m+3.

In class P, N even ⇔ m even ⇔ i = 0. The weakest bound in every class is 2N ≤ 5m+6.

4.2 Lemma S (coverage): under I, exactly one macro rule applies

The preconditions exclude each other by construction. It remains to rule out the dirty cases that have no rule.

std, k not a power of 2 (k ≥ 2^(L-1)+1). If T = 2k+b+1 ≥ 2^(L+1), S1 or S2 applies. Suppose T < 2^(L+1), so b < 2^L - 3. - i ≥ 1 is impossible: N+1 ≥ 2(2k+1) gives N ≥ 2^(L+1)+5, and N ≤ 2m+3 (I, std with N odd) gives m ≥ 2^L+1, so b ≥ m+2 > 2^L - 3. - i = 0 in class X is impossible: N = 2k ≤ m+3 gives T ≥ 4k-1 > 2^(L+1). - i = 0 in class P (m even): 4k ≤ 3m+6 gives 3T = 6k+3m+6 ≥ 10k. Hence k < 0.6·2^L < 3·2^(L-2) (bit L-2 of k is 0) and T > 3·2^(L-1). T = 2k+m+2 is even, so u ≥ 1 and h ≤ L-3. Finally 3m ≥ 4k-6 ≥ 2^(L+1)-2 gives n = m+2+u > 2^(L-1) ≥ 2^(h+1) - 2g. So S3a or S3b applies.

pk, k not a power of 2 (r ≥ 1). If T = 2r+b+1 ≥ 2^L, P2 or P3 applies. Suppose T < 2^L, so b ≤ 2^L - 4. - i ≥ 2 is impossible: N ≥ 4·2^L + 11 and 2N ≤ 5m+6 give b > 2^L. - Class X is impossible: for i = 1, N ≥ 2^(L+1)+5 and N ≤ m+3 give b > 2^L; for i = 0, N = 2k ≤ m+3 gives T > 2^L. - i = 0, class P: m ≥ k-1, so T ≥ 3r + 2^(L-1) + 1. Hence r < 2^(L-2), T > 2^(L-1), T is even (u ≥ 1), and n ≥ k+1 > 2^(L-1). - i = 1, class P: 5m ≥ 8k-4, so 5T ≥ 18r + 4·2^L + 11. Hence r < 2^(L-2), T > 2^(L-1), T is even (u ≥ 1), and n > 2^(L-1). - In both class-P cases P4a or P4b applies.

4.3 Lemma C (closure): the result of every macro rule satisfies I

Every result is N' = m' + D with D ≥ 0 and m' ≥ 1. So I0 holds, and it remains to bound D.

rule D why the bound holds
S0, S2, P0, P3 0
S1 2k (result pk, m' = b) i = 0 class P: 4k ≤ 3b+3; i = 0 class X: 2k ≤ b+2; i ≥ 1: 2k ≤ m+1 < b
P1 k = 2^(L-1) (result std) k = 1: class X, D = 1; k ≥ 2: from k ≤ m+1, 2k ≤ m+3, or 2N ≤ 5m+6 by the parity of i
P2 2r < k (result std) the same bounds as P1, now on 2r < k
S3, P4 3·2^h, or 2^(h+1)+2g ≤ 2^(h+2)-2; so D < 2^(L-u) m' = n > 2^(L-1) and n ≡ u (mod 2); h = 0 gives D = 3 (class X); u odd: D < n; u even: 2D < n

W4-2 proof.md §4.3 writes out every inequality. Check M re-runs W4-2's INV checks under this seed: every state with I and m ≤ 700 (251,124 states; --full: m ≤ 1300, 856,374 states), plus 300,000 random boundary states up to m ≈ 2^60, with every inequality step of Lemma S and Lemma C as its own check.

5. Progress and halting

  • Progress. Every macro rule contains an overflow and at least one bounce, so it takes at least 9 steps. Also m' ≥ m+1 in every rule (checks M and B).
  • Halting. TP's only undefined transition is E1 (349: F1). E is entered only by D1, in two places:
  • in RS, where E reads a cell that B has just written 0;
  • in OVo, where E reads the last cell of x.
  • Inside the macro rules OVo occurs only with x = 0^inf (in S2 and P0), where E reads 0.
  • The left step never enters E: its transitions are A0, A1, F0, F1, C1 and B1, and a detour goes F1, C1, A1 and never through D.
  • So under I, E1 is never executed.

7. Conclusion

7.1 Non-halting

  • 349 never halts from blank if TP never halts from 0^inf F> 0^inf (Lemma M).
  • TP reaches S(std, 2, 2) at step 73, and I holds there (§6).
  • If I(s), exactly one macro rule takes s →+ s' (Lemma S), and I(s') holds (Lemma C).
  • Every macro rule is a finite chain of the exact rules of §3.2–§3.4, and none of them executes E1 (§5).

By induction TP runs forever from F. In busycoq terms: progress_nonhalt_cond with P := I on states (typ, N, m), after multistep_nonhalt with the 73-step start from F; then flip_halts and perm_halts for 349.

7.2 Why it is not a cryptid

The branch taken in each cycle depends on bit patterns of N, which look pseudo-random. But I is closed under every branch, using only linear bounds and two parity facts (W4-2 proof.md §7.2). The detour changes step counts only, never a branch. Ground rule 6 does not apply.

7.3 A remark: the run is W4-2's run, stretched

By §3.2 (Lemma E and "why the 1 is always there"), TP's run from F is W4-2's run from F with every F1 replaced by the three steps F1 C1 A1, and nothing else changed. Check Z confirms this in lockstep for 3·10^6 W4-2 steps (--full: 3·10^7 steps, 479 detours, TP steps = W4-2 steps + 2·479). The proof above does not use this remark: it re-proves the machine-level lemmas on TP directly, which is also what the .v does.
