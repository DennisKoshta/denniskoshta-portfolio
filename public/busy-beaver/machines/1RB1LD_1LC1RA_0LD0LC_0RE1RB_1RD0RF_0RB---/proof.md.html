2. Notation and families

This is W4-2's notation, repeated so this file can be read alone.

  • Configurations in general. l <S r is state S reading the last cell of l; l S> r is state S reading the first cell of r. Cells are written left to right.
  • Words. A word w is the finite nonzero part of the tape left of the head, plus the cell under it. It is written highest cell first and read as a number: bit d is the cell at offset d, and offset 0 is the cell A reads. Even offsets are E-cells, odd offsets O-cells.
  • W(e, o) is the word with bit d of e on E-cell 2d and bit d of o on O-cell 2d+1. Every word is W(e, o) for exactly one pair. In Rocq this is WS e o.
  • Hi·W_h(c, o) is the high word Hi shifted up by 2h cells, above a low part of 2h cells holding c, o < 2^h.
  • Counters.
  • Standard: std(N) = W(N, 0).
  • Packed: pk(N) = W(N - 2^(P+1), 2^P) for N ≥ 2 with 2^(P+1) ≤ N < 2^(P+2). For example pk(6) = 1100, pk(7) = 1101.
  • std(N) and pk(N) are clean words; every other word is dirty.
  • Configurations (TP). K(w, n, m) = 0^inf w <A 1 (10)^(1+n) 0 (10)^m 0^inf for n, m ≥ 0. The right part is R n m of the .v. A clean overflow state S(typ, N, m) = K(typ(N), 0, m) is written (typ, N, m).

3. Rules

3.1 Lemma M: 349 is TP in a mirror

Lemma M. Swap L and R in every transition of TP, and rename TP's states by f⁻¹ (F→A, A→B, B→C, C→D, D→E, E→F). The result is 349, character for character.

  • So flip tm349 (349 with its directions swapped back) at state q is TP at state f(q), for every state and symbol, halting cells included. This is busycoq's Perm (flip tm349) TP f (Permute.v): tm (q,s) = None → tm' (f q, s) = None, and tm (q,s) = Some (s',d,q') → tm' (f q, s) = Some (s',d,f q').
  • Consequence. flip_halts (Flip.v) gives halts tm349 c0 → halts (flip tm349) (A;; tape0), because the blank tape is its own mirror. Then perm_halts gives halts TP (f A;; tape0) = halts TP (F;; tape0).
  • So it suffices to show that TP never halts from 0^inf F> 0^inf.

349's undefined cell F1 is TP's E1. Check T verifies the string identity and both Perm clauses cell by cell. Check Z runs 349 from blank and TP from F in lockstep (state renamed, head at minus the position, every cell mirrored) for 10^6 steps (--full: 5·10^6).

For comparison, Eqv_v3's TM518 tm is W4-2 mirrored and renamed by the same f, and 349 differs from it only in A1 (349: 1LD; TM518 tm: 1RA). That one cell is exactly TP's F1.

3.2 The left step on TP

Lemma E (detour). For every left side l and right side r, on TP:

l 1 <F 1 r   -->(3)   l <F 1 1 r          transitions F1 (1RC), C1 (1LA), A1 (1LF)
  • Proof. F reads the 1 and F1 writes 1 and moves right, so C reads the cell right of F, which is 1. C1 writes 1 and moves left, so A reads F's cell, now 1. A1 writes 1 and moves left, so F reads the last cell of l.
  • W4-2's F1 = 1LF does the same in one step: l 1 <F r --> l <F 1 r, and with r = 1 r' that is the right-hand side above.
  • Why the 1 is always there. The only transition into F is A1 = 1LF (check T). It writes 1 and moves left, so right after F is entered the cell on its right is 1. F leaves F at once (F0 = 1LA, F1 = 1RC). So in every run, every time F reads a cell, the cell on its right holds 1, except for the very first read of a run started in F.
  • 349's form, mirrored: x 1 A> 1 y --(A1 D1 B1)--> x 1 1 A> y.

Left step L. For every word w and every right side r, 0^inf w <A r --> 0^inf phi(w) B> r on TP. - L0 (w_0 = 0). A0 = 1RB writes 1 and moves right: l 0 <A r --> l 1 B> r in 1 step. - L1 (w_0 = 1). Let (e, e+1) be the lowest pair of adjacent 0 cells (the 0s above w count), so e ≥ 1. The cells at offsets 0..e-1 contain no 00, and w_(e-1) = 1, since otherwise (e-1, e) would be a lower pair.

Proof of L1. The head moves left through offsets 0, 1, …, e+1, reading each cell once (apart from the detours). We show by induction on d: when offset d (1 ≤ d ≤ e+1) is read, every cell at offsets 0..d-1 is now 1, and the state is F if w_(d-1) = 1 and A if w_(d-1) = 0.

  • d = 1: A reads w_0 = 1. A1 = 1LF writes 1 and moves left, so F reads offset 1.
  • F reads a 1 at offset d (1 ≤ d ≤ e-1). The cell on its right, offset d-1, is 1 by the induction hypothesis, so Lemma E applies: three steps (F1 C1 A1) later, offset d is 1 and F reads offset d+1.
  • F reads a 0 at offset d ≤ e-1. F0 = 1LA writes 1, and A reads offset d+1. That cell is 1: d+1 ≤ e-1 (d+1 = e would make (d, e) a lower 00 pair), and w_d = 0 has no 0 next to it below offset e. A1 = 1LF writes 1, and F reads offset d+2.
  • So A only ever reads a 1 inside offsets 1..e-1, and the claim holds up to d = e.
  • At d = e, F reads the 0 (w_(e-1) = 1). F0 = 1LA writes 1, and A reads offset e+1, which is 0. A0 = 1RB writes 1 and moves right.
  • B now meets the e+1 ones at offsets e, …, 0. B1 = 0RB clears each and moves right, ending at B> r.

The result has 1 at offset e+1 and 0 at offsets 0..e, which is phi(w). ∎

  • Step count. W4-2's run of L1 takes e reads below offset e, then F0, A0 and e+1 B1 steps: 2e+3. On TP every F-read of a 1 costs 3 steps instead of 1. F reads offset d with value 1 exactly when w_(d-1) = w_d = 1 (1 ≤ d ≤ e-1). So L_TP(w) = 2e + 3 + 2·p11(w), where p11(w) counts the adjacent 11 pairs among offsets 0..e-1.
  • Locality. The scan never reads right of offset 0: a detour from F at offset d ≥ 1 reads offset d-1 ≥ 0. The transitions used are A0, A1, F0, F1, C1 and B1.

Check LS runs every word up to 14 cells and 3,000 random words up to 90 cells. It confirms the result, the step count, the untouched right side, and that every F1 is followed by C1 reading 1 and then A1.

3.5 phi in E/O coordinates

These lemmas concern only the map phi, which is the same for TP and W4-2. The proofs below are W4-2's. In W4-2's .v they are lemmas about the relations PA/PAs (Gap, Gaps, F_inc, F_carry, Sweep, INC_std, INC_pk, the orbit lemmas inside BS_*), and none of them mentions the machine.

Lemma SW. Let Hi be any word, h ≥ 1, 1 ≤ o < 2^h, P = tz(o), 0 ≤ c < 2^(P+1), and w = Hi·W_h(c, o). - (i) If c < 2^(P+1) - 1, then phi(w) = Hi·W_h(c+1, o). - (ii) If c = 2^(P+1) - 1 and o' := o + 2^P < 2^h, then phi(w) = Hi·W_h(0, o'). - Its lowest 1 is the O-cell 2g+1, g = tz(o'): a landing. - The two cells above it (offsets 2g+3, 2g+2) are (bit g+1 of o, 0) if g+1 < h, and the two lowest cells of Hi if g = h-1. - (iii) If c = 2^(P+1) - 1 and o + 2^P = 2^h, then phi(w) = phi(Hi·1)·0^(2h-1), where Hi·1 is Hi with one cell 1 appended below it.

Proof. The low part below offset 2P+1 has E-cells = the bits of c and O-cells = 0. No E-bit of c lies above P. - (i) Let d ≤ P be the lowest 0 bit of c. - If d = 0, the last cell is 0 and becomes 1. - If d ≥ 1, the cells 0..2d-2 alternate (E = 1, O = 0). So every pair of adjacent cells below 2d-1 contains a 1. - Cells 2d-1 (an O-cell below 2P+1, so 0) and 2d (bit d of c, 0) form the lowest 00 pair. phi sets cell 2d and clears 0..2d-1, which gives c+1. - (ii) and (iii) The counter is full: all E-cells ≤ 2P are 1. Let s ≥ 1 be the length of the run of 1 bits of o starting at bit P. - The O-cells 2P+1, …, 2P+2s-1 are 1, and the E-cells between them are 0 (bits of c above P). - So every pair of adjacent cells up to offset 2P+2s-1 contains a 1. - Case P+s < h. Cells 2P+2s (E, bit P+s of c, 0) and 2P+2s+1 (O, bit P+s of o, 0) are the lowest 00 pair. phi sets the O-cell 2(P+s)+1 and clears everything below, which gives o + 2^P with c = 0. The two cells above the landing are the E-cell 2g+2, which is 0, and the O-cell 2g+3, which is bit g+1 of o. When g = h-1 these two cells are the lowest two cells of Hi. - Case P+s = h. Cell 2h-1 is 1 and nothing below it is a 00 pair. 3.6 Macro rules

Each macro rule is a finite chain of R1–R3 from a clean state S(typ, N, m) to the first later overflow state K(w', 0, m') whose word w' is clean with N' ≥ 1. The variables are those of §2, and for S3/P4 also v, u, h, g, n, D of §1.

Overflow words of clean counters. Let N+1 = (2k+1)2^i. - std. phi(std(N)) = std(N+1) has its lowest 1 at E-cell 2i. The cells above it are the bits of k, now on O-cells. So q = 2i and x = W(0, k). - pk, k = 0 (N = 2^i - 1, i ≥ 2). phi(pk(N)) = W(0, 2^(i-1)): q = 2i-1 and x = 0^inf, so R3 applies, with m + (q+3)/2 = b. - pk, k ≥ 1. phi(pk(N)) = pk(N+1) = W(N+1-2^(P+1), 2^P) has its lowest 1 at E-cell 2i (i ≤ P). The E-bits above it move to O-cells, and the top O-cell 2P+1 moves to E-cell 2(P-i). So q = 2i and x = W(2^(L-1), r) with L = P-i+1. For r = 0 this is std(k).

Then R2 gives K(x, b, 0), and R1^b gives K(phi^b(x), 0, b). If that word is not clean, the next overflow sees phi^(b+1)(x).

Where a macro rule ends. Each macro rule runs from S(typ, N, m) to the first overflow state K(w', 0, m') whose word w' is clean with N' ≥ 1. That state is the result column. S0 has no hypothesis on m. - So S2 = (run to (std,0,M)) followed by S0, and the same holds for P0.

The overflows inside a macro rule. Each one is of one of these kinds: - a clean counter (q even, or q odd with x = 0^inf, the all-ones pk); - O3's top word 1 0^(2L+1) (R3 with x = 0^inf); - std(2^L) in P3 (q even); - a final-gap word with v ≥ 1 (q = 2u even); - K(0^inf, 0, M) (q = 0).

So R4 and R5 never occur inside a macro rule. The landings of the gen-2 orbits O5/O6 (the last possible one, at T = 2^h, has 01 or 11 above it) all come before j0 ≤ n. They happen during bounces, where R1 applies to any word, so they do no harm.

4. Invariant, coverage, closure

The induction runs over clean overflow states (typ, N, m) with N ≥ 1. §4 uses only the closed forms of §3.6, so it is the same as for W4-2, and the arguments below are W4-2's. In W4-2's .v it is I, Cov_S3, Cov_P4, C_S1, C_P1, C_P2, step_std, step_pk and step_I, none of which executes the machine (check V).

4.1 The invariant

  • I0: 1 ≤ m ≤ N (pk: N ≥ 2).
  • Class P (N ≡ m mod 2), with D = N - m:
typ N even N odd
std 2N ≤ 3m+6 N ≤ 2m+3
pk N ≤ 2m+3 2N ≤ 5m+6
  • Class X (N ≢ m mod 2): N ≤ m+3.

In class P, N even ⇔ m even ⇔ i = 0. The weakest bound in every class is 2N ≤ 5m+6.

4.2 Lemma S (coverage): if I(s), exactly one macro rule applies to s

The preconditions are mutually exclusive by construction (k = 0 / k a power of 2 / k not, and the position of T). It remains to show that a state with I never falls outside them: it is never dirty outside the final gap, and the gen-2 merge comes in time.

std, k not a power of 2 (so k ≥ 3, L ≥ 2, k ≥ 2^(L-1)+1). T = 2k+b+1. T > 2^(L+1) gives S1 and T = 2^(L+1) gives S2. Suppose T < 2^(L+1); then b < 2^(L+1) - 1 - 2k ≤ 2^L - 3. - i ≥ 1 is impossible: N+1 = (2k+1)2^i ≥ 2(2^L+3), so N ≥ 2^(L+1)+5, and I gives N ≤ 2m+3 (std, N odd, either class). So m ≥ 2^L+1 and b ≥ m+2 > 2^L - 3. - i = 0 in class X is impossible: N = 2k ≤ m+3 gives b = m+1 ≥ 2k-2, so T ≥ 4k-1 > 2^(L+1). - i = 0 in class P (m even): 4k ≤ 3m+6, so 3T = 6k+3m+6 ≥ 10k. - T ≤ 2^(L+1)-1 gives k < 0.6·2^L < 3·2^(L-2), so bit L-2 of k is 0. - T ≥ 10k/3 > 3·2^(L-1). - So S3's range holds. - T = 2k+m+2 is even, so v is even and u ≥ 1. - 3m ≥ 4k-6 ≥ 2^(L+1)-2 gives n = m+2+u > 2^(L-1) ≥ 2^(h+1) ≥ j0, so in case g ≥ 1 the S3b condition holds.

pk, k not a power of 2 (r ≥ 1, L ≥ 2). T = 2r+b+1. T > 2^L gives P2 and T = 2^L gives P3. Suppose T < 2^L, so b ≤ 2^L - 4. Also N+1 = (2k+1)2^i with 2k+1 ≥ 2^L+3. - i ≥ 2 is impossible: N ≥ 4·2^L + 11, and the weakest bound 2N ≤ 5m+6 gives m > 2^L, so b > 2^L. - Class X is impossible. - i = 1: N ≥ 2^(L+1)+5 and N ≤ m+3 give m > 2^L, so b > 2^L. - i = 0: N = 2k ≤ m+3 gives T ≥ 2r+2k-1 = 2^L+4r-1 > 2^L. - i = 0, class P (m, N even): N ≤ 2m+3 means 2k ≤ 2m+2, so m ≥ k-1. - Then T = 2r+m+2 ≥ 3r + 2^(L-1) + 1 > 2^(L-1). - T < 2^L gives 3r < 2^(L-1), so r < 2^(L-2), and L ≥ 3 follows. - T is even, so u ≥ 1. - n = m+2+u ≥ k+1 > 2^(L-1) ≥ j0. - i = 1, class P (m odd, N = 4k+1): 2N ≤ 5m+6 gives 5m ≥ 8k-4. Then 5T = 10r+5m+15 ≥ 18r + 4·2^L + 11. - T < 2^L gives 18r < 2^L - 11, so r < 2^(L-2). - T ≥ (4·2^L+11)/5 > 2^(L-1). - T = 2r+m+3 is even, so u ≥ 1. - n = m+3+u ≥ (8k-4)/5 + 3 > 2^(L-1) ≥ j0.

So under I the dirty cases are exactly: std with i = 0 in class P (S3), and pk with i ≤ 1 in class P (P4). Each is in its final gap (past every landing of its gen-1 orbit) with u ≥ 1, and its gen-2 orbit merges before the next overflow.

4.3 Lemma C (closure): if I(s) and s → s' by a macro rule, then I(s')

Each result has the form N' = m' + D with D ≥ 0 and m' ≥ 1, so I0 holds (for pk, N' ≥ 2). It remains to bound D.

  • S0, S2, P0, P3: D = 0.
  • S1: D = 2k, class P, m' = b, and the result is pk. We need D ≤ b+3 (b even) or 2D ≤ 3b+6 (b odd).
  • i = 0, class P (b odd): 4k ≤ 3m+6 = 3b+3.
  • i = 0, class X (b even): 2k = N ≤ m+3 = b+2.
  • i ≥ 1: N+1 ≥ 2(2k+1) gives 2k ≤ (N-1)/2 ≤ m+1 < b (I: N ≤ 2m+3 for std with N odd). Both bounds hold.
  • P1: D = k = 2^(L-1), m' = b, and the result is std.
  • k = 1: class X with D = 1.
  • k ≥ 2: class P. We need 2k ≤ b+6 (b even) or k ≤ b+3 (b odd).
    • i = 0, class P: k ≤ m+1 and b = m+1 is odd.
    • i = 0, class X: 2k ≤ m+3 and b = m+1 is even.
    • i ≥ 1, class P (m odd, so b = m+1+i ≡ i mod 2), using 2N ≤ 5m+6:
    • i odd: k ≤ (N-1)/4 ≤ (5m+4)/8 ≤ b+3;
    • i even ≥ 2: 2k ≤ (N-3)/4 ≤ 5m/8 ≤ b+6.
    • i ≥ 1, class X: 2k ≤ (N-1)/2 ≤ (m+2)/2.
  • P2: D = 2r < k (since r < 2^(L-1) ≤ k-r), class P, m' = b, and the result is std. We need 4r ≤ b+6 (b even) or 2r ≤ b+3 (b odd).
  • i = 0, class P (b odd): 2r < k ≤ m+1 = b.
  • i = 0, class X (b even): 4r < 2k ≤ m+3 = b+2.
  • i odd, class P (b odd): 2r < k ≤ (5m+4)/8.
  • i even ≥ 2, class P (b even): 4r < 2k ≤ 5m/8.
  • i ≥ 1, class X: 4r < 2k ≤ (m+2)/2.
  • S3, P4: D = 3·2^h (g = 0) or 2^(h+1)+2g ≤ 2^(h+2)-2 (g ≥ 1), so D < 2^(h+2) = 2^(L-u). Here m' = n > 2^(L-1) (Lemma S) and n ≡ u (mod 2): n = m+2+u with m even, or n = m+3+u with m odd.
  • h = 0: then g = 0 and D = 3, class X.
  • h ≥ 1: D is even, class P.
    • u odd (n odd): D < 2^(L-1) < n, which gives D ≤ n+3 and 2D ≤ 3n+6.
    • u even ≥ 2 (n even): D < 2^(L-2), so 2D < 2^(L-1) < n, which gives 2D ≤ n+6 and D ≤ n+3.

5. Progress and halting

  • Progress. Every macro rule contains an overflow and at least one bounce, so it takes at least 9 steps. Also m' ≥ m+1 in every rule (checks M and B).
  • Halting. TP's only undefined transition is E1 (349: F1). E is entered only by D1, in two places:
  • in RS, where E reads a cell that B has just written 0;
  • in OVo, where E reads the last cell of x.
  • Inside the macro rules OVo occurs only with x = 0^inf (in S2 and P0), where E reads 0.
  • The left step never enters E: its transitions are A0, A1, F0, F1, C1 and B1, and a detour goes F1, C1, A1 and never through D.
  • So under I, E1 is never executed.

7. Conclusion

7.1 Non-halting

  • 349 never halts from blank if TP never halts from 0^inf F> 0^inf (Lemma M).
  • TP reaches S(std, 2, 2) at step 73, and I holds there (§6).
  • If I(s), exactly one macro rule takes s →+ s' (Lemma S), and I(s') holds (Lemma C).
  • Every macro rule is a finite chain of the exact rules of §3.2–§3.4, and none of them executes E1 (§5).

By induction TP runs forever from F. In busycoq terms: progress_nonhalt_cond with P := I on states (typ, N, m), after multistep_nonhalt with the 73-step start from F; then flip_halts and perm_halts for 349.

7.2 Why it is not a cryptid

The branch taken in each cycle depends on bit patterns of N, which look pseudo-random. But I is closed under every branch. Lemma C uses only linear bounds and two parity facts: N ≡ m in class P, and T even at the dirty overflows. Halting is excluded by inequalities, not by residues. The detour changes step counts only, never a branch. Ground rule 6 does not apply.

7.3 A remark: the run is W4-2's run, stretched
