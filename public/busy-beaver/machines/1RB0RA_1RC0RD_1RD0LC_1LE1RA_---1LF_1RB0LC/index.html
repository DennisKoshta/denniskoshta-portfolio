Mechanism

How it works: 3 notes
  • Bell + counter: a 00 marker in a field of 101 blocks moves one block right per pass (F); each pass first adds 1 to a base-3 counter on the right (K1-K6 = the cert's side_3ary rule, mirrored).
  • Counter digits can be wide: d (110)^n 0 with d = 000/110/010 for 0/1/2 (n = 0 gives 0000/1100/0100); rules I0, I2, I1a, I1b. A digit right after a wide 2 uses 0011/1111/0111 (J0, J1).
  • From A the tape holds two big bells that take turns (the idle one is a wide digit), one small wide digit and 4-cell digits, up to 5e9; start B has one bell. Bell hand-over (E) and the carry past J2 are not pinned. Only halt: A> 0 1 0; none in 1e10 steps.
