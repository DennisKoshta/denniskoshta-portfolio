0. The map

M state 0 1 = σ(M_P state) M_P 0 M_P 1
A 1RB 1RF σ(C) 1RD 1RF
B 1LC 0LE σ(D) 1LA 0LE
C 1RD 0LB σ(A) 1RB 0LD
D 1RA 0RC σ(B) 1RC 0RA
E 1RE 1LB σ(E) 1RE 1LD
F 0RD --- σ(F) 0RB ---

σ: A↦C, B↦D, C↦A, D↦B, E↦E, F↦F. It is an involution. M's row σ(s) equals M_P's row s with every target state t replaced by σ(t). For example, M_P's A1 = 0LD becomes 0Lσ(D) = 0LB, which is M's C1. Symbols and directions are unchanged.

Lemma R (relabelling). For a configuration c, let σc be c with its head state renamed by σ; the tape and the head position stay the same. Then c → c′ in M_P if and only if σc → σc′ in M, and c is halted exactly when σc is. So every M_P run c →ⁿ c′ gives an M run σc →ⁿ σc′ of the same length, and conversely.

Proof. The transition of M in state σ(s) reading b is M_P's transition in state s reading b, with its target state renamed by σ, and F is undefined on 1 in both. ∎

Start. M's c0 is 0^inf A> 0^inf = σ(0^inf C> 0^inf). M_P's own run starts in A, and after two steps (A0 = 1RB, B0 = 1RC) it is at 0^inf 1 1 C> 0^inf. So M's run is M_P run from 0^inf C> 0^inf: M_P's run without the two 1s that its first two steps write. It is not M_P's run.

Halting cell. In M, only A1 enters F, and only D0 enters A. So M halts exactly when it reaches D> 0 1 1, which is σ of M_P's B> 0 1 1.

3. The argument (complete)

Theorem. 1RB1RF_1LC0LE_1RD0LB_1RA0RC_1RE1LB_0RD--- does not halt from the blank tape.

  1. Initial segment. M runs from c0 to B′ in exactly 79,114 steps without halting. This is a finite exact computation (§2); in the .v it is init, one esx.
  2. Base. INV+(e)(B′) holds (§2).
  3. Transfer. The period theorem (statement P§3.8.1, proof P§3.8.4) says: from an E-start satisfying INV+(e), every K up to the next E-start is in D, INV+(e) holds again there, and there are at least two macro steps, each of at least one machine step. Its statement and proof use only the rules of P§2 and arithmetic on (h, P, T). By Lemma R, each rule instance K_P(h; P; T) →⁺ K_P(h′; P′; T′) of M_P is an M run K(h; P; T) →⁺ K(h′; P′; T′) of the same length, since K = σK_P. So the theorem holds verbatim for M's configurations K(h; P; T).
  4. Conclusion. By induction from B′, M's run is an infinite chain of rule applications, each taking at least one step, so it never halts. This is the reduction of P§3.1 with K0 and B replaced by K0′ and B′. A rule application never presents the halting cell D> 0 1 1, because each rule is an exact computation from one K to the next. ∎

The argument for M_P depends on M_P's own orbit only through its initial segment and base (P§3.7, and the base values quoted in P§3.3 and P§3.8.1); here §2 replaces them. The orbit statistics in P§3.3 and P§5 (r values, merge counts, X1 count) are evidence, not premises.

4. How M's orbit relates to M_P's (explanation, not a premise)

Observation. From the first canonical configuration on, the canonical configurations of M and of M_P correspond one to one. At each of them, M's K and M_P's K_P have the same parameters except that exactly one exponent of M's is larger by 2, and from K0′ on the two orbits apply the same rule at every macro step. The larger exponent is always in the far block:

where the +2 sits when
q_L, the far pair's q regular E-starts and through the E-cycle
p_L, the last pair's p (t₀ in P§3.4) L-starts, until EndLast
t in T1(t) after EndLast / DecMergeTail, until Ov
k in T2(k) after X1, until X2, whose new pair (3, k, 1) puts it back on q_L
h only at step 20, where M has h = 2 and M_P has h = 0; at step 359 it is already on p_1 = p_L

Each cycle has the same rule sequence and the same number of decrements in both orbits (§6 gives the range checked).

Lemma C (a corollary of P§3.4). - Take an E-start X = K_P(h; P; T) of M_P that satisfies INV+(e), and let X⁺ be X with q_L (or k, at a T2 start) raised by 2. Then the cycle pair from X⁺ applies the same rules as the one from X, and it ends at M_P's next E-start after X with q_L raised by 2. - In the E-cycle, the far pair (or the pair X2 appends, whose q is k) gets exactly two touches (P§3.4 S1: q_L ≥ 6, or k ≥ 4, and it loses 2). Its q is at least 3 at each touch from X, so also from X⁺. The only branch either touch reads is "q = 1 or q ≥ 2": the borrow touch is a Dec (not DecMergeTail or DecMergeEmpty), and at V = 0 the rule is End (not EndLast or X1). The Ov then copies q_L into the new last pair's p. - In the L-slot, that p (t₀) is never compared. It enters only additively, with coefficient 1, in these places: - EndLast's t = p + 4; - the fused p of a DecMerge at M−1; - X1's T2 parameter; - DecMergeTail's t. - t and k likewise enter only additively: Ov's last-pair q = t + 1, and X2's new q = k. - So the +2 never changes a branch, and it never reaches an interior pair. This is why INV+(e) needs no change.

This also accounts for the small size difference at 10⁹ steps (§6). M lags M_P by a slowly growing number of steps: 132 steps at K0′ and 404 at the base, because every sweep over the far block is 4 cells longer. So the trajectories are not identical, but they are coupled exactly.
