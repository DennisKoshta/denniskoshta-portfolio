0. The map

σ: A↦C, B↦D, C↦A, D↦B, E↦E, F↦F. It is an involution. Twin row σ(s) equals parent row s with every target state t replaced by σ(t). For example, parent A1 = 0LD becomes 0Lσ(D) = 0LB, which is twin C1. Symbols and directions are unchanged.

check_proof.py §S searches all 720 renamings, each with and without mirroring. σ is the only map that works.

Lemma R (relabelling). For a configuration c, let σc be c with its head state renamed by σ; the tape and head position stay the same. Then c → c′ in the parent if and only if σc → σc′ in the twin, and c is halted exactly when σc is. So every parent run c →ⁿ c′ gives a twin run σc →ⁿ σc′ of the same length, and the converse also holds.

Start. The twin's c0 is 0^inf A> 0^inf = σ(0^inf C> 0^inf). The parent's own run starts in A, and after two steps (A0 = 1RB, B0 = 1RC) it is at 0^inf 1 1 C> 0^inf. So the twin's run is the parent's machine run from 0^inf C> 0^inf: the parent's run without the two 1s its first two steps write. It is not the parent's run. §S checks the twin from blank against the relabelled parent from 0^inf C> 0^inf in lockstep: 2·10⁶ steps, identical at every step.

Halting cell. Only A1 enters F in the twin, and only D0 enters A. So the twin halts exactly when it reaches D> 0 1 1, which is σ of the parent's B> 0 1 1.

3. The argument (complete)

Theorem. 1RB1RF_1LC0LE_1RD0LB_1RA0RC_1RE1LB_0RD--- does not halt from the blank tape.

  1. Initial segment. The twin runs from c0 to B′ in exactly 79,114 steps without halting. This is a finite exact computation (§C, §D); in Rocq it is one esx.
  2. Base. INV+(e)(B′) holds (§2).
  3. Transfer. The parent's period theorem (P§3.8.1, proof P§3.8.4) says: from an E-start satisfying INV+(e), every K up to the next E-start is in D, INV+(e) holds again there, and there are at least two macro steps, each of at least one machine step. Its statement and proof use only the rules of P§2 and arithmetic on (h, P, T). By Lemma R, each rule instance K →⁺ K′ of the parent is a twin run σK →⁺ σK′ of the same length. So the theorem holds verbatim for the twin's configurations σK.
  4. Conclusion. By induction from B′, the twin's run is an infinite chain of rule applications, each taking at least one step, so it never halts. This is the parent's P§3.1 reduction with K0, B replaced by K0′, B′. A rule application never presents the halting cell D> 0 1 1, because each rule is an exact computation from one K to the next. ∎

Nothing in the parent's argument depended on the parent's own orbit beyond P§3.7. The orbit-specific statistics in P§3.3 and P§5 (r values, merge counts, X1 count) are evidence, not premises.

4. How the twin's orbit relates to the parent's (the coupling; explanation, not a premise)

Observation. At every macro step from the first canonical configuration on, the twin's K is the parent's K with exactly one exponent larger by 2, and the two orbits apply the same rule. The larger exponent is always the far block:

where the +2 sits when
q_L, the far pair's q regular E-starts and through the E-cycle
p_L, the last pair's p (P§3.4's t₀) L-starts, until EndLast
t in T1(t) after EndLast / DecMergeTail, until Ov
k in T2(k) after X1, until X2, whose new pair (3, k, 1) puts it back on q_L
h only at step 20, where twin h = 2 and parent h = 0; at step 359 it is already on p_1 = p_L

Checked at every macro step to L = 16 (539,656 steps) and at every re-pairing to L = 300 (§X2, 1,089 re-pairings, including 3 X1/X2 detours). It was also checked to L = 600 (2,209 re-pairings; check_proof.py --lmax 600, output in check_proof_l600.out). Each cycle has the same rule sequence and the same number of decrements.

Why it persists (Lemma C, a corollary of P§3.4). - Take a parent E-start K that satisfies INV+(e), and let K⁺ be K with q_L (or k, at a T2 start) raised by 2. Then the cycle pair from K⁺ applies the same rules, and it ends at the parent's next E-start with q_L raised by 2. - In the E-cycle, the far pair (or the pair X2 appends, whose q is k) gets exactly two touches (P§3.4 S1: q_L ≥ 6, or k ≥ 4, and it loses 2). Its q is at least 3 at each touch in the parent, so also in the twin. The only branch either touch reads is "q = 1 or q ≥ 2": the borrow touch is a Dec (not DecMergeTail or DecMergeEmpty), and at V = 0 the rule is End (not EndLast or X1). The Ov then copies q_L into the new last pair's p. - In the L-slot, that p (t₀) is never compared. It enters only additively, with coefficient 1, in these places: - EndLast's t = p + 4; - the fused p of a DecMerge at M−1; - X1's T2 parameter; - DecMergeTail's t. - t and k likewise enter only additively: Ov's last-pair q = t + 1, and X2's new q = k. - So the +2 never changes a branch, and it never reaches an interior pair. That is why INV+(e) needs no change.

This also accounts for the size difference at 10⁹ steps: - twin: 67,347 cells (−67,163..183) and 33,668 nonzeros; - parent: 67,343 cells and 33,665 nonzeros.

The twin lags the parent by a slowly growing number of steps: 132 steps at K0′ and 404 at the base, because every sweep over the far block is 4 cells longer. The trajectories are therefore not identical, but they are coupled exactly.
