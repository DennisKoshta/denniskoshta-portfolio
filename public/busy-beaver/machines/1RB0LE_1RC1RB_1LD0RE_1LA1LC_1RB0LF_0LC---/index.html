Mechanism

How it works: 3 notes
  • Same table as ChaoticBell1Halt.v TM13 (ours A,B,C,D,E,F = TM13 D,A,B,C,E,F; no mirror): our blank start is TM13 started in D. All TM13 lemmas hold verbatim; 26 rules + the halt window pass 40/40 random instances here.
  • A bell over digits D n = 1^(2n+1) 00: B> 0100 sweeps right (D n -> S n = 1(01)^(n+1)), <C 1 sweeps back. Each 111 on the left is one call (sweep to the right end, append 100 100); PL blocks replay calls; the far left turns the head (over1/over2). Direct sim: no halt to 1e9 (sheet: 1e13); left-end tapes are clean D-digit lists.
  • Port of ccz181078's certified executor (CBSim): reproduces TM13's halt (tick 64,832) and TM7's (65,400), matches direct sim for 4,000 ticks (21.1M steps). Our start: no halt in 16,551,000 ticks; 602's start: none in 10,000,000; 299's: none in 7,627,000. After ~4e5 ticks the run turns regular: a stack of PL(n)^k_n, n = 0,1,2,..., counts ~1e31 falling ~5x per two levels, small remainders.
