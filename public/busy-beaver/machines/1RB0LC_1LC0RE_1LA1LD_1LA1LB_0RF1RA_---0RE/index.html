Mechanism

How it works: 3 notes
  • Turn config R(u,e) = 0^inf u <C 0 1^e 0^inf, u = w 1 (101)^k (w counter, 1 separator, (101)^k middle field). Bounce: R(w 1 (101)^k, e+3) -> R(inc(w) 1 (101)^(k+1), e) in 6k+4t+9 steps (t = trailing 1-digits); exact on all 60,001 turns to 5.1e7.
  • Eat (e = r in {0,2}): z = inc(inc(w)); z = p 00 -> R(p 1, 3k+3+3[r=2]); z = q c 10 -> R(q 101, 3k+2+3[r=2]). Matches all 631 checked real eats (287 from A, 344 from the certified start B). So e mod 3 is always 0 or 2.
  • Start B (IndBECv1 cert) stays on the clean orbit R(enc(s) 1, 3s) -> R(enc(s+1) 1, 3s+3). Start A keeps leaving it: odd eats make 010 tails and lone-1 separators inside w (90 of 289 cycle starts to 5e7 are not clean); inc passes through separators; w never contains 1111, which every halting inc input up to length 13 but one has. 88 and 280 run the same orbit (identical tape at 1e9): 280's table equals 88's with state B split by entry; they diverge only if 88's F reads 0 or 88's B (entered by D1) reads 1, which are exactly the two halting reads.

Proof strategy & riskshow the formal proof will go · 3 risks to watch

Then a hand proof (Rocq: inc lemmas per word shape + progress_nonhalt_cond), with 280 covered by the shared orbit.

  • ▲280 halts on different reads (B after D1 reading 1); a shared proof must exclude both 88's and 280's halting reads.
