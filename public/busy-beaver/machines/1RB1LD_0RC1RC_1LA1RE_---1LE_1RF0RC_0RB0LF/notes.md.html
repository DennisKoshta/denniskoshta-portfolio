Observation

Table: A0 1RB, A1 1LD; B0 0RC, B1 1RC; C0 1LA, C1 1RE; D0 halt, D1 1LE; E0 1RF, E1 0RC; F0 0RB, F1 0LF. It halts only if A reads 1 with a 0 to its left (A1 -> 1LD, then D reads 0).

  • A bouncer. Every round trip goes from the left end to the right end and back. lo moves exactly -2 per trip, and hi about +2.05. The span grows like 1.07 sqrt(steps): 34,041 cells at 1e9 and 107,321 at 1e10 (26,506 trips).
  • Left end. A fixed gadget G (44 cells; corrected in proof.md: 43, the 44th is the head cell). At the first left record of every trip the tape starts with 0^inf <F G, where G = 0^2 1^2 0 1^4 0 1^2 0 1^6 0 1^2 0 1^5 0^2 1^2 0 1^5 0 1^2 0^2. Each trip has two left records, about 151 steps apart.
  • The sea. Everything right of G is a sea of 1s, with a few gaps (particles) in it.
  • The right pass rewrites C> 11 -> 10 C>.
  • The left pass undoes it with a moving 3-cell composite, 10 11 C> 0 -> 11 C> 0 11 (or 10 B> 000 -> B> 000 11 on the other trip phase; corrected in proof.md: this needs a 0 on the left, 0 10 B> 000 -> 0 B> 000 11), 12 steps per pair.
  • So at left records the sea is 1^(2k); at right records it is (10)^k.
  • Particles. Seen at left records, measured from hi, there are four.
  • The wall W (0) and the edge E (0110 0110) stay fixed relative to hi (they move +2 per trip in absolute terms).
  • The fast particle P1 (0110) moves 8 cells left of hi per 12 trips.
  • Two slow particles, Q (0^6) and Q' (0110 1111 0^6), move 4 cells per 12 trips.
  • Each particle cycles through 12 shapes with period 12 trips. At the phase-0 trip of a run the tape is exactly K(n,a,b,c,d) = 0^inf <F G 1^n 0 1^a 0110 1^b 0^6 1^c 0110 1111 0^6 1^d 0110 0110 111 0^inf (written with explicit exponents: 1^n 0 1^a 0 1^2 0 1^b 0^6 1^c 0 1^2 0 1^4 0^6 1^d 0 1^2 0^2 1^2 0 1^3).
  • Collisions. When P1 reaches W, about 138 or 147 trips of rearrangement follow, of two kinds that alternate (Fig 2). Each kind restarts the steady pattern with the parameters shifted linearly.

The general two-parameter map is (x,y) -> (3x/4 + y/2 + 13, x/4 + y/2 + 35). It keeps the line x - 2y = -76 and attracts nearby points to it. Both families, start A (x = 212 + 32j) and start E (x = 220 + 32j), lie on that line.
