0. Summary

The machine builds a tape of five long blocks of 1s, separated by four short "particles", with a fixed gadget G at the left end.

Every round trip starts at G. The head runs right over some of the blocks and is turned back by one of the particles. How far it gets depends on the trip's phase, which has period 12.

Over 12 trips the first block grows by 48 and the second shrinks by 8. So the particle after the second block drifts toward the particle before it. When the second block is down to 2, 4, 6 or 8 cells, a collision of 135 to 147 trips rebuilds the pattern with new block lengths.

Two of the collisions alternate forever. Together with the 12-trip steps between them they form a double cycle on a one-parameter family:

Even(n, x)  -->  Even(n + 12x + 808, x + 32)        (n odd, x = 4 mod 8, x >= 52)

The run from the blank tape reaches Even(12863, 212) at step 153,126,993, after an opening of 4,097,897 steps and 20 more macro steps. From there the double cycle repeats forever, and every piece of it is an exact run of the machine. So the machine never halts.

2. Notation and families

Configurations. l <S r is state S reading the last cell of l; l S> r is state S reading the first cell of r. Words are written left to right. w^k is k copies of w, and 0^inf is the blank tail.

Rules. X --> Y between configurations means an exact run of the machine. A rule on partial configurations, such as R1, holds for every left side and every right side: the run never reads a cell outside the written part.

G is the 43-cell word of §1. It is the same at the start of every trip.

The family K. For n, a, b, c, d ≥ 0,

K(n,a,b,c,d) = 0^inf <F G 1^n 0 1^a 0 1^2 0 1^b 0^6 1^c 0 1^2 0 1^4 0^6 1^d 0 1^2 0^2 1^2 0 1^3 0^inf

The head is in state F on the 0 just left of G, and everything left of it is blank. The five 1-blocks have lengths n, a, b, c, d.

Particles. The short words between the blocks are, from left to right:

  • W = 0 (between n and a);
  • P1 = 0 1^2 0 (between a and b);
  • Q = 0^6 (between b and c);
  • Q' = 0 1^2 0 1^4 0^6 (between c and d);
  • E = 0 1^2 0^2 1^2 0 1^3 (after d, the right end).

Trip. A left record is a step at which the head visits a cell left of every cell visited before. Trips are counted by left records, two per trip, and K(...) is the configuration at the first left record of a trip. "j trips" means 2j left records.

Even(n, x) = K(n, x, (x+76)/2, 35, 18). It is used for n odd and x = 4 (mod 8), x ≥ 52.

3. Rules

3.1 The two shift rules

R1. For all left sides l and right sides r:

l C> 1 1 r  -->(2)  l 1 0 C> r          transitions C1 (1RE), E1 (0RC)

C reads 1, writes 1 and moves right in state E. E reads 1, writes 0 and moves right in state C. By induction on k, C> 1^(2k) --> (10)^k C> in 2k steps.

R2b. For all l and r:

l 0 1 0 B> 0 0 0 r  -->(12)  l 0 B> 0 0 0 1 1 r

Number the six written cells 0 to 5, so B starts on cell 3. The twelve transitions are:

step transition head after cells 0..5 after
1 B0 = 0RC 4 010000
2 C0 = 1LA 3 010010
3 A0 = 1RB 4 010110
4 B1 = 1RC 5 010110
5 C0 = 1LA 4 010111
6 A1 = 1LD 3 010111
7 D1 = 1LE 2 010111
8 E0 = 1RF 3 011111
9 F1 = 0LF 2 011011
10 F1 = 0LF 1 010011
11 F1 = 0LF 0 000011
12 F0 = 0RB 1 000011
  • The head stays on cells 0..5, so the rule holds for every l and r.
  • Cell 0 must be 0. With a 1 there, step 12 is F1 = 0LF instead, and the run goes elsewhere (check SR.R2b_needs_the_0_on_the_left).
  • k-fold form. 0 (10)^k B> 000 --> 0 B> 000 1^(2k) in 12k steps, by induction on k. In 0 (10)^(k+1) B> 000 = 0 (10)^k 1 0 B> 000, the cell left of the last copy is the 0 of the copy before it (or the leading 0 when k = 0). So R2b applies to the last copy, giving 0 (10)^k B> 000 11, and the induction hypothesis finishes.

Not used: R2a. The observe stage also found 0 10 11 C> 0 --> 0 11 C> 0 11 (12 steps). It is true (check SR), but no proof below uses it: every macro rule closes with R1 and R2b alone (check MR.*_proved_with_R1_R2b_only).

3.2 How the macro rules are proved: symbolic execution

Each macro rule is a statement "for all values of the variables in the domain, start → end in exactly N steps". It is proved the way busycoq's ES_v3 es' proves block rules.

Symbolic tapes. A tape is a finite list of tokens between two blank tails: - a single 0 cell; - a run 1^L; - a block (10)^X.

L and X are linear forms in variables over ℕ with nonnegative coefficients, so each form is at least its constant term. Each domain variable is written by its parity and lower bound; for example a even ≥ 10 is a = 2a' + 10 with a' ≥ 0.

Moves. Each move is either an identity of tapes or an exact run of the machine.

move what it does why it is sound
peel take one concrete cell off a run whose constant term is ≥ 1 1^L = 1 1^(L-1), (10)^X = 1 0 (10)^(X-1) (read from the side the head is on)
merge join adjacent 1-runs; (10)^X 1 0 = (10)^(X+1) identity
step one transition of the table on a concrete head cell the table; a --- stops the proof
R1 C> 1^(2h+c) --> (10)^h C> 1^c on the symbolic part of a run §3.1, 2h steps
R2b 0 (10)^X B> 000 --> 0 B> 000 1^(2X) on the symbolic part of a block §3.1, 12X steps; the 0 is the last cell of the block's constant copies, or the cell below the block must be a 0 cell or the blank tail
split v = 0, or v = v' + 1 covers every v in ℕ

A split happens only when the head must read a cell of a run or block whose constant term is 0.

Leaves. Each branch runs until the stated number of left records. Then it must match the claimed end configuration exactly, as a word (after merging runs), with the head on the leftmost cell and in state F. The step count of a branch is a linear form, and it must equal the claimed formula. The rule holds because the branches cover the domain and each branch is a chain of exact runs and tape identities.

Testing the executor. We run the executor against direct simulation of the machine on random symbolic tapes, half of them set up so that a shift rule fires. The test compares tape, head, state and step count, for random branches and random values of the variables (check ENG).

The same test catches a variant of the executor that drops R2b's 0-on-the-left condition (ENG.teeth_unsound_variant_is_caught).

How to read the table: - A block crossed once in each direction costs 7 steps per cell: 1 per cell by R1 going right, 6 per cell by R2b going left. So the coefficients show how far each trip goes. Trips 3, 6, 9 and 12 cost 7n + const: the head crosses only the first block and turns back at the particle right after it. - The steps add up to S's formula: 84n+84a+77b+70c+63d+13628 (check PH.sum_of_phase_steps_is_S_formula).

Case split. Our executor splits once, on d: d = 2 or d ≥ 4. The split happens in trip 1, where the head reads the (10)^X block made from the d block cell by cell, and X may be 0. Both branches reach the same K_1, with the same step formula, so the table holds for all d ≥ 2. P2 to P12 need no split.

The split is a feature of our executor, not of the rule. A block can be rotated before the head reads it:

y (v y)^X  =  (y v)^X y

This moves a concrete cell from one side of the block to the other. An executor that rotates the (10)^X block this way, instead of splitting, proves P1 and S in one branch.

Domain. Each lower bound of S is sharp. One below it (a = 8, b = 4, c = 5 or d = 0, same parity), the result is not K(n+48,a-8,b+4,c,d+4) in any sampled case (check TEETH). a = 8 is where T8 takes over.

What happens in a collision. The tables show the following.

  • The variables occur only in the exponents of a few long 1-blocks: the first block, and the blocks that come from b and d (and c, in TO). Every other exponent is a constant.
  • Every trip crosses the first block: every step count contains 7n.
  • In TO, the b and c blocks merge into one block at trip 10.
  • From trip 12 on, the left part grows and shrinks as in S. At rows 12, 24, 36, ... the first block is 48 longer than 12 rows before, and the block that came from b (in TO, from b and c) is 8 shorter. At the end that block is the new second block: b - 86 in TE, b + c - 91 in TO.

The bounds are sufficient, not minimal. Only the domains stated are claimed. For example TE also holds at d = 18 in the sampled cases, which nothing below uses.

4. The double cycle

Lemma DC. Let n be odd, x = 4 (mod 8) and x ≥ 52. Write m = (x-4)/8 and m' = (x-52)/8. Then

Even(n, x)  -->  Even(n + 12x + 808, x + 32)

by the chain S^m, TE, S^(m'), TO, in 12m + 138 + 12m' + 147 = 3x + 201 trips.

Proof. We check each rule's domain at each application.

Step 1: S, m times. Before the i-th application (0 ≤ i < m) the configuration is

K(n + 48i, x - 8i, (x+76)/2 + 4i, 35, 18 + 4i)
  • n + 48i is odd.
  • x - 8i is even and at least x - 8(m-1) = 12 ≥ 10.
  • x + 76 = 0 (mod 8), so (x+76)/2 + 4i is a multiple of 4, hence even, and it is ≥ 6.
  • 35 is odd and ≥ 7; 18 + 4i is even and ≥ 2.

After m applications, with 4m = (x-4)/2:

K(n + 48m, 4, x + 36, 35, (x+32)/2)

Step 2: TE. a = 4 and c = 35 hold. - b = x + 36 is even, and b ≥ 88 exactly when x ≥ 52. - x + 32 = 4 (mod 8), so d = (x+32)/2 = 2 (mod 4) is even, and d ≥ 20 since x ≥ 8.

The result is

Odd = K(n + 48m + 556, x - 50, 82, (x+134)/2, 18)

Step 3: S, m' times. Before the i-th application the configuration is K(·, x - 50 - 8i, 82 + 4i, (x+134)/2, 18 + 4i). - x - 50 - 8i is even and at least x - 50 - 8(m'-1) = 10. - x + 134 = 2 (mod 8), so c = (x+134)/2 = 1 (mod 4) is odd, and c ≥ 7. - b and d are even and ≥ 6 and ≥ 2.

After m' applications, with 4m' = (x-52)/2:

K(n + 48(m+m') + 556, 2, (x+112)/2, (x+134)/2, (x-16)/2)

Step 4: TO. a = 2 holds. - x + 112 = 4 (mod 8), so b = (x+112)/2 is even; b ≥ 82 exactly when x ≥ 52. - c = (x+134)/2 is odd (step 3) and ≥ 37. - x - 16 = 4 (mod 8), so d = (x-16)/2 is even; d ≥ 18 exactly when x ≥ 52.

TO gives K(n'', b + c - 91, d + 62, 35, 18), where

b + c - 91 = (x+112)/2 + (x+134)/2 - 91 = x + 32
d + 62     = (x-16)/2 + 62 = (x+108)/2 = ((x+32) + 76)/2
n''        = n + 48(m+m') + 556 + 588 = n + 6(x-4) + 6(x-52) + 1144 = n + 12x + 808

So the result is Even(n + 12x + 808, x + 32). ∎

Closure. n + 12x + 808 is odd, x + 32 = 4 (mod 8) and x + 32 ≥ 52. So DC applies again, forever. The Even family with these conditions needs no further invariant: the conditions are the whole domain of DC, and DC preserves them.

The general two-parameter map behind DC, (x, y) ↦ (3x/4 + y/2 + 13, x/4 + y/2 + 35) for K(n, x, y, 35, 18), is an observation of the observe stage. It keeps the line x - 2y = -76, which is the Even family. Nothing below uses the general map.

6. Coverage and progress

  • Coverage. There is no case analysis at the top level. The orbit from step 153,126,993 stays in the Even family (§4, closure), and every Even member satisfies the hypotheses of DC. Inside DC, each application's domain is checked in §4. The opening is a fixed finite list (§5).
  • Progress. Every macro rule takes at least 13,628 steps (S at its smallest), so each DC round takes at least one step. Progress is never a 0-step round.

7. Conclusion

7.1 Non-halting

  1. c0 = 0^inf A> 0^inf reaches Even(12863, 212) at step 153,126,993 (§5).
  2. Each Even member reaches the next by an exact run of at least one step (§4), and the next one is again an Even member.
  3. So the run is infinite.

Why D0 is never read. D0 is the only undefined transition. D is entered only by A1 = 1LD, so the machine halts exactly when A reads a 1 that has a 0 on its left. Every step of the run is inside one of the exact runs above: the opening (a direct run that does not halt), the shift rules (their transitions are listed in §3.1, and D0 is not among them), and the executor's concrete steps (it stops with a failure on a ---, and no leaf ever recorded D0; check HALT).

7.2 Why it is not a cryptid

The top-level map is affine: (n, x) ↦ (n + 12x + 808, x + 32). All parities are fixed (n odd, x = 4 mod 8). No branch depends on the digits of a growing number. So ground rule 6 does not apply.
