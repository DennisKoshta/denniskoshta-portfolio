1RB0RB_1LC0RA_1LE0LD_1LC1LF_1RA0LD_1LC---: never halts

This machine never halts. From the blank tape it runs a binary counter: its tape is a row of binary digits, each a run of 10 pairs then a run of 01 pairs (with 00 between them for a digit 0), followed by a block at the right end.

At each return of the head to the right edge, the tape reads as such a counter. A carry adds 1 to the counter. When all digits are 1, an overflow re-pairs the halves of every digit instead.

The machine has the same transition table as another holdout, called the parent below, up to a renaming of the states. Symbols and directions are the same. This machine starts in the state that the parent calls B, so its run is not the parent's run.

The proof reuses the parent's whole argument. Only the start is new: a 732-step run from the blank tape to a configuration where the parent's invariant holds.

Summary

This is the parent's binary counter, with head state A where the parent has B.

Head notation as in P§2.1: X> puts the head in state X on the next cell, and <X on the previous cell. At each return to the right edge the tape is

K = 0^inf 10 01 d_1 .. d_m (10)^a 000 (10)^b A> 0^inf

with digits

(10)^u 00 (01)^v        bit 0
(10)^u (01)^v           bit 1

As in the parent: - a carry M adds 1 to the counter; - an overflow O re-pairs the halves of every digit; - the three-class invariant INV = Common ∧ (A ∨ B ∨ C) of P§3 is closed under M and O.

τ is a pure renaming of states (Lemma R, §0), so every window lemma, rule, step formula and the whole invariant argument carry over word for word. The invariant is not adjusted.

Only the start differs, because this machine starts in what is the parent's state B. From the blank tape it follows a different orbit of the same macro map:

this machine:  reaches the INV state K((1,1,10); 8, 1)  (class A)  at step 732
the parent:    reaches K((1,1,2); 8, 5)                             at step 483

The proof is that 732-step initial segment, a base-case check, and the parent's induction.

0. The map

this state 0 1 = τ(parent state) parent 0 parent 1
A 1RB 0RB τ(B) 1RC 0RC
B 1LC 0RA τ(C) 1LD 0RB
C 1LE 0LD τ(D) 1LA 0LE
D 1LC 1LF τ(E) 1LD 1LF
E 1RA 0LD τ(A) 1RB 0LE
F 1LC --- τ(F) 1LD ---

The renaming is

τ:  A↦E,  B↦A,  C↦B,  D↦C,  E↦D,  F↦F        (a 5-cycle on A–E)

Row τ(s) of this table is the parent's row s with every target state t replaced by τ(t); symbols and directions are unchanged. For example, the parent's C1 = 0RB becomes 0Rτ(B) = 0RA, which is this machine's B1.

Among all 720 state renamings, each with and without mirroring, τ without mirror is the only map from the parent's table to this one.

Lemma R

Lemma R (relabelling). For a configuration c, let τc be c with its head state renamed by τ; the tape and head position stay the same. Then: - c → c′ under the parent if and only if τc → τc′ under this machine; - c is halted exactly when τc is (F1 is the only undefined cell, and τ fixes F).

So every run c →ⁿ c′ of the parent gives a run τc →ⁿ τc′ here, of the same length, and conversely.

Proof. If the parent has δ(s, x) = (y, d, t), this machine has δ(τs, x) = (y, d, τt) by the table above. ∎

Start, halting cell and the four holdouts

Start. This machine's c0 is

0^inf A> 0^inf  =  τ(0^inf B> 0^inf)

So its run is τ of the parent's table run from 0^inf B> 0^inf. This is not the parent's own run, which starts in A.

Halting cell. Only D1 = 1LF enters F (it is τ of the parent's E1), and F1 is ---. So the machine halts exactly when D reads 1 with a 1 to its left.

The invariant

INV(d_1..d_m; a, b) := Common /\ (A \/ B \/ C)
Common: m >= 1; canonical (every v_j >= 1, every bit-1 u_j >= 1); a >= 1; b odd; a + R_tot even;
        S >= 0; T >= 0; vbar_m >= 1
A:      d_1 = (0,0,v) with v >= 2, or d_1 = (1,1,v); for all j, vbar_j >= 1 and ubar_j odd; S >= 1
B:      d_1 = (0,0,1); for all j, v_j + beta_j odd; for j >= 2, ubar_j >= 2^(j-1)

The legs

Each leg is an instance of the rules of §1. Its step count, from the step formulas:

step 122, O:               141 = 89 − 4 + 16 + 20 + 4 + 16
step 263, M_1:             100 = 32 + 32 + 8 + 4 + (16 + 8)

The two M legs:

  • The M_1 at step 263 flips the top (0,0,1) to (1,1,0), which falls into the next digit: (2,0,1) becomes (3,0,1).
  • The M_0 at step 363 flips (3,0,1) to (4,1,0), which joins the block: a = 5 + 1 + 4 = 10.

Two legs use rule cases the invariant argument never needs (the LSB drop, and O at m = 0). That does not matter: the proof uses the 732-step run only as one finite computation, and the table only explains it.

For comparison: - the parent's run has K-configurations at 142, 283 and 383 (not in INV) and reaches its base K((1,1,2); 8, 5) at 483 (P§4); - the mirrored C-start 1RB0LD_1RC0RE_1LD0RE_1LA0LA_1RB1RF_1RB--- reaches K((1,1,9); 8, 1) at step 687.

INV at the base K((1,1,10); 8, 1)

  • top (1,1,10): bit 1, u_1 = 1; m = 1;
  • V = 1, R_tot = R_1 = 0, R1_1 = 0;
  • ubar_1 = 1 (odd), vbar_1 = 10 ≥ 1 (also the LSB condition);
  • S = 8 + 0 − 2 = 6 ≥ 1, T = 1 − 1 = 0 ≥ 0 (tight, as at the parent's base);
  • a = 8 ≥ 1, b = 1 odd, a + R_tot = 8 even;
  • so Common holds, and class A holds (top (1,1,v), every vbar ≥ 1, every ubar odd, S ≥ 1).

The base in the .v

In the .v, INV is the parent's additive form (P§6). There, R = Rof ds is computed by structural recursion on the least-significant-first digit list, and the clauses carry no subtraction or division.

At ([d1 1 10], 8, 1), with m = 1 and 2^(m+1) = 4, its 12 clauses are:

  • ds ≠ [], a = 8 ≥ 1, b mod 2 = 1, (a + R) mod 2 = 0 with R = 0;
  • a + R + 2 = 10 ≥ 4 (S ≥ 0), b + 3 + 2R = 4 ≥ 4 (T ≥ 0), LSBok: v_m = 10 ≥ R + 1;
  • class A: a + R + 1 = 9 ≥ 4 (S ≥ 1), and PA (d1 1 10) 0 0, which is canonical (1 ≥ 1, 10 ≥ 1), 10 ≥ Rd + 1 = 1, ub = 1 odd, and ub = 1 for the top digit.

Every clause is linear arithmetic on constants, so the parent's own tactic line for its base goal closes this one (§5).

3. The argument (complete)

Theorem. 1RB0RB_1LC0RA_1LE0LD_1LC1LF_1RA0LD_1LC--- does not halt from the blank tape.

The proof has four steps.

  1. Initial segment. The machine runs from c0 to K((1,1,10); 8, 1) in exactly 732 steps without halting. This is a finite exact computation (§2); in Rocq it is init, proved by solve_init.

  2. Base. INV([(1,1,10)], 8, 1) holds, in class A (§2).

  3. Transfer. P§3.2 (coverage) and P§3.3 (closure): every INV state has a macro step M or O, of at least 32 machine steps, to an INV state. These statements are about the triples and a, b, and the macro steps are rule instances K → K′ of the parent.

By Lemma R, each such instance is a run τK →⁺ τK′ of this machine of the same length, and τK is the K of §1. So coverage and closure hold verbatim for this machine's K-configurations.

  1. Conclusion. By induction from the base, the run is an infinite chain of macro steps, each of at least one machine step, so it never halts (progress_nonhalt_cond with P := INV, as in P§5).

No macro step reaches the halting cell: each is an exact computation from one K to the next, composed of window lemmas in which F reads only 0. ∎

The parent's invariant argument (P§3) never refers to the parent's own orbit, so it applies to this orbit unchanged. The parent's orbit statistics (P§7) are evidence there, not premises.

4. How this orbit relates to the other starts of this table (remark, not used in the proof)

6. Numerical checks

These simulation checks are independent of the .v; the result rests on the .v alone.

  • Table: τ without mirror is the only one of the 720 × 2 renamings that maps the parent's table to this one (12 of 12 cells). D1 is the only cell that enters F, and F1 is the only undefined cell.
  • Lockstep: from the blank tape, this machine and τ of the parent's table run from 0^inf B> 0^inf agree at every step to 2·10⁷ (state, symbol written, move), with identical tapes at the end.
  • Window lemmas: each of the 20 lemmas of §1 runs exactly as stated on this table, never reading outside its window, with τ of the parent's transitions. F is entered only in T4, T9 and T13, and reads 0 each time.
  • Rules:
  • M on 700 random K-configurations (k = 0..6; 273 with a drop, 257 with u* = 0; a, b ≥ 0) and O on 350 (m = 1..7) give exactly the stated result and step count.

7. Relation to hipparcos's analysis

This section translates hipparcos's analysis (the thread in the header) and says what INV decides about it; it is not used in the proof.

Dictionary

His token n is 1 0^n left of the head and 0 1^n right of it. His names translate as follows:

tokens:     X = 1,   C = 2,   C0 = 0,   Cs = 4
R  = 0^inf
L0 = 0^inf 1001
L3 = 0^inf 1001000
>  = A>
b> = B>11
<  = <D

In his order, his 14 block rules are these lemmas of §1:

 1   S1

In his notation, a K-configuration reads

K(d_1..d_m; a, b) = L0 w_1 C0 … C0 w_m C0 X^(a−1) Cs X^b > R

w = X^(u−1) C X^(v−1)       for bit 1
w = X^(u−1) Cs X^(v−1)      for bit 0

A top (0,0,v) gives L3 X^(v−1) for L0 w_1 (below the top, u ≥ 1 in the run).

His cycle

His cycle is one turn A → B → C → A. His configurations translate as follows:

L0 < r               the far-left turn T9 of an overflow from class C
L3 < f(r)            the class-A carry into the top
L0 C < f²(r)         the overflow from class A
L3 C0 < g(f²(r))     the top fall

Here, for the state K((u_j,1,v_j)_{j≤m}; a, b) of that overflow from class C,

r = Π_j (X^(u_j−1) C X^(v_j−2) C) X^a C X^(b+2) R

So: - passes 1–2 are class A, 3 is B, 4 is C; - his first group is the u_j − 1 and a, his second the v_j − 2 and b + 2; - his collisions Cs C0 < are the other drops.

His rules and hypotheses

Block, stride and collision rules, the cycle, and the exponent table without collisions: true. His 14 rules alone, from L0 b> X^2 R at step 24, reproduce the run to step 10⁹. They miss only C0 C0 < (a halt) and C C0 <.

Collisions only in pass 4: true. INV gives passes 1–2 (class A has no drops) but allows drops in class B.

There the top falls by L3 C0 < and the LSB never drops. Every other digit j starts with v equal to the u_j of the overflow from class A, which is

ubar_j ≥ 2^(j−1) + 1        (F3, F1)

and the digit is touched at most 2^(j−1) − 1 times before the top falls, so it never runs out.

A collision removes one digit, i.e. two exponents.

First group never 0: true at cycle starts, where

u_j − 1 ≥ 2^j − 1   and   a ≥ 2^(m+1) − 1        (class C at all bits 1)

Mid-cycle the j-th one falls by 2^j, to v_j − 2 at the overflow from class A. There INV proves only the weaker bound ≥ −1 (vbar_j ≥ 1).

Second group even: true for each v_j − 2 (v_j + 1 is odd). The X^n R exponent b + 2 is odd at every left-end visit (b odd), as he guessed.

C C0 at the right end: no

C C0 < is D reading the last 1 of a 1001 with a nonzero cell further left. It does not occur in the first 732 steps.

After them, D reads 1 only in T4, T9 (L0 <) and T13 (X C0 <), and T4 meets a 1001 only where Lb starts on a digit (u,1,1).

So C C0 < is Lb on a bit-1 digit with v = 1 (his <D 0111).

The right end is the LSB digit and the block (10)^a 000 (10)^b. The block holds no digit, and INV excludes the LSB:

  • A carry sweeps only digits with v ≥ R + 1 ≥ 3 (class A, F0) or v even (B, C).
  • An overflow from class C has all v even.
  • An overflow from class A has v_m = vbar_m, which is ≥ 1 and even, so v_m ≥ 2.
  • It is even because class A starts at the base (vbar = 10) or after an overflow from class C, and class A keeps it. After an overflow from class C, F3 gives the new LSB vbar = a − 2^(m+1) + 2 with a even (a + R_tot even, R_tot = 0).

INV leaves open only a digit (u,1,1) above the LSB at an overflow from class A. That needs u_j = 2^j at the overflow from class C before it (v_j = u_j − 2^j + 1).

Checks

Direct simulation to step 10⁹: - the 14 rules (in random contexts) hold; - both readings hold (19,332 K-configurations, 53 overflows); - the rule-only run holds (38,672 > R moments); - the cycle holds (132 left-end visits); - the table holds (next paragraph); - no C C0 < occurs.

For the table, the tracked exponents are the 289 X^n C exponents at the starts of the 25 complete cycles after step 732: - the 242 not involved in a collision follow his table exactly (each by its place at the start of the cycle); - the 47 caught in a collision follow his collision rule.

On the abstract orbit (1.2·10⁶ macro steps), class B never drops below the top, and every v swept at an overflow from class A is ≥ 4.
