Non-halting argument (sketch, not proved)

Every regime from the blank tape is R / B / W / E0 / E1 / E2 plus the digestion phase. Halting needs an eat at an unsafe counter state. Unsafe states occur only while the residue is digested, which takes O(len X0) bounces, and len X0 = O(log N) while the epoch has N bounces and N grows every epoch. Missing: (1) an exact rule set for the digestion and for non-clean counters (inc on words with extra 001 groups), (2) a proved bound "digestion time < N" on the reachable residues, i.e. an invariant like #10's Lemma N but with large slack (observed max unsafe j / N = 0.52 at N=48, otherwise < 0.3).

Notation

  • Chunks: a = 001, b = 101, z = 000.
  • A block is c = d01 (001)^e: a digit d (a-block if d = 0, b-block if d = 1) followed by e extra a's.
  • Grammar G (aligned words): '', a bare tail, or c (z c)* [z tail], where tail is 1, 010001 or 110001 (= Dn(1..3)) and the exponents e are arbitrary. The clean D(k,s,v) words are the case e = 1 for every block except the last, which has e = 0.
  • O2 words: a 2-cell prefix P in {00, 01, 10, 11}, then a G word, or z then a G word. Every residue is O2: E2 leaves '11' a^e0 z W.

How digestion runs. - D1/D3 eat the residue one chunk every 2 bounces. Only 1 b is used per chunk, because the hub absorbs one 011. - At an a-block, D5 adds 1 to the rest and the eating goes on. - At the first b-block, D6 fires. - The right sweep turns 10 101 (001)^e 000 into 11 100 (011)^(e+1). This builds a sub-hub 1 (110) 0 (011)^(e+1) C> R. - The sub-hub runs a whole sub-epoch inside this one bounce. Its sub-eat then goes back through the main word and leaves a^m z Y. - After D6 the top block toggles, so Y is incremented once every 2 main bounces. Its absorptions go into a^m. These are the O2 rules again, one level down and at half speed. - The same thing repeats at every D6 below that. The counter is fractal. This nesting is why digestion takes about 2^(k/2) bounces.

Cost recursion and the doubling law (scripts/nest_cost.py)

  • Write J(w) for the own-level bounces until the word is in G, and A for the hub absorptions.
  • Top level: β = J - A.
  • D6: J = 1 + 2 J(Y). The new block is an a-block, so the nest is incremented on every 2nd bounce and never absorbs.
  • J('11' a^x z W) = 2x + 2 + J('10' W).
  • A top-level a-block strip costs e + d + 4. An inner strip costs 2e + 2d + 6.
  • This recursion equals the TM's β on all 32,760 clean residues (k ≤ 12, data/nest_cost_clean.json).
  • Doubling law, proved from the rules (k ≥ 3, any s):
  • Let Y_k = '11' a z D(k,s,1).

Proof plan for Lemma D (all links checked on the model orbit)

  • Positions are stable. inc, E1g bounces and overflows change digit bits and append blocks at the top, but they never move a block's exponent.
  • (K) Each D6 level consumes a contiguous run of at least 2 positions of W: the trigger b-block, the sub-epoch's E1g strips and E2g digit, and that level's own D5 strips.
  • The parent block's exponent is Σ(consumed e) + 2·(#consumed) − 2 + (overflow d's).
  • Level ℓ only uses positions ≥ 2(ℓ−1), so 2(L−1) + S ≤ kW. Check: 12,000 epochs, maximum 2(L−1) + S − kW = 0.
  • (P) When digestion ends, the word is just these L blocks plus at most one remnant: k_post − L ∈ {0, 1} in 12,000 of 12,000 epochs. The counter restarts from a value below 2^(L+4).
  • (V) Write m for the counter value n+4.
  • The eat value is at most 2^(L+4) + N. The eat removes at least 1 digit.
  • So m_W ≤ N/2 + 2^(L+3) + X + 1, which gives 2^(kW+3) ≲ N.
  • Observed: m_W/N ≤ 0.517 for N ≥ 100.
  • (X) Excess flow.
  • The excess of a block is η = e − 1 (or e for the last block); clean words have excess 0. Let S_t(q) be the sum of η over positions ≥ q of W at epoch t.
  • Step: S_{t+1}(q) ≤ S_t(2q+2) + 3k_t + 4 and x0_{t+1} ≤ S_t(0) + 3k_t + 5. Checked: 103,679/103,679 and 8,000/8,000 (scripts/nest_excess.py, data/nest_excess.json).
  • Why the step holds: block q of the next W is post-digestion block q+h (h ≥ 1 digits eaten). That block merged positions ≥ 2(q+h) ≥ 2q+2. Each level creates at most 3 per consumed digit. x0 is destroyed by the top-level D1 steps.
  • Unrolled: S_t(q) ≤ ⌈log2((k+2)/(q+2))⌉·(3k+4). Excess is O(log N · log log N); observed S_0 ≤ 0.26 × this bound. The largest exponents in the long run are x0 = 95 and e = 59, up to N = 3.49e6.
  • Bound.
  • Bnd = x0 + 2 + Σ_q 2^((q+1)//2+1)·(2η(q)+10) + 3·2^(k//2+2) + 20·2^(k//2+1) (scripts/nest_bound.py).
  • On 8,000 epochs: β ≤ Bnd holds every time (β/Bnd ≤ 0.333), and Bnd ≤ N − 2 holds for every epoch with N > 784.
  • With the worst-case profile from (X) and N ≥ 0.95·2^(k+3) from (V): Bnd(k) < N − 2 for every k ≥ 13, and Bnd(k ≤ 12) ≤ 40,110. So every epoch with N ≥ 40,112 is safe whatever its k.
  • The finite rest, N < 40,112, is inside the model orbit, which is the rules' own orbit. The TM log checks it directly up to N = 12,668.
  • Non-halting. Every eat then happens at a G word. G eats (E1g, E2g, E0, Et) never halt, and N never decreases. The only halts in the table need D reading 0, which only happens at a non-G eat.
