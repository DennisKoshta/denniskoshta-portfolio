How the invariant was formalized

  • Marker words are given by their absorption-index lists P = [I_1..I_m] (mw P). valid_from s P says each index is odd above the previous one, which is the same as even gaps. α = cnt P n = #{p < n}, [n ∈ P] = ind P n = cnt P (S n) - cnt P n, and cost = 2 + ind.
  • Orb Q n W is the orbit with the absorption-law costs built in (O0 / OS with Ep W (cost Q n) W'), so AL never appears as a separate statement.
  • Inv P n W uses one predicate Core P k a b Q for both word types: k = n for a T-word T(a, n+α) and k = n+1 for an S-word S(a, n+α-1). Core says Q = Qi ++ Qe, |Qi| + a = b+1+ind P k, every q in Qi has q+2+ind P k <= a, and Sh (k+3) a Qe (filter (k <?) P) (Sh u v = Forall2 (q+u = p+v)). The EXT clauses become exact shifted copies of the unabsorbed indices, and the absorption exception and the merged case aff = -1 are both the + ind P k terms. With this form no case split is needed on aff = -1 or α = m.
  • Parity enters through one lemma, parity_in : valid_from s P -> In n P -> n + cnt P n + s odd. It gives "n ∉ P at S-words" and "n+1 ∉ P at non-absorbing T-words" (so Qe >= a-1 there).
  • Composition of shifts: sh_compose (filter_lt_app + Sh_filter + filter_filter_lt + Sh_trans) and in_transfer (Sh_in + filter_in) carry inner Core facts to the outer word. These are the same two lemmas in both T cases; only k, k' differ (a-1, n+2 vs a-2, n+1).
  • Measure: Claim Lm := forall Q k, k + |Q| <= Lm -> valid Q -> exists W, Orb Q k W /\ (1 <= k -> Inv Q k W), by plain induction on Lm. The inner calls are (Q, a-1) with measure n+m (T) and (Q, a-2) with n+m-1 (X). filter_cnt_len + Sh_len give |Qe| = m - cnt P (S n).
  • Top: progress_nonhalt_cond with A = nat * list nat, C (n,W) = conf [] (3::2::W), P (n,W) = Orb [] n W /\ (1 <= n -> Inv [] n W). No determinism lemma is needed, because the step lemma takes the given W.

Pitfalls hit

  • R, L, A..F are constructors (dir, states). A hypothesis named R1 shadowed the lemma R1, so the TM rules were renamed tR1/tR2/tR3. match o with Fin R => ... fails ("constructor of dir"), so use W as the pattern variable.
  • cbn unfolds Nat.ltb into match; use cbn [filter length] together with cnt_cons_lt/_ge rewrites.
  • exists [], [] cannot infer the type: write (@nil nat).
  • eapply Sh_eq; [apply Sh_map with (d:=2) | reflexivity | lia] leaves an evar for lia. Prove the Sh fact first as an assert, then [apply Sh_map ...; exact H | reflexivity | lia].
  • frame_step takes equalities y' = y - 1, z' = z - c + 1 as premises. Leave those goals open and finish with ; lia after exact H has instantiated the evars.
