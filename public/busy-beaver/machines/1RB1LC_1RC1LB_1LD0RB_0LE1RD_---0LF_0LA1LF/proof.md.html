Summary. The tape is a stack of runs of 1s, and the machine is a recursive counter. One "epoch" starts and ends with the head at the left edge, and the leftmost frame has a budget of 3 child creations per epoch. The machine halts exactly when that budget runs out. An epoch on a word T(a,b)+N replays the machine's own history one level down, on the marker word N, for a-1 epochs. Each inner epoch costs 2, or 3 when it absorbs a marker. The absorption law (§3) says exactly when the cost is 3. Its proof is an induction on (epoch index + number of markers), carried by an invariant on the shape and positions of the markers. The top level is the marker-free orbit, so every top-level epoch costs 2 and the budget never runs out.

0. Notation

Tape notation follows Appendix A of PLAN.md: l <A r means A is reading the last cell of l.

Run configurations. For L = [a_1..a_p] (a stack, top = a_p) and R = [c_1, g_1, c_2, g_2, ..., c_r]:

conf(L, R) := 0^inf 1^a_1 0 1^a_2 0 ... 0 1^a_p <A 0 1^c_1 0^g_1 1^c_2 0^g_2 ... 1^c_r 0^inf
domain:  every a_i >= 1, c_i >= 1, g_i >= 1, and g_1 >= 2.   (p = 0 means 0^inf <A 0 1^c_1 ...)

R always has odd length and ends with a run. I call the entries of L frames and a_p the top frame.

Words. A word is an R-shaped list. The edge configuration of a word is Edge(W) := conf([], [3,2]+W). - Marker word: M = [g_1,1, g_2,1, ..., g_m,1] (lone 1s), with every g_i >= 2 even. Write #M = m. - Absorption indices: I_j(M) := sum_{i<=j} (g_i - 1) for j = 1..m, and I_0 := 0. They are strictly increasing, and I_j ≡ j (mod 2) because each g_i - 1 is odd. Write I(M) = {I_1..I_m}. - Tail: N = [], or an even-length list N = [g_1, c_2, g_2, c_3, ..., g_k, c_(k+1)] (a gap first, then run and gap alternating) with every entry >= 1 and g_1 >= 2. For every x >= 1, [x]+N is then a word in the domain. Every marker word is a tail. The epoch rules of §2 are stated for tails; the invariant of §3 uses marker words. - T(a,b)+N := [a,2,b]+N, a T-word. S(a,b)+N := [2,2,a,2,b]+N, an S-word. In §3, N is a marker word; in §2's rules it may be any tail. S(a,b)+N is also T(2,a)+[2,b]+N, where [2,b]+N is a tail but not a marker word when b >= 2. On orbit words the invariant says which reading is meant, and Rule S (§2) handles the S reading directly. - For a T- or S-word, aff := b + 1 - a. This is the number of internal markers, the ones the next replay will absorb.

1. TM-level rules

The --- is E0. Shift rules (ind, one IH use each):

CW   C> 1^n 1        -->  1^n C> 1        3n steps   [C1 B1 B0 per cell: 0RB, 1LB, 1RC]
DW   D> 1^n          -->  1^n D>          n steps    [D1]
FW   1^n <F          -->  <F 1^n          n steps    [F1]

Macro rules. l and r are arbitrary. All parameters are >= 0.

R1   l 1^(n+2) <A 0 1^(m+1) 0 0 1^x 0 r  -->  l 1^(n+1) 0 1^(m+1) <A 0 1^(x+1) 0 0 r      3m+2x+15

1.1 The run model (Lemma RM)

Every conf(L,R) in the domain moves by exactly one rule below. The result is again in the domain.

push   (p = 0, or a_p >= 2):   R3 if p = 0, pushing c_1+1;  R1 if p >= 1, setting a_p := a_p - 1 and pushing c_1.
       In both cases R becomes:  g_1 = 2:  [c_2+1, g_2+1, c_3, ...]   (just [c_2+1] if r = 2)
                                 g_1 >= 3: [1, g_1-1, c_2, g_2, ...]  (just [1] if r = 1)
pop    (a_p = 1, p >= 2):      L := [a_1..a_(p-2)],  R := [a_(p-1)+1, 2] + R      (R2, or R2e when p = 2)
halt   (a_p = 1, p = 1):       HALT

Matching against §1: with g_1 = 2, R1/R3 take x = c_2, and the 0 after 1^x is the first cell of 0^g_2. With g_1 >= 3 they take x = 0, so 0 0 1^0 0 = 0^3 is the start of 0^g_1. With r = 1, the rest is 0^inf. The pop rule needs a single 0 between frames, which the domain gives. The constraints are preserved: a new first gap is g_1-1 >= 2, g_2+1 >= 2 or 2. Evidence: B1, the model equals the TM at every macro step for 40,000 macro steps from step 50. B2: the TM C core agrees at the edge returns up to TM step 4·10^8.

Frame reading. A push decrements the top frame (its payment) and creates a child frame. A frame is top only when it has just been created, or right after its child and grandchild were popped together (the grandchild finished). In both cases it then pays for one child (re)creation. When a frame is top with value 1, it finishes: it is popped together with its parent, and the parent goes back into R with value +1. The grandparent then pays to re-create the parent. HALT is a depth-1 frame that has to pay with value 1.

2. Epoch rules

Epoch. Run from Edge(W) until L = [] again. The run ends at conf([], [5-c, 2]+W'). Write Ep(W) = (c, W'), with cost c ∈ {1,2,3}. The first step R3 creates the edge frame E with value 4. E pays once for each child it creates, and the epoch ends when E's current child finishes (the R2e step). So c is the number of children E created, and HALT happens exactly when an epoch would need a 4th. For a tail N, put W_0(N) := [1]+N and, as long as the epochs exist, (c_i, W_(i+1)(N)) := Ep(W_i(N)). The orbit of a marker word M is O_n(M) := W_n(M) = Ep^n([1]+M) (the cost is dropped).

Every rule below is an exact run of the run model. Macro-step lists are in order. Evidence: D.

Proof of TL (translation). Run both sides one macro step. Edge(W) does R3 and pushes 4. conf(L0+[y], [z,2]+W) does R1 (y >= 2): it sets y := y-1 and pushes z. Both leave the same R = [W_0+1, W_1+1, W_2, ...], because the R-update of a push depends only on R. Call the pushed frame the bottom frame B, and let i be the number of children B has created so far. Claim: until the edge run's last step, the edge run is at ([4-i] + S, R) and the other run is at (L0 + [y-1, z-i] + S, R), with the same S and R.

What a macro step reads (Lemma RM): - A push reads the top value and R, and whether the depth p is 0 (R3 or R1). Here p >= 1 in both runs before the end. - A pop (a_p = 1, p >= 2) also reads the frame beneath the top, a_(p-1), which goes back into R as [a_(p-1)+1, 2]. Whether p = 2 (R2e) or not (R2) changes only the TM step count, not the model. - HALT is a_p = 1 with p = 1. The other run has p >= |L0| + 2 >= 2 throughout, so it never halts.

Cases, by the length of S: 1. S non-empty, top of S >= 2: both runs push the same value with the same R-update, so S grows. 2. |S| >= 2, top of S = 1: both runs pop. The frame beneath the top is inside S, so it is the same in both runs, and so is the new R. 3. S = [], so B is top. In the edge run its value is 4-i, and 4-i >= 2 because the epoch does not halt. So B pushes (R1), and i grows by 1. B creates c children in all, so i <= c-1 before this push. Then z-i >= z-(c-1) >= 2, and the other run pushes too (R1), with the same R-update. 4. |S| = 1, top of S = 1: the pop reads B's value. In the edge run this is R2e: [4-c, 1] -> [], R := [5-c, 2]+W'. It is the epoch's final step, because L = [] for the first time, and i = c here. The other run does R2: L0+[y-1, z-c, 1] -> L0+[y-1], R := [z-c+1, 2]+W', and z-c >= 1.

So before the last step every pop has |S| >= 2 and reads only frames inside S. Case 3 depends on B's value only through ">= 2", which holds in both runs. The single pop with |S| = 1 is the epoch's final step (case 4). Both runs take the same k macro steps. ∎ (The Coq form of this argument is in §7, step 3.)

Rule T (replay). Let a >= 2, b >= 1, and N a tail. Put ζ_0 := b+2, (c_i, W_{i+1}(N)) = Ep(W_i(N)) and ζ_{i+1} := ζ_i - c_i + 1. For a marker word, W_i(N) = O_i(N). - If the epochs Ep(W_i(N)) exist and ζ_i >= c_i + 1 for i = 0..a-2, then Ep(T(a,b)+N) = (2, [ζ_{a-1}, 2] + W_{a-1}(N)). Proof: TR, then TL a-1 times, then TF. The i-th TL use has y = a-i, z = ζ_i and W = W_i(N). None of TR, TL or TF uses marker structure. - Rule X (exhaustion). Suppose the epochs exist, ζ_i >= c_i + 1 for i = 0..a-3, ζ_{a-2} = 2, and W_{a-2}(N) = [a'',2,b'']+N'' with a'' >= 2, b'' >= 1, and N'' arbitrary. Then Ep(T(a,b)+N) = (3, T(a''+2, b''+2) + N''+), where N''+ is N'' with its first entry increased by 2 ([] stays []). Proof: TR, then TL a-2 times (Y goes from a to 2), which gives conf([2,2], [2,2]+W_{a-2}(N)), then X. - Rule S. For a, b >= 1 and N a tail: Ep(S(a,b)+N) = (2, T(a+1, b+2) + [2,1] + N), in 18 macro steps. Proof: S(a,b)+N = T(2,a)+N_S with N_S := [2,b]+N, a tail with first gap 2. Rule T at (2, a, N_S) needs one inner epoch. W_0(N_S) = [1,2,b]+N, and U2 gives Ep(W_0(N_S)) = (2, [b+2,2,1]+N). Then ζ_0 = a+2 >= 3 = c_0+1, and Rule T gives (2, [a+1,2] + [b+2,2,1]+N). The count is TR (8) + U2 replayed by TL (9) + TF (1) = 18. As a standalone model lemma (the Coq form), the macro steps are R3 R1 R1 R2 R1 R1 R1 R2 | R1 R1 R1 R2 R1 R1 R1 R2 R2 | R2e. The middle block is U2 with its first R3 read as R1 and its last R2e read as R2. Every case split in it is decided by the literal entries 2, a+1 >= 2 and so on, and by N's first gap >= 2. Evidence: D7, 1,200/1,200 (a, b in 1..20, half marker tails, half arbitrary tails).

Unrolled to the tape, ζ_i is the value of the [ζ,2] run right of the head when the replay frame Y creates its i-th child. "Cost 3" at an inner level means "ζ drops by 2" at the level above.

3. The orbit invariant and the absorption law

Fix an even-gap marker word M with m markers and n >= 1. Let α := #{j >= 1 : I_j(M) < n} (markers already absorbed), and let j* := α+1 be the first unabsorbed marker if α < m. Call n an absorption step when α < m and I_{j*} = n.

Inv(M, n). W := O_n(M) has one of the following two forms. The type rule decides which: T when n - I_α is odd, S when it is even.

T case. W = T(a,b)+N with a >= 2, b = n + α, and N an even-gap marker word. Let aff := b+1-a. Then: - (count) #N = aff + (m - α), and aff >= -1. aff = -1 happens only at an absorption step (the marker has merged into the head). - (INT) I_aff(N) <= a-2. The aff internal markers are within reach. - (EXT) For every j with j* <= j <= m, put t := aff + 1 + (j - j*), the index in N of original marker j. If t >= 1 then I_t(N) = a - 3 + I_j(M) - n. There is one exception: at an absorption step, for j = j*, the claim is only I_t(N) <= a-3 (within strict reach).

S case. W = S(a,b)+N with a >= 2, b = n - 1 + α, aff := b+1-a. Everything is as in the T case with a-3 replaced by a-4 in EXT. The exception now applies when n+1 = I_{j*}: the claim is then I_t(N) <= a-3, and aff = -1 is allowed only then.

When α = m there are no external markers: N has exactly aff markers, all within reach.

Read with an arbitrary word W in place of O_n(M), the clauses define a predicate "W ∈ Inv(M, n)". The induction step below uses nothing about W = O_n(M) except these clauses and the IH on the inner orbits O_i(N) of W's own marker tail. In Coq, state the step as a lemma over arbitrary W ∈ Inv(M, n). Evidence E2 tests exactly this step on words that are not orbit words.

AL(M, n). Epochs 0..n-1 of the orbit exist (no halt), and epoch i costs 3 iff i ∈ I(M). Otherwise it costs 2.

Theorem. For every even-gap marker word M and every n >= 0, AL(M, n) holds, and so does Inv(M, n) when n >= 1.

Parity facts. (P1) I_i ≡ i (mod 2). (P2) At a T-word, b = n+α is odd: n - I_α is odd and I_α ≡ α. At an S-word, b = n-1+α is also odd.

Proof. Strong induction on Λ := n + m. For Λ = 0 (M = [], n = 0) there is nothing to prove. Assume the claim for every (M', n') with n' + #M' < n + 1 + m, and in particular for (M, n). We prove it for (M, n+1) by cases on O_n(M).

Case n = 0 (U-words). O_0 = [1]+M. - M = []: by U0, O_1 = T(2,1) with α = 0 and aff = 0. - M = [g_1,1]+M' with g_1 >= 4: by U1, O_1 = T(2,1)+[g_1-2,1]+M'. Here aff = 0 and I_t(N) = I_t(M) - 2 = a-3+I_t-1 (EXT with n = 1 < I_1). - M = [2,1]+M': by U2, O_1 = T(3,1)+M'. Here aff = -1 and n = 1 = I_1 is an absorption step; the marker merged into the head. EXT holds for j >= 2: I_{j-1}(M') = I_j - 1 = a-3+I_j-1.

The epoch costs 2, and 0 ∉ I(M) because every I_j >= 1. The type is T since 1 - I_0 = 1 is odd, and b = 1 = n + α.

Case S-word, O_n = S(a,b)+N. Rule S needs a >= 2, b >= 1 (S-words occur only at n >= 2) and N's first gap >= 2. It gives O_{n+1} = T(a+1, b+2) + [2,1] + N at cost 2. Here n ∉ I(M): I_α < n, and I_{j*} - n is odd (because n ≡ I_α ≡ α and I_{j*} ≡ α+1), so n+1 <= I_{j*}. - α is unchanged, the type is T (n+1-I_α is odd), and b+2 = (n+1)+α. - The new aff_T = aff_S + 1 >= 0, and the marker count goes up by 1 (the new [2,1]) ✓. - INT: I_{aff_T}([2,1]+N) = 1 + I_{aff_S}(N) <= (a+1)-2. When aff_S = 0 this is 1 <= a-1. - EXT: indices shift by 1 and positions by +1, so 1 + (a-4+I_j-n) = (a+1)-3+I_j-(n+1) ✓. - Absorption exception (n+1 = I_{j*}): 1 + I_t(N) <= (a+1)-3. If aff_S = -1, the new [2,1] at position 1 is the (aff_T+1)-th marker, and 1 <= a-2 because a merged S-word has b = a-2 >= 1.

Case T-word, not an absorption step (n < I_{j*}, or α = m), O_n = T(a,b)+N. 1. Inner costs. I_1(N) .. I_aff(N) <= a-2 by INT. The next one is I_{aff+1}(N) = a-3 + I_{j*} - n >= a-1, because I_{j*} - n is even and positive. This uses the type rule, the P1 parity of I_{j*}, and n - I_α odd. Take the IH AL(N, a-1). Its measure is Λ = (a-1) + #N = (a-1) + aff + m - α = b + m - α = n + m, which is smaller. It gives c_i = 2 + [i ∈ I(N)] for i <= a-2, with exactly aff threes. 2. ζ-accounting. ζ_i = b+2-i-#(I(N)∩[0,i-1]), so ζ_i - (c_i+1) = b-1-i-#(I(N)∩[0,i]) >= b-1-(a-2)-aff = 0. Also ζ_{a-1} = b+2-(a-1)-aff = 2. Rule T gives Ep(O_n) = (2, [2,2] + O_{a-1}(N)). The cost is 2, and n ∉ I(M) ✓. 3. Shape. By the IH Inv(N, a-1), α_N = aff (the same count as in step 1), and (a-1) - I_aff(N) ≡ a-1-aff ≡ b ≡ 1, so the inner word is a T-word: O_{a-1}(N) = T(a',b')+N' with b' = (a-1)+aff = b. Therefore O_{n+1} = S(a', b) + N'. Check the S clauses at n+1: - b = (n+1)-1+α ✓. - #N' = aff' + (#N - aff) = aff' + m - α ✓. - INT is inherited. - EXT: original marker j = j*+s is N-marker aff+1+s, at a-3+I_j-n. Inner EXT puts it at a'-3 + (a-3+I_j-n) - (a-1) = a'-4+I_j-(n+1) in N' ✓. - If I_{j*} = n+2, the inner word is at its own absorption step, so the inner exception gives <= a'-3 (or aff' = -1). This is exactly the S exception at n+1. - The type is S because n+1-I_α is even ✓.

Case T-word at an absorption step (n = I_{j*}). Here a >= 3: if aff >= 0 then 1 <= I_{aff+1}(N) <= a-3, and if aff = -1 then a = b+2 >= 3. 1. Inner costs. The first aff+1 markers of N are <= a-3; when aff = -1 there are none. The next one is a-3+I_{j*+1}-n >= a-2. The IH AL(N, a-2) has measure n+m-1. It gives exactly aff+1 threes among c_0..c_{a-3}. 2. ζ-accounting. For i <= a-3: ζ_i-(c_i+1) >= b-1-(a-3)-(aff+1) = 0. Then ζ_{a-2} = b+2-(a-2)-(aff+1) = 2. 3. Shape for rule X. By Inv(N, a-2): α_N = aff+1, and (a-2) - I_{aff+1}(N) ≡ a-3-aff ≡ b ≡ 1 (when aff = -1: a-2 = b, odd). So O_{a-2}(N) = T(a'',b'')+N'' with b'' = (a-2)+(aff+1) = b >= 1 and a'' >= 2. Rule X gives Ep(O_n) = (3, T(a''+2, b+2)+N''+). The cost is 3 at n = I_{j*} ✓. 4. Clauses at n+1. Now α' = α+1, the type is T (n+1-I_{j*} = 1), b+2 = (n+1)+α' and a''+2 >= 4. - aff_new = aff'', and #N''+ = aff'' + (#N-aff-1) = aff'' + m - α' ✓. - INT: I_{aff''}(N''+) = I_{aff''}(N'')+2 <= a'' ✓. - EXT for j >= j*+1: inner EXT gives a''-3 + (a-3+I_j-n) - (a-2) = a''-4+I_j-n. Adding 2 gives (a''+2)-3+I_j-(n+1) ✓. - If I_{j*+1} = n+1, the inner exception carries over: <= a''-3, plus 2, gives <= a_new-3, or the marker has merged (aff'' = -1).

Measure. Every inner call uses (N, i) with i <= a-1 and #N = aff + m - α, so i + #N <= n + m < (n+1) + m. The outer call uses (M, n). So the induction is well-founded. Epochs are finite because each is a finite composition of rules. ∎

4. Coverage

  • Edge level. The run reaches Edge(O_0([])) (§5). By the Theorem with M = [], every epoch from Edge(O_n([])) exists and costs 2, because I([]) is empty. The epoch ends at conf([], [5-2, 2] + O_{n+1}([])) = Edge(O_{n+1}([])). Every O_n([]) is a U-word (n = 0), a T-word or an S-word, and each epoch is covered by U0, T or S. 6. Conclusion

Every top-level epoch costs 2, so the edge frame E creates exactly 2 children per epoch. It is never asked for a 4th, which is the only way HALT can happen (§2). Each epoch takes at least 9 macro steps, and so at least 9 TM steps. The run therefore passes through Edge(O_n([])) for every n and never halts.

Why --- (E0) is never read. E is entered only by D0 (0LE). In R1 and R3, D0 fires just right of the 1^(x+2) block, so E reads a 1. In R2 and R2e, D0 fires just right of the lone 1, so E reads that 1. E reads 0 only in the HALT pattern 0^inf 1 <A 0, where C0, D0 run off the left edge. That pattern is a depth-1 frame with value 1 on top, which the cost-2 argument excludes. Evidence: G, E is entered about 10^5 times in the first 2·10^6 steps, always reading 1. A5: the HALT pattern halts in exactly 3 steps reading E0.

7. busycoq lemma plan

  • Nearest template: vendor/busycoq/verify/CounterClass2v1.v. It has an abstract Inductive Side, a to_side translation, a measure, one-step lemmas lifted to the TM, and progress_nonhalt_cond. BinaryCounter.v shows Fixpoint-built sides. No repo file has this machine's word recursion, so the model layer below is new.
  • Size: larger than the CounterClass examples. Most of it is the model-level combinatorics, which is pure list nat + lia with no TM execution.

1. TM layer. Definition tm := Eval compute in (TM_from_str "1RB1LC_1RC1LB_1LD0RB_0LE1RD_---0LF_0LA1LF"). - Shift lemmas CW, DW and FW, by ind n with es. - R1, R3, R2 and R2e, for all sides l and r, by es and follow CW/DW/FW in the order listed in §1.

2. Sides. Store L with its top first. - Fixpoint lside : list nat -> side (single 0 between runs, const 0 at the bottom). - Fixpoint rside : list nat -> side (alternating runs and gaps). - Definition conf L R := lside L <{{A}} [0] *> rside R. - Lemma RM_sound : wf L R -> mstep (L,R) = Push/Pop (L',R') -> conf L R -->+ conf L' R'. This is a case split on g_1 = 2 / >= 3 / r = 1. The 0 0 1^x 0 reshaping needs rside rewriting lemmas.

3. Model layer. Pure Coq, no TM. - mstep is a Fixpoint-free function on (list nat * list nat), with mrun k its k-fold iterate. - Ep W c W' is defined as mrun k ([], [3;2]++W) = ([], [5-c;2]++W'), with no intermediate empty L. - Lemmas U0, U1, U2, TR, TF and X are reflexivity/simpl after destruct on the list shapes. - TL needs a simulation relation: the edge state ([4-i]++S, R) against (L0++[y-1; z-i]++S, R), both written bottom-first here. Prove it by induction on the remaining step count, generalized over (i, S, R). Put these into the invariant explicitly: - i <= c; - if S = [] then i < c, so the bottom frame, when it is top, has value >= 2 in both runs (4-i >= 2 and z-i >= 2). Derive this from "the edge run does not halt and the bottom value only decreases". - Before the last step, every pop has |S| >= 2, so the frame it reads sits in S. The |S| = 1 pop is the step that empties the edge stack, which is the epoch's last step and the base case of the induction. The "no intermediate L = []" clause in the definition of Ep is what identifies the |S| = 1 pop as the last step. This is the one non-trivial model lemma. The twin's budget-2 edge lemma (§6.1) is the same proof with L0 empty and [3-i] in place of [y-1; z-i]. - Rule T and rule X follow by induction on a, using follow-style transitivity of mrun. State them for tails, not for marker words. Rule S is then T at a = 2 with tail [2;b]++N, or a standalone 18-step computation.

4. Theorem (§3). - orbit M n W is an inductive relation. - Inv M n W is a Prop over list nat, with Ivec as a Fixpoint prefix-sum. - Prove forall Λ M n W, n + markers M <= Λ -> orbit M n W -> AL M n /\ Inv M n W by induction on Λ. Factor out the step as its own lemma over arbitrary words: Inv M n W -> (IH for all (N, i) with i + markers N <= n + markers M) -> exists W', Ep W (2 + [n ∈ I M]) W' /\ Inv M (S n) W'. This is the statement E2 tests. - The parity facts and the EXT arithmetic are lia with Nat.even/Nat.odd lemmas. - Expect the EXT index bookkeeping (nth on prefix sums under [2;1]++ and "first gap +2") to be most of the work. Write helper lemmas Ivec_cons21 and Ivec_bump2 first.

5. Top. - Lemma init : c0 -->* conf [] [3;2;1] by solve_init/es (50 steps). - Lemma nonhalt : ~halts tm c0. Apply multistep_nonhalt (TM.v:584) with init. That leaves ~halts tm (conf [] [3;2;1]). Close it with progress_nonhalt_cond (TM.v:632), whose arguments are an index type A, a start index i0, a map C : A -> Q * tape and a predicate P : A -> Prop (not a predicate on configurations, which is progress_nonhalt's shape). Take: - A := nat * list nat, - C '(n, W) := conf [] (3 :: 2 :: W), - P '(n, W) := orbit [] n W, - i0 := (0, [1]), so that C i0 = conf [] [3;2;1] and P i0 is the base case of orbit. The step obligation is forall i, P i -> exists i', C i -->+ C i' /\ P i'. Take i' := (S n, W'), where W' comes from the Theorem (AL([], n+1): epoch n exists and costs 2), lifted to the TM by RM_sound. This avoids having to define W_n as a function. - Twin (§6.1): the same with C '(n, W) := conf [] (2 :: 2 :: W), a 44-step init from c0 of TM113.tm, and the budget-2 edge lemma in the step. Then TM113.eqv gives row 833.
