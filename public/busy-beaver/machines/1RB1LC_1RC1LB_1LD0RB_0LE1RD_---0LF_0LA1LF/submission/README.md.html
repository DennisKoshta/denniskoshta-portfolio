Mechanism

  • The tape is a stack of runs of 1s, 0^inf 1^a_1 0 .. 0 1^a_p <A 0 1^c_1 0^g_1 1^c_2 ... A push (R1) takes one 1 from the top run and makes the next run right of the head the new top frame; at the left edge R3 does the same without the payment, and the new frame gains a 1. When the top run is a lone 1 it finishes: R2 merges it into the run below, which moves back to the right side one cell longer.
  • An epoch starts at 0^inf <A 0 1^3 0^2 W. Its edge frame has value 4, so it can create 3 children; the machine halts only if an epoch needs a 4th. On a word 1^a 0^2 1^b N, the epoch replays the machine's own history one level down, on the marker tail N (lone 1s with even gaps), for a−1 inner epochs.
  • Each inner epoch costs 2, or 3 when it absorbs a marker. The top level has no markers, so every top epoch costs 2 and the budget never runs out.

How the proof works

  • TM layer. Three rules on arbitrary sides (tR1, tR3/tR3c, tR2), each one plain es. A big-step frame semantics Inductive Life x R o (4 constructors) is lifted to the TM by one induction (Life_tm). An epoch Ep W c W' is the life of the edge frame.
  • Epoch rules. U0–U2 and rule S are concrete traces closed by a search tactic. Rule T (replay, ruleT) and rule X (ruleX) compose inner epochs. The translation lemma is Life_shape: a popped frame's outcome depends on its value only through "enough budget".
  • Absorption law. Marker words are stored as lists of absorption indices (mw P). Orb builds the predicted costs into the orbit, and Inv/Core record where the unabsorbed markers sit, as exact shifted copies (Sh). main proves both by induction on n + #markers (stepU, stepS, stepT_nabs, stepT_abs).
  • nonhalt. multistep_nonhalt with init (50 steps, solve_init), then progress_nonhalt_cond over nat * list nat with the marker-free orbit as the predicate.
