`1RB1LC_1RC1LB_1LD0RB_0LE1RD_---0LF_0LA1LF` (Counter Class 4, sheet row 832) never halts. Coq proof: <LINK>

The tape is a stack of runs of 1s and A runs it like a call stack: a push pays one 1 from the top run and makes the next run the new top frame, and a top run that is a lone 1 finishes and merges into the run below. An epoch starts at `0^inf <A 0 111 00 W`; its edge frame can make 3 children, and the machine halts only if an epoch needs a 4th. On `W = 1^a 00 1^b N` the epoch replays the machine's own history one level down on the marker tail N (lone 1s, even gaps) for a-1 inner epochs, each costing 2, or 3 when it absorbs a marker. The absorption law (inner epoch n costs 3 iff n is the sum of (gap-1) over the first j markers, for some j) is proved by induction on n + #markers, together with an invariant on where the unabsorbed markers sit. The top level has no markers, so every top epoch costs 2. In Coq, a big-step frame relation `Life` (one induction over 3 `es` rules lifts it to the TM) replaces the stack simulation, and marker words are lists of absorption indices, so the bookkeeping is shifted `Forall2` copies plus lia.
