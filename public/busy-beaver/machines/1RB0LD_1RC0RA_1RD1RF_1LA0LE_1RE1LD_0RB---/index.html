How we proved it never halts

A countdown in which only safe blocks run out

It counts a binary number down, like an odometer running backward. The tape is a list of pairs, each like 1010…10 0101…01 0010: a block of 10s, a block of 01s, and one digit (0010 is a 0, 0001 a 1). On each trip the head goes from the left end to the first 1 digit and back, subtracting 1; every pair it reaches flips its digit and trades one 01 for one 10. About every second time the count reaches zero, the blocks are regrouped into new pairs, so growing and shrinking blocks swap roles, and a pair is added.

The danger is a block of 01s shrinking to nothing. At the first 1 digit that is a normal move: the pair fuses with the next one. Anywhere else the tape leaves the pattern, and some of those tapes halt. Parity decides which: a block whose length plus its digit is even can only run out at the first 1 digit.

The key idea: every block is one of two kinds for life. One kind shrinks in one countdown and grows in the next, and never runs out; every block with the wrong parity is of this kind. The other kind wears down and does run out, but always with the right parity, so it only fuses.

The proof turns this into a checklist of simple inequalities, checked at every second regrouping. If it holds at one, every move up to the next is one of nine known moves, none of which halts, and it holds again there. It holds after 78,710 steps, so the machine never halts.

The Rocq proof (checked against busycoq) proves the nine moves for all block lengths, replays the first 78,710 steps, and shows that a move-by-move version of the checklist holds there and survives every move.

How it works: 3 notes
  • Tape: (10)^h, marker 11001, then pairs (10)^p (01)^q, each ending in a digit block 0001 (=1) or 0010 (=0).
  • Each cycle (3 short bounces + 1 long sweep) subtracts 1 from that binary number; pairs the borrow passes get p+1, q-1.
  • At 0, End adds a tail; at the next 0, Overflow re-pairs the list and adds a pair (net ~1 per 2 epochs: width ~ t^0.5).

444(** * The per-pair clause. n = number of pairs to the right, w = 2^n, tv = value of the digits
445 from this pair to the top (this pair least significant, so tv = d mod 2). Rt = tv + (phase
446 term) is the number of touches the pair still gets before the next re-pairing if no merge
447 happens; p + Rt and q - Rt are invariant under touches. *)
449Inductive phase := E1 | E2 | E1t | E2t | T0 | L1 | L2 | LX.
451(** clauses that depend on n (not on the index) *)
452Definition PN (ph : phase) (c4 : bool) (p q n tv : nat) : Prop :=
453 match ph with
454 | E1 => match n with
455 | 0 => q >= tv + 2 ^ n + 1 /\ p + tv + 2 ^ n >= 3
456 | S _ => q >= tv + 3 * 2 ^ n + 1 /\ (p + tv) mod 2 = 1 /\ p + tv + 2 ^ n >= 3 * 2 ^ n
457 end
458 | E2 => match n with
459 | 0 => q >= tv + 1 /\ p + tv >= 3
460 | S _ => q >= tv + 2 * 2 ^ n + 1 /\ (p + tv) mod 2 = 1 /\ p + tv >= 3 * 2 ^ n
461 end
462 | E1t => match n with
463 | 0 => q >= tv + 2 ^ n + 1 /\ p + tv + 2 ^ n = 5
464 | S _ => q >= tv + 2 * 2 ^ n + 1 /\ (p + tv) mod 2 = 1 /\ p + tv + 2 ^ n >= 3 * 2 ^ n
465 end
466 | E2t => match n with
467 | 0 => q >= tv + 1 /\ p + tv = 5
468 | S _ => q >= tv + 2 ^ n + 1 /\ (p + tv) mod 2 = 1 /\ p + tv >= 3 * 2 ^ n
469 end
470 | T0 => q >= tv + 7 * 2 ^ n + 1 /\ p + tv + 5 * 2 ^ n >= 6 * 2 ^ n /\
471 match n with
472 | 0 => tv = 0 /\ p mod 2 = 0
473 | S _ => (p + tv) mod 2 = 1
474 end
475 | L1 => q + 2 ^ n >= tv + 2 /\
476 match n with
477 | 0 => q = tv + 2 ^ n
478 | 1 => p + tv + 2 ^ n >= (if c4 then 4 else 5) * 2 ^ n /\
479 (q >= tv + 2 ^ n + 1 \/ (q + tv) mod 2 = 0) /\ (if c4 then q = tv + 2 ^ n else True)
480 | S (S _) => p + tv + 2 ^ n >= (if c4 then 4 else 5) * 2 ^ n /\ (q + tv) mod 2 = 0
481 end
482 | LX => match n with
483 | 0 => q = tv + 1
484 | 1 => p + tv >= 4 * 2 ^ n /\ q = tv + 1
485 | S (S _) => p + tv >= 4 * 2 ^ n /\ (q + tv) mod 2 = 0
486 end
487 | L2 => p + tv >= (if c4 then 4 else 5) * (2 * 2 ^ n) /\
488 match n with
489 | 0 => (q >= tv + 1 \/ (q + tv) mod 2 = 0) /\ (if c4 then q = tv else True)
490 | S _ => (q + tv) mod 2 = 0
491 end
492 end.
494(** clauses for pairs 1 and 2 (h only matters for pair 1) *)
495Definition PI (ph : phase) (h i p q n tv : nat) : Prop :=
496 match i with
497 | 1 => h mod 2 = 0 /\
498 match ph with
499 | E1 | E1t => 2 <= n /\ p + tv + 2 ^ n + 3 >= 11 * 2 ^ n /\ h + 4 * (tv + 2 ^ n) + 6 >= 12 * 2 ^ n
500 | E2 | E2t => 2 <= n /\ p + tv + 3 >= 11 * 2 ^ n /\ h + 4 * tv + 6 >= 12 * 2 ^ n
501 | T0 => 2 <= n /\ p + tv + 5 * 2 ^ n + 3 >= 22 * 2 ^ n /\ h + 4 * (tv + 5 * 2 ^ n) + 6 >= 24 * 2 ^ n
502 | L1 => 2 <= n /\ q >= tv + 3 * 2 ^ n /\ h + 4 * (tv + 2 ^ n) + 6 >= 8 * 2 ^ n
503 | LX => 3 <= n /\ q >= tv + 2 * 2 ^ n /\ h + 4 * tv + 6 >= 8 * 2 ^ n
504 | L2 => 1 <= n /\ q >= tv + 4 * 2 ^ n /\ h + 4 * tv + 6 >= 16 * 2 ^ n

506 | 2 => match ph with
507 | E1 | E1t => p + tv + 2 ^ n + 1 >= 7 * 2 ^ n
508 | E2 | E2t => p + tv + 1 >= 7 * 2 ^ n
509 | T0 => p + tv + 5 * 2 ^ n + 1 >= 14 * 2 ^ n
510 | L1 => q >= tv + 2 ^ n + 1
511 | LX | L2 => q >= tv + 1
512 end
513 | _ => True
514 end.

In words:

  • Each Dec* subtracts 1 from V: pairs 1..k are touched.
  • End* and X2 touch every pair; they behave like a decrement from 0 that the tail absorbs.
  • Ov and X1 re-pair the blocks, so that the old splits become the new digit blocks, and they reset h to 2.

Physically, a decrement is three short bounces at the left end followed by one sweep to the borrow pair and back.

Outside cases are the K for which no rule above applies:

  • (o1) Some pass-through pair j < k has q_j = 1.
  • (o2) k = L, q_L = 1 and T = T2.
  • (o3) V = 0, T = -, and some q_j = 1 with j ≤ L−1, but the shape is not X1.
  • (o4) The X1 shape with L ≤ 2 or p_1 = 1.
  • (o5) Ov with p_1 = 1.
  • (o6) X2 with some q_j = 1.
  • (o7) L = 0.

At least (o1), (o3) and (o6) can halt (direct simulation):

case configuration halts after
(o1) K(6; (5,1,0),(7,4,1); −) 1,480 steps
(o3) K(2; (6,1,0),(5,8,0),(11,2,0),(12,3,0); −) 1,554 steps
(o6) K(6; (9,1,0),(5,4,0); T2(5)) 1,684 steps

In random samples, 45 of 56 (o1) instances, 24 of 35 (o3) and 27 of 44 (o6) halted. The others jump to an unrelated K.

Either way, the proof must keep the orbit out of (o1)–(o7), and it does so without using what the machine does there.
