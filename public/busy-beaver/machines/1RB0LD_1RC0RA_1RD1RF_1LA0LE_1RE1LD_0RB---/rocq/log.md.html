Low-level structure found (all proved by plain es, symbolic powers)

A macro step = Start (3 short bounces; A -> B entering pair 1) + one long rightward sweep in state B + a turnaround + one leftward sweep + an end phase at the left edge. - Rightward sweep over a pass pair [p,q+1,0] leaves the region 0 (01)^p 110 (01)^q 11 (left list reg p (q+1) l), the leading 0 being the boundary cell. - Two leftward modes: - Dec mode (state D arrives reading the region's trailing 0): PassL turns the region into [p+1,q,1]; EndPh rebuilds (10)^(h+4) 11001. - Ov mode (D arrives reading the region's last 1, its boundary 0 already on the right): OvL turns reg (p+1) q into (01)^(p+1) 0001 (10)^q (needs p>=1); OvEnd builds (10)^2 11001 (10)^(h+5) (01)^(p1-1) 0010 (needs p1>=2). - Turnarounds: Borrow (d=1, q>=2), MergeB (d=1, q=1, any continuation r: covers DecMerge and DecMergeTail with one lemma), MergeE (q=1, then 0^inf), EndT, EndLastT, OvT, X2T (needs k>=1), and X1Sw (Dec-mode milestone over a q=1 region switches to Ov mode). - List lemmas PassesR, PassesL, OvPasses by induction on the pair list, with LP = left fold of reg, RP = right fold of pair words, OvR = Ov-mode output.

K-level rules proved (proof.md section 2 numbering)

Dec, DecMerge, DecMergeTail, DecMergeEmpty, EndR (End), EndLast, X2, Ov, X1: every rule of the table, each as K h P T -->+ K h' P' T'. Ov/X1 outputs are ovp/ovpX (re-pairing functions). init : c0 -->* K 2 [(11,11,false)] TN by esx (956 steps), compiles.

Pitfalls hit

  • es overshoots a target whose right side differs only by a power rotation ([1;0]^^(S t) *> [0;0;1] vs 1 >> [0;1]^^t *> [0;0;0;1]): it keeps stepping and gets stuck later. Fix: pick the milestone/form es reaches (or the next natural stop).
  • es stops when the head must read a power w^^n whose first period is not a shift-rule period (e.g. E entering [1;0]^^p): state such lemmas with ^^(S p).
  • Under the sym scope, tuples (p,1,true) parse 1 as a symbol: write 1%nat.
  • okR x (a let-pattern Definition) cannot be destructed by an as [..] pattern after inversion: use hnf in Hx; destruct Hx.

High-level plan (rounds 2-4): a PER-STEP invariant J, not a per-cycle period lemma

Use progress_nonhalt_cond with index i = (h, P, T, phase, c4) and C i = K h P T, so every macro rule is one -->+ step and J only has to be preserved by single rules. Ghost phase: E1 (regular E-cycle before End), E1t (after X2), T0 (T2 start, before X2), E2/E2t (after End), L1 (EndLast-type L-slot before EndLast), LX (X1-type L-slot), L2 (after EndLast); ghost c4 (L-slot after a T2 start, before its DecMergeTail).

Key quantities (all per pair j, N = #pairs, n = N - j = #pairs to the right): - tv_j := value of digits d_j..d_N (d_j least significant) = touches left in this countdown. dv of the suffix starting at j. Dec_k: tv_j -1 for j <= k, unchanged for j > k. - extra(phase,n) := 2^n (E1, E1t, L1), 52^n (T0), 0 (E2, E2t, L2, LX). - Rt_j := tv_j + extra = touches pair j still gets before the cycle's re-pairing. - Phat_j := p_j + Rt_j, Qhat_j := q_j - Rt_j (as integers). A touch keeps both, and keeps p+d and q+d mod 2. End/X2 touch the last pair without flipping its digit, and End/EndLast/X2 match the extra-term switch exactly (checked by hand: Phat, Qhat unchanged). - hhat := h + 4Rt_1 (every step touches pair 1, so h grows 4 per touch of pair 1). - DecMerge at k (H := tv_{k+1}): fused pair inherits pair k+1's Rt (Qhat_fused = Qhat_{k+1}, Phat_fused = Phat_{k+1} + p_k + 3); pairs j > k+1 unchanged; pairs j < k: Phat drops by 2^(k-j) H + [phase 1] 2^(N-1-j), Qhat rises by the same.

J formalized (rocq/J.v, standalone, compiles in ~28 s)

  • Per-pair clause PC ph c4 h i p q n tv = 1<=p /\ 1<=q /\ PN ph c4 p q n tv /\ PI ph h i p q n tv: PN matches on n (0 / 1 / >=2), PI on the index i (1 / 2 / other). Parity is stated on p+tv and q+tv (tv = d mod 2), so no digit case split is needed.
