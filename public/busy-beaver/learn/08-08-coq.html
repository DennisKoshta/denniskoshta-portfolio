From informal proof to Coq: a tour of one kill file

The answer

A kill file is the informal proof, rule by rule, written so that Coq can check every step.

  • Each finite rule is a lemma. Coq proves it by running the machine on a tape with unknowns in it (the tactic es).
  • Lemmas chain into one macro rule per case of N (BS1 to BS5), each from one eat configuration EC p N to the next. BS4 and BS5 pass a second eat on the way. A rule for any number of counts is proved by induction.
  • The invariant becomes one closure lemma, step_J.
  • Two busycoq lemmas turn "the blank tape reaches the invariant, and every configuration with it moves on to another" into the final theorem, nonhalt.

The tour follows W5-3's file: 530 lines, compiled by check_kill in 3.4 seconds.

2One lemma is one run you can watch

(* EAT: EB, then the C/F sweep EAT0 over the whole word, then CS *)
Lemma LEat b r:
  HF (0inf <* [0;1]^^b) r -->+ 0inf <* [0;1]^^(b+2) <* [0;1;1] {{A}}> r.
Proof. unfold HF. es. Qed.

LEat says: from the tape on the left of -->+, the machine reaches the tape on the right. It holds for every b and every right side r. First, the four pieces of notation, each on W5-3's real tape.

l <{{E}} r
E reads the last cell of l, the one next to r. Step 171. HF l r is l <{{E}} [1;0;1;1] *> r.
l {{A}}> r
A reads the first cell of r. Step 190: this is how LEat ends.
0inf <* [0;1]^^2a left side
[0;1]^^2 = [0;1;0;1], the list twice. 0inf = blank forever. The list starts at the head and runs left (1, 2, 3, 4), so on the tape it reads 1 0 1 0.
-->+ and -->*
c -->+ c': from c the machine reaches c' in one or more steps (here 19). -->* also allows zero steps; init uses it.

The trap: a left list starts at the head

Row 3 is the trap. Coq keeps the left side as a list that starts at the head and runs left. So 0inf <* [0;1]^^2 is 1 0 1 0 on the tape, which is (10)2. The file's header says the same: EC p N = HF (0^inf (10)^p) (C N) (line 17).

A right-hand list like [1;0;1;1] *> r starts next to the head (or at the head, in the {{A}}> form) and reads left to right, as written. Both notations are one busycoq function, Str_app:

Notation "xs *> r" := (Str_app xs r) (at level 25, right associativity).
Notation "l <* xs" := (Str_app xs l) (at level 24, left associativity, only parsing).

busycoq verify/Helper.v, lines 179–180: Str_app xs s puts the list xs in front of the side s, first item nearest the head.

What es sees: b left unknown

Coq cannot try every b one by one. So es treats (10)^b as one box, and r as another. It runs the cells outside the boxes one step at a time, and crosses a box in one jump with a shift rule (module 2): a rule for one copy of 10, used b times.

Each row is the real tape at b = 2 (the run above, steps in brackets), with the cells of (10)^b and of r drawn as boxes. The page checks the same five rows for b = 0 to 8.

3Lemmas chain into a macro rule

(* M2: N = 0 mod 4 *)
Lemma BS2 p n: EC p (n*4) -->+ EC (p+3+p mod 2) (n+p+4).
Proof.
  unfold EC.
  eapply progress_trans. 1: apply LEat.
  eapply progress_trans. 1: apply Y2C.
  eapply progress_trans. 1: apply (Cnt1 (0inf <* [0;1]^^(p+2) <* [1;1]) 0 (C n) _ (IncC n)).
  eapply pt_eq. 1: apply (Wk (p+2) 1 (1+n)).
  apply HF_eq. 2: f_equal; lia.
  f_equal. f_equal. lia.
Qed.

Each eapply progress_trans. 1: apply X. means: first run lemma X, then prove the rest. So the proof of BS2 is a list of lemmas laid end to end, and its last two lines check the arithmetic with lia. The bar is the real run from EC 2 4 (step 171) to EC 5 7 (step 457), cut where each lemma ends. Tap a piece to jump there.

Induction: one lemma for every size

(* W(a,b): G((10)^a 1 (10)^b, C n) -> E(a+b+[a odd], n+a+1), a+1 counts *)
Lemma Wk a: forall b n,
  HF (0inf <* [0;1]^^a <* [1] <* [0;1]^^b) (C n) -->+
  HF (0inf <* [0;1]^^(a+b+a mod 2)) (C (n+a+1)).
Proof.
  induction a as [a IH] using lt_wf_ind. intros b n.
  destruct a as [|[|a]].

Wk is stated for every a (line 235), so Coq proves it by induction on a (line 239). For a = 0 and a = 1 the counts are done directly. For a ≥ 2 the proof runs W2 (two counts that move the lone 1 two pairs left) and then uses Wk itself for a − 2. Here a goes 4, 2, 0, as in the rows above.

4The invariant becomes one lemma

Lemma step_J p N: 1 <= N <= 2*p ->
  exists p' N', EC p N -->+ EC p' N' /\ 1 <= N' <= 2*p'.

step_J: if 1 ≤ N ≤ 2p (this is J), then EC p N runs to some EC p' N' where J holds again. Below is the real run: the blank tape, then every EC configuration up to step 2,731, with J checked and the macro rule that comes next.

The row at step 37 is a real EC configuration too: EC 0 1. But J fails there, because 1 ≤ 2·0 is false. That is why the opening runs on to EC 2 4.

The proof of step_J (lines 449–478) is this table: split N into cases, apply that case's macro rule, then let lia check 1 ≤ N' ≤ 2p'.

5The last nine lines

This is the whole argument as a picture. The blank tape reaches a configuration with J. From every configuration with J, the machine moves on, in one step or more, to another with J. So it can never stop. The nine lines say exactly this:

Lemma nonhalt: ~halts tm c0.
The claim: started on the blank tape c0 (state A, every cell 0), tm never halts. check_kill requires exactly this line.
Proof.
  eapply multistep_nonhalt. 1: apply init.
multistep_nonhalt (busycoq TM.v line 584): if c0 reaches some configuration c, and c never halts, then c0 never halts. init gives c = EC 2 4.
  change (EC 2 4) with ((fun x : nat*nat => let (p,N) := x in EC p N) (2,4)).
Rewrites EC 2 4 as "EC applied to the pair (2, 4)", so the next lemma can talk about pairs (p, N).
  apply progress_nonhalt_cond with (P := fun x : nat*nat => let (p,N) := x in 1 <= N <= 2*p).
progress_nonhalt_cond (TM.v line 632) with P = J: if every pair with J moves, in at least one step, to another pair with J, and the start pair has J, the machine never halts. Two goals are left.
  - intros [p N] HJ. destruct (step_J p N HJ) as [p' [N' [H1 H2]]].
    exists (p',N'). split; assumption.
Goal 1, every pair with J moves on to another pair with J: that is step_J.
  - lia.
Qed.
Goal 2, the start pair has J: 1 ≤ 4 ≤ 2·2, checked by lia. At Qed, Coq's kernel re-checks the whole proof.

The opening is the one part Coq checks by running the concrete machine. init (line 435) makes it run these 171 steps from the blank tape and compare the result with EC 2 4. The brackets appear twice: at step 171, and at step 37, where the tape is EC 0 1 and J fails.

6Another start state: mirror and rename

A machine whose table is another machine's table seen in a mirror needs no new macro rules. It needs only a new opening, plus three busycoq lemmas.

Definition phi (q : Q) : Q :=
  match q with
  | A => C | B => A | C => B | D => D | E => E | F => F
  end.

Lemma perm: Perm (flip tm) tmP phi.
Proof.
  split.
  - intros [] [] H; cbn in *; try discriminate; reflexivity.
  - intros [] [] s' d q' H; cbn in *; inversion H; subst; reflexivity.
Qed.

Lemma nonhalt: ~halts tm c0.
Proof.
  intros H.
  apply flip_halts in H.
  change (halts (flip tm) (A;; tape0)) in H.
  exact (nonhaltP (perm_halts _ _ _ _ _ perm H)).
Qed.
  • phi (line 351) is the renaming, from W5-8b's states to W5-8's. In this file W5-8 is called tmP.
  • perm (line 356): the mirrored table flip tm, renamed by phi, is tmP, cell for cell (the table above).
  • nonhalt (line 363) is the picture: H is box 1, flip_halts gives box 2, perm_halts box 3, and nonhaltP (line 335) box 4.

So the macro rules carry over from W5-8's own proof. What is new is the opening from the new start state (W5-8 from C: 4,098,826 steps to its first macro configuration, line 148) and these 19 lines.

Recap
  1. Each finite rule is a lemma that es proves by running the machine on a tape with unknowns, crossing each block in one jump. Rules for any number of counts are inductions. Macro rules chain lemmas end to end.
  2. The invariant becomes step_J. multistep_nonhalt (the opening) and progress_nonhalt_cond (the closure) give ~halts tm c0. A mirrored, renamed table started in another state needs a new opening plus Perm, flip_halts and perm_halts.
  3. check_kill demands: it compiles on unmodified busycoq, the string equals the holdout entry, the theorem is Lemma nonhalt: ~halts tm c0., nothing is admitted, and no assumption is added.
